## 二、违规发现与整改结果

### 2.1 总览

| 级别 | 数量 | 占比 | 整改结果 |
|------|------|------|---------|
| **P0** | 10 | 7% | ✅ **全部整改落地** |
| **P1** | 61 | 44% | ✅ **全部整改落地** |
| **P2** | 49 | 35% | ✅ **全部整改落地** |
| **P3** | 19 | 14% | ✅ **绝大部分完成**（4 类纯风格项留痕） |
| **合计** | **139** | 100% | **120 条硬整改 + 15 条 P3 完成 + 4 类留痕** |

### 2.2 P0（安全隐患 / 功能错误，10 条）—— 已清零

| 类别 | 修正 |
|------|------|
| 敏感信息出站（admin_config/works/refresh_work 含 api_key/pat_token/access_code） | 响应剥离敏感字段，统一 `get_work_public()` 脱敏视图 |
| 鉴权缺失（`/api/admin/*` 无校验） | `require_admin` 从 `_admin_sessions` 校验 token，未通过 401 |
| 前端 XSS（renderMarkdown/FileReader 上传 innerHTML） | `DOMPurify.sanitize` 后再插入；上传改 `createElement` |
| Token 明文持久化（sessionStorage） | 改内存变量，不落 sessionStorage |

### 2.3 P1（MUST 规范类，61 条）—— 已清零

| 类别 | 修正 |
|------|------|
| 统一响应契约（约 60 处裸 jsonify） | 统一 `{code, data, message}`，抽公共 `respond()` |
| 裸 except / print 残留 | 改指定异常捕获；`print()` → `logging` |
| JSON 无锁无原子写（数据损坏风险） | `config_loader`/`work_manager`/`knowledge_store`/`knowledge_linker`/`role_import` 全部加锁 + `.tmp`+`os.replace` |
| 明文密码比较 / 任意文件上传 / 句柄泄漏 | 存 hash + 恒时比较；扩展名白名单 + 大小上限；`with open()` |
| 函数签名超上限 / 依赖未锁版本 | `ChatOptions` dataclass 聚合；requirements 锁版本 |
| SSE 流式缺 done / GeneratorExit | 3 处补 `done` + try/finally |
| 前端裸 fetch / 内联 onclick | 统一走 `api.request`（含 blob）；约 18 处内联改 `addEventListener` |
| story_engine 状态残留 | 失败置 `paused` 且不追加 step |

### 2.4 P2（SHOULD 建议类，49 条）—— 已清零

| 类别 | 修正 |
|------|------|
| `_generate_id` 8 位碰撞 | 改完整 `uuid.uuid4().hex` |
| 密码明文存 JSON | 新增 `_hash_password`/`_is_hashed`，新建/迁移/update 均存哈希，旧明文自动迁移，`admin_login` 兼容 |
| `run_workflow` 返回类型不一致 | 流式统一补 `data` 字段，docstring 修正 |
| `convert_to_agent_config` token 写入配置 | api_key 置空占位，真实 PAT 出站时注入 |
| 参数校验 int→500 | 捕获 ValueError 返回 400 |
| 蓝图未用 url_prefix | 补 `url_prefix="/api"`，13 路由改相对路径 |
| 路由层访问私有方法 | `_gen_step`/`_gen_branches`/`_apply_event`/`_collab_lock` 转公开接口 |
| 模块级单例 | `role_agent_scheduler` 参数注入完成 |
| `advance_step` 超 30 行 | 拆为 `advance_step`+`_roll_step`/`_roll_random`/`_commit_step` |
| 文件上传 innerHTML | 三处改 `createElement`+`textContent`/`setAttribute` |
| 流式无 AbortController/竞态 | `state.streamController` 统一管理，navigate/beforeunload 清理，AbortError 静默 |
| CSS 颜色字面量散落 | 收敛 `:root` 变量（`--badge-*`/`--file-preview-*`/`--danger-light`，light+dark） |
| z-index 超分级 | toast 2000→1000 归档 |
| 表单控件缺 aria-label / button 缺 type | 全量补齐 |
| 内联 style 未收敛 | 提炼 `.hidden`/`.modal-*`/`.ai-gen-area` 等 class |
| `_debouncedRefresh` 未清 timer | `destroy()` 加 `clearTimeout` |

### 2.5 P3（MAY 风格偏好，19 条）—— 绝大部分完成

| 类别 | 结果 |
