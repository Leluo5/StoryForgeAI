## 三、测试用例与结果

| 编号 | 用例 | 操作 | 验证点 | 实测证据 | 结果 |
| --- | --- | --- | --- | --- | --- |
| TC-01 | 浅色初始态 | 首次加载页面 | `body[data-theme]` 为 `light`；背景为浅色 | `data-theme="light"`；`--bg-primary` 解析为 `rgb(240,242,245)` | ✅ |
| TC-02 | 切换到深色 | 点击 `#btn-theme-toggle` | 背景/卡片/文字/badge 全部切换深色 Token | 背景 `rgb(15,23,42)`；卡片 `#1e293b`；标题 `#f1f5f9`；描述 `#94a3b8`；badge 深蓝底 | ✅ |
| TC-03 | 图标切换 | 切换主题后检查图标显隐 | 浅色月亮 / 深色太阳 | `body[data-theme="dark"] .icon-moon{display:none}`、`.icon-sun{display:block}` 生效 | ✅ |
| TC-04 | aria 同步 | 切换主题后检查按钮状态 | `aria-pressed` 与 `title` 随主题更新 | 浅色 `false` / 深色 `true`；`title` 文案对应切换 | ✅ |
| TC-05 | 刷新持久化 | 深色下刷新页面 | localStorage 恢复深色 | 刷新后仍为深色，`data-theme="dark"` | ✅ |
| TC-06 | 切回浅色 | 深色下再点击按钮 | 恢复浅色，双向可逆 | `data-theme="light"`；月亮图标；`aria-pressed="false"` | ✅ |
| TC-07 | 控制台 | 全程 | 无 JS 错误 | 控制台 0 错误 | ✅ |

> 注：首次读取背景色曾返回 `rgb(240,242,245)`（浅色过渡中间值）。根因是 `body` 存在 `transition: background-color 0.2s ease`（`style.css` 第 165 行），早期采样落在过渡动画内；待过渡完成后重采样即得深色 `rgb(15,23,42)`，非缺陷。
