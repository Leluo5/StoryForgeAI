## 二、C-001 会话过期（修复：app.py）

**问题**：原 `_admin_sessions[token] = "admin"` 无过期时间，token 永久有效。

**修复**：
- 会话结构升级为 `{"role": <str>, "exp": <unix秒>}`。
- 新增 `_get_session_role(token)`：读取时校验 `exp`，过期自动清除并返回 None。
- `require_admin` / `require_work_access` 改用 `_get_session_role` 判定。
- 会话 TTL：`SESSION_TTL = 24 * 3600`（管理员会话 24 小时）。

**复测**：
- `test_get_session_role_expired`：过期 token 返回 None ✅
- `test_get_session_role_valid`：有效 token 返回角色 ✅
- `test_get_session_role_missing`：不存在 token 返回 None ✅

## 三、C-003 PAT 落盘加密（修复：modules/common/crypto.py + work_manager.py）

**问题**：`import_from_coze` / `import_dataset` / `import_workflow` 将 `pat_token` 明文写入 work 文件。

**修复**：
- 新增 `modules/common/crypto.py`：Fernet 对称加密，提供 `encrypt_value` / `decrypt_value` / `is_encrypted`。
- 主密钥来源优先级：环境变量 `STORYFORGE_MASTER_KEY` → `data/.master.key`（.gitignore 保护，不提交 Git）→ 首次自动生成。
- `work_manager._save_work`：落盘前对 `pat_token` 加密（拷贝后加密，不修改调用方 dict）。
- `work_manager.get_work`：读取时解密，运行时注入 Authorization 头用明文。
- `import_*` 返回 dict 保留明文 pat_token（接口语义不变），磁盘为密文。

**复测**：
- `test_import_pat_not_in_file`：磁盘文件不含明文 token，为加密标记格式 ✅
- `test_get_work_returns_plaintext`：get_work 解密返回明文 ✅
- `test_save_work_keeps_encrypted`：update_work 后磁盘仍无明文 ✅
- `test_public_view_excludes_token`：公开视图不含 pat_token（对外脱敏）✅

**兼容性**：旧明文 work 文件读取时 `is_encrypted=False`，原样返回，自动兼容无需迁移。

## 四、C-004 会话持久化（修复：app.py）

**问题**：会话仅存内存，服务重启后 token 失效。

**修复**：
- 新增 `SESSION_FILE = data/sessions.json`，`_set_session` 写会话时同步持久化。
- 新增 `_save_sessions`：写入前清理过期会话，原子写。
- 新增 `_load_sessions`：启动时恢复有效会话、丢弃过期。
- 在 `if __name__ == "__main__"` 启动入口调用 `_load_sessions()`。

**复测**：
- `test_set_session_writes_persistence`：_set_session 写 sessions.json ✅
- `test_load_sessions_recovers_valid`：启动恢复有效、丢弃过期 ✅
