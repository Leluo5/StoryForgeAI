## 三、整改过程与关键方法

### 3.1 整改原则

- **零破坏**：每处改动以 `pytest 309 passed` 基线为准，改一处验证一处，杜绝回归。
- **最小侵入**：只改违规点，不顺手重构周边代码。
- **可解释**：每类问题有统一、可复用的改法，避免同题异解。

### 3.2 逐类整改方法

| 维度 | 方法 | 关键约束 |
|------|------|---------|
| 行宽 >100 | 超长行折行（dict 字面量拆多行、断言拆行、长 URL 提取常量） | 折行不改变语义 |
| 函数内 import | 移至模块顶部统一分组 | 避免运行时延迟导入副作用 |
| 参数 >5 | `**extra` 聚合可选字段（vararg 不计入 `len(args)+len(kwonly)`），保留核心位置参数，调用点改关键字 | Python 3.9 兼容；调用点零破坏 |
| 引号混用 | 统一双引号；f-string 内嵌键提取中间变量（`bg = ctx.get("background")`）；长 JSON 字符串改三引号双引号；`'/'.join(...)` 改模块级常量 | f-string 内不允许同引号嵌套（Python 3.9） |
| 安全上传校验 | 补扩展名白名单 + 10MB 大小上限 | 与人工审查 P1 上传项一致 |
