## 阻塞原因

`docker compose -f infra/docker-compose.yml up -d postgres --wait` 退出码 1：failed to connect to the docker API at npipe:////./pipe/dockerDesktopLinuxEngine; check if the path is correct and if the daemon is running: open //./pipe/dockerDesktopLinuxEngine: The system cannot find the file specified.

环境复核：WSL 用户态、VirtualMachinePlatform 与 HypervisorPlatform 已安装或启用，固件虚拟化可用，`hypervisorlaunchtype=Auto`；但多次实际重启后 `HypervisorPresent=false`，Docker 服务端仍不可用，因此停止继续修改本机系统配置。

提交前补充检查：`python scripts/run_checks.py --path .` 四类检查均为 0 违规；`pnpm run ci` 因本机 PostgreSQL 实例在重启后不可用而失败，错误为 `connect ECONNREFUSED 127.0.0.1:5432`，未形成 CI 通过结论。本次仅按用户明确指令提交阻塞证据，不代表 M1 验收通过。
