> 版本：v1.0 · 状态：待评审（2026-11-10）
> 项目：StoryForgeAI —— 专业小说 AI 写作软件
> 类型：技术文档

> 维护：02-技术与架构｜关联：[架构设计文档](./架构设计文档.md)、[技术栈](./技术栈.md)
> 权威口径：本文档定义 6 个核心实体表/集合结构，覆盖 P2-T1 数据模型设计；本阶段仅定义结构，不落地表（JSON 文件，预留 SQLite 迁移接口）。

---

## 一、设计总则

### 1.1 存储形态

- **当前**：JSON 文件存储（每项目一文件 / 每条目一文件），个人规模。
- **预留**：`StorageBackend` 抽象接口，并发 ≥ 50 时评估迁移 SQLite。
- **命名**：`<entity>_id` 使用 UUID（`uuid4().hex`），保证跨文件唯一。

### 1.2 实体关系总览

```text
小说项目 (Project) 1 ── n 角色 (Role)
   │                       │
   │                       └── n 角色Agent绑定 (RoleAgentBinding)
   │                            └── n Agent会话 (AgentSession)
   ├── n 章节 (Chapter)
   ├── n 工具调用记录 (ToolCallRecord)
   └── n 剧情树节点 (PlotNode, F7)
```

### 3.4 剧情树分支（PlotBranch，F7 分支管理）

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | string | 是 | 自动 UUID | 分支 ID |
| `project_id` | string | 是 | — | 所属项目 |
| `parent_node_id` | string | 是 | — | 挂载主节点（每主节点可挂多分支） |
| `branch_id` | string | 是 | — | 业务分支标识（同主节点内唯一） |
| `branch_name` | string | 是 | — | 分支名（可重复，以 branch_id 唯一标识区分） |
| `parent_branch_id` | string | 否 | null | 父分支（null=一级分支） |
| `sort_order` | number | 是 | 递增 | 分支排序（同主节点内） |
| `node_ids` | array | 否 | `[]` | 该分支下节点 ID 列表（隔离数据） |
| `content` | object | 否 | `{}` | 分支专属剧情内容（隔离） |
| `created_at` | string | 是 | 当前时间 | 创建时间 |
| `updated_at` | string | 是 | 当前时间 | 更新时间 |

> 约束：`(project_id, parent_node_id, branch_id)` 唯一；`sort_order` 同主节点内唯一；删除非空分支（`node_ids` 非空或存在子分支）禁止，需先清空。

### 3.5 剧情树版本（PlotVersion，F7 版本管理）

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | string | 是 | 自动 UUID | 版本 ID |
| `project_id` | string | 是 | — | 所属项目 |
| `version_no` | number | 是 | 递增 | 版本号（从 1 起，项目内递增） |
| `parent_version_no` | number | 否 | null | 父版本号（回滚可产生新分支） |
| `created_at` | string | 是 | 当前时间 | 创建时间 ISO |
| `created_by` | string | 是 | — | 创建人（用户标识） |
| `note` | string | 否 | `""` | 版本备注（手动创建时填写） |
| `change_type` | string | 是 | `manual` | `manual`/`auto`（自动保存） |
| `snapshot` | object | 是 | — | 剧情树完整快照：`{nodes: [...], edges: [...], node_props: {...}}` |
| `diff_summary` | object | 否 | `{}` | 与父版本差异摘要：`{added_nodes: n, removed_nodes: n, modified_nodes: n, added_edges: n, removed_edges: n}` |

> 约束：`(project_id, version_no)` 唯一；`snapshot` 保存全量节点结构 + 连线关系 + 节点属性配置；回滚时完整还原 `snapshot`。

## 四、索引与查询

| 实体 | 索引/查询键 | 用途 |
| --- | --- | --- |
| Role | `project_id` | 按项目列角色 |
| RoleAgentBinding | `role_id` + `enabled` | 按角色列绑定 |
| AgentSession | `(role_id, agent_id)` 唯一 | 记忆恢复 |
| Chapter | `project_id` + `order` | 章节排序 |
| ToolCallRecord | `project_id` + `tool_name` | 工具审计 |
| KnowledgeEntry | `tags` + `title` | 检索 |
| PlotNode | `project_id` + `parent_id` + `branch_id` | 剧情树遍历 / 分支隔离 |
| PlotBranch | `(project_id, parent_node_id, branch_id)` 唯一 + `sort_order` | 分支挂载/排序 |
| PlotVersion | `(project_id, version_no)` 唯一 | 版本历史查询 |
| VersionOperationLog | `project_id` + `created_at` | 操作溯源 |

> JSON 文件存储下，索引为内存字典 + 文件锁；迁移 SQLite 时转化为唯一索引/普通索引。

## 五、数据完整性规则

| 规则 | 实现 |
| --- | --- |
| 引用完整性 | 角色删除级联删绑定/会话；项目删除级联删角色/章节 |
| 唯一性 | `step_order` 同角色唯一；`(role_id, agent_id)` 唯一 |
| 原子性 | 回写剧情树先校验环路再写入；版本切换先快照当前态再整体还原目标版本（原子替换） |
| 并发安全 | 文件锁（`fcntl`/`msvcrt`）+ 临时文件原子写 |
| 版本权限 | 版本删除/重命名仅授权用户（无权限拒绝并记日志）；创建/切换/回滚/历史/对比全员 |
| 版本日志 | 所有版本操作（create/switch/rollback/rename/delete/compare）写 `VersionOperationLog`，可溯源 |
| 分支隔离 | 各分支 `content`/`node_ids` 独立存储，切换仅加载该分支，不串数据 |
| 分支删除约束 | 删除前二次确认；`node_ids` 非空或存在子分支返回 409 拒绝 |
| 时间 | 全部 ISO 8601（`YYYY-MM-DDTHH:mm:ss`） |
