# 接口契约

> 版本：v1.0 · 状态：待评审（2026-11-10）
> 项目：StoryForgeAI —— 专业小说 AI 写作软件
> 类型：技术文档（API）
> 适用范围：研发
> 维护：02-技术与架构｜关联：[架构设计文档](./架构设计文档.md)、[开发规范](./开发规范/README.md)
> 权威口径：本文档定义本次改造全部新增 API 的请求/响应/错误码；既有 `/api/works/*`、`/api/admin/*` 沿用不在此列。接口契约冻结后变更走 ADR。

---

## 一、契约总则

### 1.1 通用规范

| 项 | 规范 |
| --- | --- |
| 请求格式 | `application/json`（`Content-Type`） |
| 响应格式 | `{"code": 0, "data": ..., "message": "ok"}` |
| 错误格式 | `{"code": <非0>, "data": null, "message": "错误说明"}` |
| 错误码 | `400` 参数错误 / `401` 未授权 / `403` 禁止 / `404` 未找到 / `409` 冲突 / `500` 服务端错误 / `502` 上游错误 |
| 鉴权 | 管理端 `/api/admin/*` 需 `session`；创作端需项目访问令牌（可选） |
| 幂等 | 创建类接口支持 `Idempotency-Key` 请求头，重复请求返回首次结果 |

> 错误码与[开发规范 · 错误处理](./开发规范/01-基础约定与后端规范.md#33-错误处理)一致，禁止自定义 `-1`。

### 1.2 接口分组

| 分组 | 前缀 | 说明 |
| --- | --- | --- |
| 项目 | `/api/projects` | 项目 CRUD、章节、协同 |
| 角色 | `/api/roles` | 角色 CRUD、Agent 绑定、调用 |
| 工具 | `/api/projects/<id>/tools` | 14 工具调用 |
| 知识库 | `/api/knowledge` | F5 知识库管理 |
| 剧情推衍 | `/api/story` | F6 聊天室 |
| 剧情树 | `/api/plot` | F7 剧情树 |
| 安全 | `/api/admin/security` | C-001~C-004 修复后初始化 |

## 二、项目接口

### 2.1 创建小说项目

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `POST /api/projects` |
| 请求 | `{"title": "书名", "genre": "玄幻", "world_setting": {...}}` |
| 响应 | `{"code": 0, "data": {"id": "...", "title": "...", "current_step": 1}}` |
| 错误码 | `400` title 缺失；`409` 同名项目已存在 |

### 2.2 列出项目

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `GET /api/projects` |
| 查询参数 | `page`（默认 1）、`page_size`（默认 20） |
| 响应 | `{"code": 0, "data": {"items": [...], "total": n}}` |

### 2.3 生成章节内容

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `POST /api/projects/<id>/chapters` |
| 请求 | `{"title": "章名", "content": "正文", "author_role_id": "角色ID"}` |
| 响应 | `{"code": 0, "data": {"id": "...", "order": 3}}` |
| 错误码 | `400` content 缺失；`404` 项目不存在；`403` 非本角色章节（越界） |

### 2.4 多角色协同

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `POST /api/projects/<id>/collab` |
| 请求 | `{"roles": ["role1", "role2"], "step_order": 11, "context": {...}}` |
| 响应 | `{"code": 0, "data": {"merged_context": {...}, "conflicts": []}}` |
| 错误码 | `409` 写锁未获取 / 协同未开启；`400` roles 为空 |

| 响应 | `{"code": 0, "data": {"binding_id": "...", "enabled": false}}` |

| --- | --- |

### 7.1 回写节点

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `POST /api/plot/projects/<id>/nodes` |
| 请求 | `{"parent_id": "...", "content": {...}, "source": "derive"}` |

| 错误码 | `409` 环路检测失败 / 父节点缺失 |

### 7.2 分支管理（F7 分支管理）

#### 7.2.1 创建分支

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `POST /api/plot/projects/<id>/branches` |
| 请求 | `{"parent_node_id": "...", "branch_name": "分支名", "parent_branch_id": null}` |
| 响应 | `{"code": 0, "data": {"branch_id": "b-001", "sort_order": 2}}` |
| 错误码 | `400` 参数非法；`404` 主节点不存在 |

#### 7.2.2 重命名分支

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `PUT /api/plot/projects/<id>/branches/<branch_id>` |
| 请求 | `{"branch_name": "新分支名"}` |
| 响应 | `{"code": 0, "data": {"branch_id": "b-001", "branch_name": "新分支名"}}` |
| 错误码 | `404` 分支不存在 |

#### 7.2.3 删除分支（二次确认）

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `DELETE /api/plot/projects/<id>/branches/<branch_id>` |
| 请求 | `{"confirm": true}`（前端二次确认后携带） |
| 响应 | `{"code": 0, "data": {"deleted": true}}` |
| 错误码 | `400` confirm 缺失；`404` 分支不存在；`409` 非空分支（`node_ids` 非空或存在子分支）禁止删除 |

#### 7.2.4 分支排序

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `PUT /api/plot/projects/<id>/branches/<parent_node_id>/order` |
| 请求 | `{"branch_ids": ["b-003", "b-001", "b-002"]}`（目标顺序） |
| 响应 | `{"code": 0, "data": {"order": ["b-003", "b-001", "b-002"]}}` |
| 错误码 | `400` 参数非法；`404` 主节点不存在 |

#### 7.2.5 切换分支（加载隔离内容）

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `POST /api/plot/projects/<id>/branches/<branch_id>/switch` |
| 请求 | `{}` |
| 响应 | `{"code": 0, "data": {"branch_id": "b-001", "node_ids": [...], "content": {...}}}` |
| 错误码 | `404` 分支不存在；`409` 分支数据不完整 |

#### 7.2.6 列出分支（层级缩进树）

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `GET /api/plot/projects/<id>/branches?parent_node_id=<node_id>` |
| 响应 | `{"code": 0, "data": {"branches": [{"branch_id": "b-001", "branch_name": "分支名", "parent_branch_id": null, "sort_order": 1, "children": [...]}]}}` |

### 7.3 版本管理（F7 版本管理）

#### 7.3.1 创建版本

#### 7.3.2 列出版本历史

#### 7.3.3 获取单个版本快照

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `GET /api/plot/projects/<id>/versions/<version_no>` |
| 响应 | `{"code": 0, "data": {"version_no": 3, "snapshot": {"nodes": [], "edges": [], "node_props": {}}}}` |
| 错误码 | `404` 版本不存在 |

#### 7.3.4 切换版本（含回滚）

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `POST /api/plot/projects/<id>/versions/<version_no>/switch` |
| 请求 | `{"mode": "switch"}`（`switch` 临时切换 / `rollback` 回滚为目标版本） |
| 响应 | `{"code": 0, "data": {"restored": true, "version_no": 3, "nodes": n}}` |
| 错误码 | `409` 当前未保存变更需先保存；`404` 版本不存在 |

#### 7.3.5 重命名版本（授权）

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `PUT /api/plot/projects/<id>/versions/<version_no>/rename` |
| 请求 | `{"note": "新备注"}` |
| 响应 | `{"code": 0, "data": {"version_no": 3, "note": "新备注"}}` |
| 错误码 | `403` 无权限（仅授权用户）；`404` 版本不存在 |

#### 7.3.6 删除版本（授权）

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `DELETE /api/plot/projects/<id>/versions/<version_no>` |
| 响应 | `{"code": 0, "data": {"deleted": true}}` |
| 错误码 | `403` 无权限（仅授权用户）；`404` 版本不存在；`409` 当前激活版本不可删 |

#### 7.3.7 版本对比

| 项 | 内容 |
| --- | --- |
| 方法/路径 | `POST /api/plot/projects/<id>/versions/compare` |
| 请求 | `{"from_version_no": 1, "to_version_no": 3}` |
| 响应 | `{"code": 0, "data": {"diff": {"added_nodes": [...], "removed_nodes": [...], "modified_nodes": [...], "added_edges": [...], "removed_edges": [...], "content_changes": [...]}}}` |
| 错误码 | `404` 版本不存在 |

## 十、智能体管理接口（/api/agents）

> 所有 `/<agent_id>` 接口必须携带 `project_id` 查询参数（PUT/DELETE 也可放 JSON body）。
> 响应永不返回 PAT Token/API Key；Agent 文件仅保存 `bot_id` 等非敏感 ID。

### 10.1 Agent CRUD 与生命周期

| 方法/路径 | 说明 | 关键参数 |
| --- | --- | --- |
| `POST /api/agents` | 新建 Agent | body：`project_id`、`kind`、`name`，按 kind 附 `role_id`/`tool_name`/`step_order` |
| `GET /api/agents` | 分页列表 | `project_id`、`page`、`page_size`、`kind`、`status`、`role_id`、`tool_name`、`keyword` |
| `GET /api/agents/<agent_id>` | 详情 | `project_id`、`include_versions=true` |
| `PUT /api/agents/<agent_id>` | 白名单字段更新（生成版本快照） | `project_id` + body |
| `POST /api/agents/<agent_id>/archive` | 归档 | `project_id` |
| `POST /api/agents/<agent_id>/restore` | 恢复为 active | `project_id` |
| `DELETE /api/agents/<agent_id>` | 删除（未归档且非 `force=true` 返回 409） | `project_id`、`force` |
| `GET /api/agents/<agent_id>/versions` | 版本摘要列表 | `project_id` |
| `POST /api/agents/<agent_id>/versions/<version_no>/rollback` | 回滚到指定版本 | `project_id` |

### 10.2 分组

| 方法/路径 | 说明 | 关键参数 |
| --- | --- | --- |
| `GET /api/agents/groups` | 分组树（自动分组 + 覆盖层 + 手工分组） | `project_id` |
| `PUT /api/agents/groups/overrides` | 新增/更新覆盖项 | body：`project_id`、`key`、`name`/`sort_order`/`hidden` |
| `DELETE /api/agents/groups/overrides` | 删除覆盖项 | `project_id`、`key` |
| `POST /api/agents/groups/manual` | 新建手工分组 | body：`project_id`、`name`、可选 `parent_key`/`sort_order` |
| `DELETE /api/agents/groups/manual/<group_id>` | 删除手工分组（组内回落自动分组） | `project_id` |
| `PUT /api/agents/<agent_id>/group` | 移入手工分组（置空回落） | `project_id` + body：`manual_group_key` |

### 10.3 工具 Agent 与作品级开通

| 方法/路径 | 说明 | 关键参数 |
| --- | --- | --- |
| `GET /api/agents/tools` | 按工具汇总候选 Agent 与当前默认 | `project_id` |
| `POST /api/agents/tools/<tool_name>/switch` | 切换工具默认 Agent | body：`project_id`、`agent_id` |
| `POST /api/agents/projects/<project_id>/provision` | 幂等开通作品默认 Agent | 路径参数 |
| `POST /api/agents/projects/<project_id>/bind-roles` | 为作品全部角色补齐默认流程绑定 | 路径参数 |
| `POST /api/agents/migrations/role-bindings` | 存量绑定回填 `agent_ref_id` | body：`dry_run`（默认 `true`） |

### 10.4 角色默认流程与进度

| 方法/路径 | 说明 | 关键参数 |
| --- | --- | --- |
| `POST /api/roles/<role_id>/agents/reset-default` | 恢复角色默认绑定，`mode=fill` 只补缺、`replace` 整体重建 | body：`mode` |
| `GET /api/roles/<role_id>/flow-progress` | 读取角色 11 步流程进度（按 project_id + role_id 隔离） | 由 role_id 反查项目 |
| `POST /api/roles/<role_id>/flow-progress/reset` | 重置进度为 idle | 由 role_id 反查项目 |

> 并发语义：同一 `(project_id, role_id)` 同时触发流程时返回 `409 该角色流程正在执行`；不同角色互不影响。
