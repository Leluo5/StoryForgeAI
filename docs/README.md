## 三、文档规范

所有文档遵循 [文档编写规范](./08-工作流规范/文档编写规范.md)：

- 单一事实来源（SSOT），同一信息只在一处权威正文定义；
- 结论先行，可执行、可验证；
- 代码改动必须同步对应文档（见文档编写规范 §5.7 更新触发表）；
- 站内链接一律相对路径，禁止 `file:///` 绝对链接。
