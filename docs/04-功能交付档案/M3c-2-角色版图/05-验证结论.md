## 六、验证期发现与修复

| 问题 | 影响 | 处理 |

| 历史章节 `content_hash` 口径含 `attrs.pid=null` | T42 纯 pid 保存可能误判为内容变化 | 章节保存改为以规范化内容字符串判定“内容未变”，并保留历史哈希；新写入统一 pid 中立哈希 |
| `chapter_changes` 有 `server_version > 0` 约束 | 版本 0 的纯 pid 保存无法落变更行 | 版本 ≥ 1 时仍写变更行；版本 0 仅返回幂等结果（已在代码注释登记） |
