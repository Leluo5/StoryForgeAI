## 一、档案说明

本档案记录 M3c-2「角色版图」从需求澄清到交付的证据链。当前已完成 **F1 需求澄清定稿** 与 **F2 技术方案定稿**，不代表任务规划、编码实施或验证已经完成。

经用户批准，M3c 命名与顺序统一为：

**M3c-1 剧情（含 C11~C13 自动建树）→ M3c-2 角色版图 → M3c-3 知识库。**

本段聚焦多视图共用的角色资料、角色关系、成长线、专属剧情节点、AI 候选、头像与关系样式，以及可恢复的归档流程。旧 F8 / F9 仅作为需求基线，只有本次明确选择的内容才进入本段承诺。

## 四、已确认范围决策

| 决策点 | 结论 | 依据 |
| --- | --- | --- |
| 命名与顺序 | M3c-1 剧情（含 C11~C13）→ M3c-2 角色版图 → M3c-3 知识库 | 用户确认 |
| 视图与建图 | 多张自定义视图共用角色资料；手动建图＋指定章节或全书 AI 角色 / 关系候选，确认后合并 | 用户确认 |
| 角色专属 AI 扮演者 | 完全不包含配置、调整、绑定或启停 | 用户确认 |
| 成长线 | 手动记录并关联剧情节点、可跳章节；AI 成长事件候选确认后采用 | 用户确认 |
| 头像与连线 | 纳入头像生成与同步；每条关系独立配色，并有标签或线型等冗余表达 | 用户确认 |
| 随机资料与筛选 | 保留旧 F8 整套随机资料生成后人工修改；六维为国家/地域、信仰、阵营、种族、职业、年龄段 | 用户确认 |
| 关系规则 | 支持方向、无方向、反向称谓；同对角色多种关系并存；禁止自我关联 | 用户确认 |
| 关系类型 | 5 组 23 类默认清单（亲属 8、社会 5、情感 4、阵营 4、其他 2），作品内可改名或停用；仍允许自定义类型与反向称谓 | 用户确认（F1 v1.3） |
| 导入导出 | 本期包含角色资料导入与导出；格式见技术方案 §3.5、§4.8 | 用户于 F2 启动前确认 |
| 归档 | 角色归档、关系隐藏、个人剧情同步归档；专属剧情节点仅隐藏节点本身，层级与连线不变；正文命中段落显示「关联角色已归档」并可剔除误报，编辑后降级整章提示；正文仍可编辑且文字不被改写或删除 | 用户确认（F1 v1.3） |
| 个人剧情 | 成长事件 ＋ 作者显式标记为专属的剧情节点；共享节点永不随归档隐藏；提供「显示归档角色剧情」开关 | 用户确认（F1 v1.3） |
| 恢复与清理 | 归档角色可单独查看与恢复，关联内容同步还原；永久清理不在本期 | 用户自定义确认 |
| 疑似重复 | 提供候选，由作者选择合并或保留独立；禁止同名自动合并 | 用户确认 |
| 入口与协同 | 按作品隔离，中央角色页签入口，不遮蔽正文与保存状态；无真人实时协同；AI 不静默覆盖 | 用户确认 |
| 多端与可达性 | 移动 / 平板 / 桌面可用，提供列表、搜索和键盘等价路径 | 用户确认 |
| 验收规模 | 100 个角色 / 150 条关系；打开与筛选 1 秒内有结果，拖拽缩放不阻断；不承诺旧版 `100 ms` / `60 fps` | 用户确认 |
| 旧数据迁移 | 不属于本段，仍归 M4 | 用户确认 |
