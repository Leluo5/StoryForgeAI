## 一、用户诉求（非技术语言）

> 访客希望：**打开作品页，不用注册 Coze，就能直接跟这个智能体聊天、或者填几个参数跑一下工作流，看到结果。**

### 1.1 要解决的核心痛点

- 访客没有 Coze 账号，无法在站内体验 Coze 作品。
- 工作流有参数（变量），需要表单引导，否则不会填。
- 有些作品既要聊天又要填参数，交互模式要灵活。

### 1.2 期望的完整体验

```text
访客进入作品体验页
  → 判断交互模式：
     ├─ chat   → 显示聊天窗口，直接对话（流式打字）
     ├─ form   → 显示参数表单，填完点「运行」
     └─ mixed  → 聊天 + 右侧参数面板
  → 输入/提交 → 流式返回结果（SSE）
  → 对话历史保留在当前会话
```

## 二、功能边界

### 2.1 包含（In Scope）

| # | 能力 | 说明 |
|---|------|------|
| 1 | chat 对话模式 | 智能体 `/v3/chat` SSE 流式，逐字渲染 |
| 2 | form 参数模式 | 工作流 `/v1/workflow/run` 或 `stream_run`，参数表单 |
| 3 | mixed 混合模式 | 聊天 + 参数面板并存 |
| 4 | 参数类型转换 | String/Integer/Number/Boolean/Time/Object/Array/File 8 类 |
| 5 | 流式/非流式切换 | 工作流支持 run 与 stream_run 两条路径 |
| 6 | 会话状态 | conversationId 管理，多轮对话上下文 |
| 7 | 停止/重试 | 流式中可停止，失败可重试 |
| 8 | 文件上传 | File 类型参数走 `/v1/files/upload` |

### 2.2 不包含（Out of Scope）

- ❌ 语音通话 / WebRTC 实时音视频（本平台为文本 + 参数体验）。
- ❌ 作品间跳转推荐算法。
- ❌ 对话历史持久化（当前仅会话内，刷新即失）。
- ❌ 多模态（图片/视频）输入输出（后续增强，目前文本为主）。

## 三、功能流程

### 3.1 chat 模式（智能体对话）

```text
输入消息 → POST /api/works/<id>/chat
  → 后端校验访问 token
  → coze_client.chat_stream(conversation_id, message)
  → SSE 流式返回 { delta } 增量
  → 前端逐字渲染，结束 { done }
  → 保存 conversation_id 供下一轮
```

### 3.2 form 模式（工作流运行）

```text
填写表单（参数类型校验）
  → 转换参数（String→str, Integer→int, Number→float, Boolean→bool...）
  → POST /api/works/<id>/workflow/run
  → coze_client.run_workflow(params)
  → 非流式：返回完整结果；流式：SSE 增量
  → 渲染输出（文本/JSON）
```

### 3.3 mixed 模式

- 左侧聊天 + 右侧参数面板。
- 聊天走 chat 路径，运行按钮走 workflow 路径，互不干扰。
- 参数可被聊天上下文引用（后续增强）。

## 四、验收标准（DoD）

| # | 标准 | 验证方式 |
|---|------|---------|
| 1 | chat 模式消息流式输出不卡顿 | 发消息 → 逐字出现，无整段等待 |
| 2 | 参数类型转换正确 | 填 Integer=abc → 前端拦截报错 |
| 3 | form 运行返回结果 | 填参 → 运行 → 显示输出 |
| 4 | Boolean 参数渲染为开关 | 参数面板 Boolean 类型显示 toggle |
| 5 | File 参数可上传 | 选择文件 → 上传 → 返回 file_id |
| 6 | 流式可停止 | 运行中点击停止 → SSE 断开，状态复位 |
| 7 | 多轮对话上下文保留 | 第 2 条消息能引用第 1 条上下文 |
| 8 | 访问码未验证无法发起体验 | 无 token → API 返回 403 |
| 9 | 工作流非流式降级可用 | stream 失败 → fallback 到 run |

## 五、异常与边界处理

| 场景 | 处理 |
|------|------|
| 参数类型不合法 | 前端即时校验；后端二次校验返回 400 |
| Coze 超时 | 提示超时，允许重试 |
| SSE 连接中断 | 前端显示「连接中断，可重试」，状态复位 |
| 未授权访问 | 403「请先验证访问码」 |
| 作品不存在 | 404 |
| File 上传失败 | 提示重新选择文件 |
| 非流式 fallback | `stream_run` 出错 → 自动切 `run`（如支持） |
| 空消息提交 | 前端禁用发送按钮 |

## 六、数据字段说明

### 6.1 参数定义（params）

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 参数名 |
| `type` | enum | String/Integer/Number/Boolean/Time/Object/Array/File |
| `label` | string | 显示标签 |
| `required` | bool | 是否必填 |
| `default` | any | 默认值 |
| `description` | string | 说明 |

### 6.2 会话（conversation）

| 字段 | 说明 |
|------|------|
| `conversation_id` | Coze 会话 id，多轮上下文用 |
| `messages` | 前端消息数组（仅会话内） |
| `is_streaming` | 是否流式中（防重复提交） |

## 七、相关依赖与约束

- **依赖**：`coze_client.chat_stream` / `run_workflow` / `stream_run` / `upload_file`；`app.js` 的 `chat`/`form`/`mixed` 渲染。
- **约束**：SSE 事件必须 `data: {json}\n\n` 格式；禁止把上游错误原文直接透传。
- **前置**：需先通过 F2 访问码验证（如作品设码）。
