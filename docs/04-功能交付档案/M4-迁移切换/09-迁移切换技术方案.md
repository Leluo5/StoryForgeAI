## 三、设计决策（多方案对比）

### 决策 1：工作流运行触发 —— 同步执行 vs 队列任务

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| A. 同步执行 | 简单 | 长任务阻塞请求、超时风险 | ✗ |
| **B. ai-task 队列（复用）** | **非阻塞、进度可查、SSE 推送** | 需接队列 | **✅ 推荐** |

**推荐 B**：工作流运行入 ai-task 队列，`FlowProgressService` 记录节点进度，前端经 SSE 消费。复用既有 ai-task + flow-progress 机制，不新建执行框架。

### 决策 2：工作流运行状态校验 —— 同步校验 vs 队列内校验

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| A. 仅队列内校验 | 入队快 | 归档工作流也会占用任务槽位 | ✗ |
| **B. 入队前校验状态 + 归属** | **快速失败、不浪费槽位** | 校验两处 | **✅ 推荐** |

**推荐 B**：入队前校验归属与 `status=active`（快速失败 404/409），队列内不再重复校验。

## 四、模块设计

### 4.1 模块结构


### 4.2 工作流运行（WorkflowRunService）

```ts
async runWorkflow(authorId: string, workflowId: string): Promise<{ aiTaskId: string }> {
  // 1. 归属校验：workflow ∈ author（否则 404）
  const wf = await this.assertOwnedWorkflow(authorId, workflowId);
  // 2. 校验 workflow 状态 active（archived 不可运行，409）
  if (wf.status !== 'active') throw new ConflictException('工作流已归档，不可运行');
  // 3. 创建 ai-task（复用 AiTaskService），payload = workflow 编排
  const task = await this.aiTaskService.create({
    kind: 'workflow_run',
    workflow_id: workflowId,
    payload: { node_ids: wf.node_ids, order: wf.order }
  });
  // 4. 入队（ai-task.queue），processor 异步执行节点编排
  await this.aiTaskQueue.addJob(task.id);
  return { aiTaskId: task.id };
}
```

执行经 `ai-task.processor.ts`（现有机制）驱动，`FlowProgressService.recordStep` 记录每节点进度。

### 4.3 端点扩展（workflow.controller.ts）

| 方法 | 路径 | 服务方法 | 说明 |
|---|---|---|---|
| POST | `/ai-workflows/:workflowId/run` | runWorkflow | 运行工作流（入队，返回 `aiTaskId`） |
| GET | `/ai-workflows/:workflowId/runs/:aiTaskId` | getRunStatus | 查询运行进度（经 flow-progress） |

## 五、边界与安全

| 项 | 处理 |
|---|---|
| 长任务运行 | ai-task 队列异步执行，非阻塞；进度经 flow-progress + SSE |
| 归档工作流运行 | `status=archived` → 409 Conflict |
| 归属校验 | `assertOwnedWorkflow(authorId, workflowId)` |
| 鉴权 | `SessionGuard` + 写操作 `CsrfGuard` |
| 输入校验 | `ZodValidationPipe` + schema |

## 八、风险与应对

| 风险 | 应对 |
|---|---|
| 长任务超时 | ai-task 队列 + 超时标记，前端经 SSE 重连 |
| 运行幂等 | 同工作流并发运行允许，但 `aiTaskId` 唯一标识每次运行 |
| 编排字段缺失 | 入队前校验 `node_ids`/`order` 存在，缺失 → 409 |
| ai-task 队列积压 | 复用既有队列容量监控与告警 |
