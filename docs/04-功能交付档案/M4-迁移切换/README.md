## 一、档案说明

本档案记录 M4 迁移切换功能从缺口清点到收尾验收的完整证据链。M4 将唯一写入方从旧 JSON（Flask）切换为 PostgreSQL（NestJS），共 15 项任务：

| 任务编号 | 名称 | 层级 | 状态 |
| --- | --- | --- | --- |
| M4-T1 | 缺口清点（旧架构端点 vs 新架构端点逐项核对） | 前置 | ✅ 已完成 |
| M4-T2 | F6 聊天室房间模型迁移 | 数据层 | ✅ 已完成 |
| M4-T3 | plot sync-room 端点迁移 | 接口层 | ✅ 已完成 |
| M4-T4 | Agent 管理 HTTP 入口补齐 | 接口层 | ✅ 已完成 |
| M4-T5 | 工具开关 / Agent 版本回滚迁移 | 接口层 | ✅ 已完成 |
| M4-T6 | 作品级 LLM 参数生成迁移 | 接口层 | ✅ 已完成 |
| M4-T7 | 作品上传 / 工作流运行迁移 | 接口层 | ✅ 已完成 |
| M4-T8 | role_map AI 建图旧链路迁移 | 数据层 | ✅ 已完成 |
| M4-T9 | 知识库旧端点迁移（detect-type/similar/markdown-render） | 接口层 | ✅ 已完成 |
| M4-T10 | Coze 工作流导入迁移 | 数据层 | ✅ 已完成 |
| M4-T11 | 旧数据分类映射与迁移脚本 | 数据层 | ✅ 已完成 |
| M4-T12 | 迁移数据校验（行数/字段/引用一致性） | 测试 | ✅ 已完成 |
| M4-T13 | 唯一写入方切换（cutover） | 部署 | ✅ 已完成 |
| M4-T14 | 旧代码清理与归零 | 数据层 | ✅ 已完成 |
| M4-T15 | 路线图状态同步 + 全量回归验收 | 测试 | ✅ 已完成 |

核心诉求：旧 Flask + 旧 JSON 业务数据全量迁移落 PG，唯一写入方切换至 NestJS（PG），旧 UI 与旧后端退场，旧代码清理归零。
