## 一、迁移范围

M4 将唯一写入方从旧 JSON（Flask）切换为 PostgreSQL（NestJS），共 15 项任务（M4-T1~T15）：

- **缺口清点（T1）**：枚举旧架构全部端点，识别 38 处缺口。
- **9 类旧端点迁移（T2~T10）**：F6 聊天室房间模型（9 端点）、plot sync-room 数据同步（2）、Agent 管理 HTTP 入口补齐（16）、工具开关 / Agent 版本回滚（2）、作品级 LLM 参数生成（1）、作品上传 / 工作流运行（2）、role_map AI 建图（1）、知识库旧端点（3）、Coze 工作流导入（2）。
- **旧数据迁移（T11）**：`migrate-legacy-data.ts` 分类映射迁移脚本，旧 data JSON 全量落 PG。
- **数据校验（T12）**：`legacy-verify.ts` 独立复跑校验（行数 / 字段 / 引用一致性）。
- **唯一写入方切换（T13）**：cutover（P0 冻结 → 正式迁移 → 全量切新 → 关停旧服务 → 稳定观察）。
- **旧代码清理归零（T14）**：旧 Flask 主链路 + 旧前端 + pytest + 合规脚本 + 配置池删除；CI 同步；已迁移 data JSON 归档。
- **收尾验收（T15）**：路线图状态同步 + 全量回归验收。
