## 一、完成内容

### 1.1 校验脚本升级（`apps/api/src/database/legacy-verify.ts`）

将 T11 的纯函数库升级为 **CLI 入口 + 完整校验**：

| 能力 | 实现 | 说明 |
| --- | --- | --- |
| `legacy_id_map` 覆盖率校验 | `verifyIdMapCoverage(ds)` | 遍历主键映射域（work/agent/character/plot_tree/plot_node/workflow），检查新表每个主键能否在 `legacy_id_map`（domain 匹配）追溯到旧 ID；覆盖率 100% = 全部主键均有映射 |
| 字段比对 | `verifyFields(ds, sourceDir)` | 主键映射域（work/character/plot_node）全量比对；非主键字段（agent/workflow）10% 抽样固定种子 |
| 抽样可复现 | `seededSample(arr, ratio, seed=42)` | LCG 固定种子 42，多次运行抽样集合一致 |
| CLI 入口 | `main(argv)` | 解析 `--source`/`--report`/`--strict`，初始化数据源，运行校验，写报告文件 |
| 退出码 | `runVerify(opts)` | 0 通过 / 1 有差异 / 2 执行错误 |
| Markdown 报告 | `renderMarkdownReport(opts, result)` | 四节：行数对比表 / 覆盖率 / 字段比对 / 差异明细 |
