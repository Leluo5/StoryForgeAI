### 2.1 CI 运行中发现的修复（T14-8 验证触发）

首次 `pnpm run ci` 失败，定位为**旧前端 Node 测试残留引用已删模板**：

- **现象**：`tests/node/auth-entry.test.mjs`、`tests/node/f3-chat-ui.test.mjs` 引用已删除的 `templates/index.html` 与 `static/js/app.js`（旧 Flask 前端）。
- **根因**：T14-4 仅删除了旧 pytest（`.py`），遗漏了这两个**旧前端配套的 `.mjs` 测试**。
- **修复**：删除这两个旧前端测试文件（`node --test tests/node/*.test.mjs` 自动匹配，属旧链路归零范围）。
- **结果**：删除后 `node --test` 4/4 通过，`pnpm run ci` 全绿。

> 说明：CI 运行还暴露本地测试基础设施（PG 5433 / Redis 6380 未启动）问题——此为**环境问题，非 T14 引入**，CI 的 test job 自带 `docker compose up` 步骤；本地验证已通过 `docker compose up -d postgres/redis --wait` 补齐。
