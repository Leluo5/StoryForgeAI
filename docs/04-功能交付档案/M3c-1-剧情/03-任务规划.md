## 一、任务总览

```text
第一阶段（本期主线）
  C1 数据层（实体 + 迁移）
   └→ C2 契约层
        ├→ C3 剧情树服务（节点/父级/分组/坐标 + 环检测）
        │    └→ C4 关联与导入导出
        │         └→ C5 剧情树接口层 + API 集成测试
        └→ C6 任务作用域扩展（ai_tasks scope=plot + Provider 端口）
             └→ C7 推衍服务与接口（会话/步骤/候选/确认回写）
  C8 前端剧情页签（client/state/workspace/canvas/layout/inspector）
   └→ C9 前端推衍与列表视图（a11y + 响应式）
        └→ C10 测试与验收（单测/API E2E/Playwright/回归/文档）

第二阶段（第一阶段验收后）
  C11 自动建树后端（草稿 + 生成服务 + 工具）
   └→ C12 自动建树前端（预览编辑 + 提交）
        └→ C13 第二阶段验收与文档
```

依赖原则：数据层 → 契约 → 服务 → 接口 → 前端 → 验收；前端 C8 可在 C5 与 C6 完成后并行推进，但 C9 必须等 C7 完成。
