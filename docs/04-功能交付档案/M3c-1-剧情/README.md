## 一、档案说明

本档案记录 M3c-1「剧情」功能从需求澄清到上线的完整证据链。M3c 是 M3 里程碑第三段（剧情 → 角色 → 知识），本段为第一子段，聚焦 **剧情树 + 推衍**：

- 剧情树：树 + 图混合结构（父子层级主线 + 线性/非线性关联），节点增删改查、分组/泳道、自动布局、拖拽缩放、搜索、导入导出。
- 推衍：从节点发起步进推衍，每步暂停可编辑、可选分支，结果作为候选节点，经作者确认后回写剧情树。

第一阶段为结构化 CRUD + 可视化与推衍联动；第二阶段（同里程碑内）补大纲 / 章节文本自动建树。

不在本期：节点挂接章节与角色、真实外部模型接入、旧 Flask 数据迁移（留 M4）。
