## 一、用户诉求（非技术语言）

### 1.1 要解决的核心痛点

1. **剧情一多就乱**：主线、支线、伏笔混在一起，作者说不清哪段在前、哪段属于哪条线，写到中后期容易自相矛盾。
2. **结构看不见**：正文按章节线性排列，跨章节的因果与呼应关系只能靠脑记，缺一张能看、能改的剧情地图。
3. **推衍与结构脱节**：旧系统的剧情推衍是独立聊天室，推衍出来的好内容要手动抄回大纲，结构那边永远跟不上。
4. **自动生成不可控**：旧系统能自动解析建树，但生成结果不好改、布局不可调、分组不清，最终还是要手动返工。
5. **结构数据不透明**：剧情树数据无法导出复用，换设备、换工具就丢。

### 1.2 期望的完整体验

```text
作者在写作工作台打开「剧情」页签
  → 首次进入为空态，可「新建空树」或「导入 JSON」起步
  → 手动搭结构：
       ├─ 建节点（标题 / 概要 / 正文片段 / 受控属性）
       ├─ 拉主线（父子层级：父剧情 → 子剧情）
       ├─ 拉支线（线性关联：必须先于；非线性关联：无先后）
       └─ 分组 / 泳道归类，一键自动布局，拖拽微调
  → 画布操作：拖拽、缩放、适应视图、关键词搜索定位
  → 选中某节点 → 发起推衍：
       ├─ 配置场所 / 背景 / 时间节点 / 前置剧情 / 关联剧情
       ├─ 手动录入参与角色（本期不接角色库）
       ├─ 逐步推衍，每步自动暂停，可改内容、选分支
       └─ 推衍结束 → 生成候选节点 → 作者确认 → 写入剧情树
  → 作品结构可导出 JSON，换环境可导入恢复
```

### 1.3 核心目标（与 M3 验收门槛一致）

| 目标 | 说明 |
| --- | --- |
| 结构可建可改 | 剧情树、节点、关联、分组全部可视化增删改，改完即持久化 |
| 主线支线分明 | 父子层级表达主线包含关系，线性/非线性关联表达跨线关系，三类连线样式可辨 |
| 结构可信 | 父子链与线性关联均禁止成环，非法操作明确拒绝 |
| 推衍可回写 | 推衍结果作为候选节点，经作者确认后写入剧情树并挂接，不直接覆盖结构 |
| 布局可管 | 拖拽、缩放、自动布局、分组/泳道、搜索齐全，节点规模上千仍可操作 |
| 数据可迁移 | 剧情树可导出 JSON 并原样导入恢复，结构校验不通过时不覆盖现有树 |
| 自动建树可审 | 第二阶段支持大纲 / 章节文本解析建树，结果先预览再确认入库 |

## 二、功能边界

### 2.1 包含（In Scope）

**第一阶段（本期主线）**

1. **剧情树实例**：一个作品一棵主剧情树，含标题、来源（manual/import）、版本号、时间戳。
2. **节点增删改查**：节点标题、概要、正文片段、受控属性（时间点、地点、状态）、画布坐标、来源（manual/derivation/outline/novel_text/import）。
3. **树 + 图混合结构**：
   - 父子层级（主线）：每个节点至多一个父节点，同级有顺序；
   - 线性关联（支线/跨线）：有方向的「必须先发生」，必须构成无环图；
   - 非线性关联：无方向的「呼应/同事件不同侧面」。
4. **关联守卫**：父子链禁止成环；线性关联禁止成环；非线性关联不限制方向与数量。
5. **可视化画布**：节点拖拽、画布缩放、适应视图、一键自动布局（层级 + 分组内局部布局，可撤销一次）。
6. **分组与泳道**：自由分组框与手动命名泳道，节点可归入一个分组/泳道，布局按组分区。
7. **搜索定位**：按标题/概要/正文片段/属性关键词搜索，命中高亮并居中定位，支持按来源与分组过滤。
8. **导入导出**：导出完整树结构 JSON（含 schema 版本号）；导入时校验结构、重建标识、覆盖前二次确认，失败不覆盖。
9. **推衍会话**：从选中节点发起，配置场所/背景/时间节点/前置剧情（树内多选）/关联剧情（树内多选），手动录入参与角色名称与一句话设定。
10. **步进推衍**：每步生成后自动暂停，作者可编辑本步内容，每步提供多个分支选项，选择结果影响下一步走向。
11. **随机机制**：随机意外事件与随机新角色入场可开关，触发结果在步骤中明确标注。
12. **候选节点与人工确认回写**：推衍结束生成候选节点（默认合并为 1 个，可选按步拆分多个），作者确认后写入剧情树并挂到起点节点下（或作为兄弟节点），拒绝则不写入。
13. **前端入口**：写作工作台中央「剧情」页签承载剧情树与推衍，不遮蔽正文与保存状态。
14. **审计**：树/节点/关联/分组/推衍回写的关键变更写入审计日志。

**第二阶段（同里程碑内，第一阶段验收后启动）**

15. **大纲自动建树**：粘贴大纲文本 → 生成树预览（节点 + 层级）→ 可编辑 → 确认入库。
16. **章节文本解析建树**：选择作品内章节正文作为解析输入（仅作输入，不建立节点-章节关联）→ 生成树预览 → 确认入库；失败保留原文并降级为手动建树。

### 2.2 不包含（Out of Scope）

1. **节点挂接章节与角色**（本期明确不做）：节点不存 chapter_id / role_id，也不做双向跳转；角色版图（M3c-2）上线后再评估。
2. **自动生成正文**：剧情树只管结构，正文仍由推衍或写作工具产出。
3. **推衍结果自动回写**：必须经作者确认，系统不得自动写入结构。
4. **多棵剧情树并存**：本期一作品一棵主树，多树与跨作品合并留后续。
5. **旧 Flask 剧情树 / 聊天室数据迁移**：不迁移代码与数据，统一留 M4 迁移里程碑。
6. **角色库联动**：推衍参与角色本期为文本录入，不读取角色版图，不做角色 Agent。
7. **节点级权限与多人协同**：沿用单作者模型。
8. **动画式剧情回放、时间轴播放**：本期为静态结构与步进推衍。
9. **真实外部模型接入**：推衍与自动建树沿用 M3a 任务队列与既有 Provider 能力，Coze 真实接入不在本期。

## 三、功能流程

### 3.1 建树与手动编辑

```text
作者打开「剧情」页签
  → 无树：空态提供「新建空树」/「导入 JSON」
  → 有树：渲染画布（节点 + 父子连线 + 线性/非线性关联）
  → 工具栏「新增节点」→ 填写标题/概要/正文片段/属性 → 落点画布
  → 双击节点 → 编辑内容与属性 → 保存即时持久化
  → 删除节点 → 二次确认（含子节点与关联的影响说明）→ 级联删除子树与相关关联
```

### 3.2 建立三类连线

```text
主线（父子层级）
  → 拖动节点到目标节点「子级」热区，或右键「设为子节点」
  → 校验：不能设自己或自己的祖先为父 → 成环则拒绝并提示
  → 同级顺序可通过拖拽排序调整

线性关联（必须先发生）
  → 从节点 A 拖线到节点 B，选择「线性关联」
  → 校验：加入后线性链不得成环 → 成环返回冲突提示，不写入

非线性关联（无先后）
  → 从节点 A 拖线到节点 B，选择「非线性关联」
  → 无方向校验，允许双向各建一条
```

### 3.3 布局、分组与搜索

```text
分组/泳道
  → 新建分组框或泳道并命名 → 拖节点入组
  → 一个节点至多归属一个分组/泳道

自动布局
  → 点击「自动布局」→ 按父子层级分层排布，组内局部布局，泳道横向分区
  → 布局结果写入坐标 → 提供一次「撤销布局」回到布局前坐标

手动微调
  → 拖拽节点 → 坐标实时更新并持久化（不触发结构变更）
  → 画布滚轮缩放 / 适应视图 / 复位

搜索
  → 输入关键词 → 命中节点高亮 → 点击结果居中定位
  → 支持按来源（手动/推衍/导入/自动生成）与分组过滤
```

### 3.4 推衍与人工确认回写

```text
选中起点节点 → 「发起推衍」
  → 配置：场所 / 核心背景 / 时间节点（默认取节点属性，可改）
         / 前置剧情（树内多选）/ 关联剧情（树内多选）
         / 参与角色（文本录入名称 + 一句话设定，至少 1 个）
         / 随机事件、随机新角色（开关）
  → 「开始推衍」→ 生成第 1 步 → 自动暂停
  → 作者：编辑本步内容 / 从分支选项中选择 / 调整配置 → 「下一步」
  → 循环直至「结束推衍」
  → 生成候选节点预览（默认合并为 1 个；可勾选按步拆分）
  → 作者确认挂接位置：作为起点节点的子节点 / 作为起点节点的兄弟节点
  → 确认 → 原子写入（节点 + 关联 + 坐标 + 审计）→ 画布即时刷新并定位新节点
  → 拒绝 → 候选丢弃，剧情树保持不变
```

### 3.5 导入导出

```text
导出
  → 选择「导出 JSON」→ 下载包含树/节点/关联/分组/schema 版本/导出时间的文件

导入
  → 选择 JSON 文件 → 结构校验（必填字段、引用完整性、环检测、schema 版本）
  → 校验通过 → 提示「将覆盖当前剧情树」→ 二次确认
  → 确认 → 重建标识并写入 → 画布刷新
  → 校验失败 → 明确失败原因，现有剧情树不受影响
```

### 3.6 大纲 / 章节文本自动建树（第二阶段）

```text
选择输入来源：粘贴大纲文本 / 选择作品内章节正文
  → 提交解析（走 M3a 任务队列，进度可见）
  → 生成树预览：节点标题 + 概要 + 层级关系
  → 作者编辑预览（增删改节点、调整层级）
  → 确认入库：覆盖当前树 / 追加为新子树（二选一，覆盖需二次确认）
  → 解析失败：保留输入原文，提示原因，可重试或转手动建树
```

## 五、异常与边界处理

| 场景 | 系统行为 | 用户反馈 |
| --- | --- | --- |
| 未登录 / 无作品权限 | 拒绝访问，401/403 | 提示登录或权限说明 |
| 剧情树不存在 | 404 | 提示暂无剧情树并提供新建入口 |
| 设自己或祖先为父节点 | 409，拒绝写入 | 提示「不能形成循环层级」 |
| 线性关联合成环 | 409，拒绝写入 | 提示「该关联会形成循环，请调整」 |
| 删除有子节点的节点 | 二次确认，确认后级联删除子树与相关关联 | 提示将一并删除的节点数量 |
| 删除分组 | 组内节点保留并回到未分组，不删除节点 | 提示「仅解除分组」 |
| 拖拽超出画布边界 | 坐标限制在画布范围内 | 无感 |
| 导入 JSON 结构非法 / 引用缺失 / 成环 / 版本不匹配 | 拒绝导入，不改动现有树 | 明确失败原因 |
| 搜索无结果 | 保持画布不变 | 空态 + 建议放宽条件 |
| 推衍未填必填项 | 禁止开始 | 字段内联错误并聚焦首个 |
| 推衍无参与角色 | 禁止开始 | 提示至少录入 1 个角色 |
| 推衍任务失败 | 保留会话配置与已完成步骤 | 提示重试，已生成内容不丢 |
| 推衍工具被停用 | 拒绝发起，409 | 提示「剧情推衍工具已停用」 |
| 同一会话重复确认回写 | 幂等处理，不重复生成节点 | 提示已完成回写 |
| 回写时起点节点已被删除 | 409，候选保留 | 提示重新选择挂接位置 |
| 并发编辑同一棵树 | 乐观版本校验，版本过期返回 409 | 提示刷新后重试 |
| 自动建树输入过短 / 无情节 | 拒绝生成 | 提示补充大纲内容 |
| 自动建树解析超时 | 任务标记失败，保留输入原文 | 提示重试或转手动 |

## 六、数据字段说明（概念模型）

### 6.1 剧情树（plot_tree）

| 字段 | 说明 |
| --- | --- |
| `tree_id` | 剧情树标识（不可猜解 UUID） |
| `work_id` | 所属作品（一作品一棵主树） |
| `title` | 剧情树标题 |
| `source` | 来源：`manual / outline / novel_text / import` |
| `schema_version` | 导入导出结构版本号 |
| `version` | 乐观并发版本号 |
| `created_at` / `updated_at` | 时间戳（UTC 存储，界面按上海时区显示） |

### 6.2 剧情节点（plot_node）

| 字段 | 说明 |
| --- | --- |

## 七、相关依赖与约束

1. **复用 M3a 任务队列与 SSE**：推衍步进与大模型建树均作为 AI 任务执行，进度通过 SSE 推送；任务状态以数据库为准。
2. **复用 M3b 工具注册表**：推衍与自动建树以工具标识注册（如 `plot_derivation` / `plot_generate`），工具停用时拒绝发起并返回 409；禁止前端硬编码工具清单。
3. **复用 M2 审计服务**：树/节点/关联/分组变更与推衍回写写入审计日志。
4. **复用契约与鉴权模式**：前后端从 `@storyforge/contracts` 复用 Zod Schema；沿用 `SessionGuard` + `CsrfGuard` + `ZodValidationPipe` + `ok()` 包装与 401/403/404/409/422 错误语义。
5. **AI 不直接覆盖**：推衍结果必须先成为候选，作者确认后才写入结构；回写失败整体回滚。
6. **结构完整性**：父子链与线性关联均禁止成环；导入必须做引用完整性与环检测。
7. **坐标独立维护**：拖拽只更新位置，不触发结构变更；自动布局写坐标且可撤销一次。
8. **性能**：单树 500 节点内交互无明显卡顿；更大规模在任务规划阶段评估虚拟化或分片渲染。
9. **不迁移旧数据**：旧 Flask 剧情树与聊天室数据不导入，留 M4 统一迁移。
10. **响应式与无障碍**：375/768/1024/1440 四档可用；核心操作键盘可达；动效尊重 `prefers-reduced-motion`。
11. **时区与标识**：时间统一 UTC 存储、界面按 `Asia/Shanghai` 展示；标识使用不可猜解 UUID。
