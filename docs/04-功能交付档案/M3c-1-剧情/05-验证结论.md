## 三、CI 门禁

`pnpm run ci`（contracts build → lint → typecheck → 全量 test → build）：

- 5 个 workspace 的 `lint` / `typecheck` / `build` 全部通过。
- vitest 全量：**57 个文件 / 341 个用例全部通过**（含新增剧情前端 42 例、API E2E 2 例、工作台 2 例）。
- Node 基线测试 2/2 通过。

> 门禁必须使用 `pnpm run ci`；`pnpm ci` 会被 pnpm 当作内置命令报 `ERR_PNPM_CI_NOT_IMPLEMENTED`。
> 全量测试前需停止本地 dev server，避免其 BullMQ Worker 与测试共用 Redis 队列抢任务。

> 口径补充（2026-11-19）：`.github/workflows/ci.yml` 已拆分为三层并行门禁——**quality**（静态质量门禁：lint / typecheck / build）、**test**（单元与 API E2E）、**m1**（M0–M3c 全链路验收，含浏览器 E2E）。本地 `pnpm run ci` 与 GitHub Actions 三层门禁并行执行，二者均为提交前必须全绿的门禁；三层拆分来源见 [M3a 实施记录 §七](../M3a-AI创作基座/04-实施记录.md)。
