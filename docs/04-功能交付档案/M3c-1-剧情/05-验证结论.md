## 一、结论

**两个阶段（C1~C13）均达到可交付标准。**

- 第一阶段后端：剧情树 16 条路由、推衍 8 条路由、导入导出、任务作用域、确认回写全部实现。
- 第一阶段前端：工作台「剧情」页签、画布（三类连线/拖拽/缩放/自动布局/撤销/搜索/导入导出）、列表视图、推衍面板全部实现。
- 第二阶段后端：新增自动建树草稿 5 条接口、大纲/章节快照输入、`plot_generate` 任务链、覆盖/追加事务提交、版本推进与 `plot_generation_commit` 审计、失败保留原文。
- 第二阶段前端：工具栏「自动建树」入口、SSE + 轮询进度、预览节点编辑、覆盖二次确认、追加父节点选择、失败重试/转手动建树。
- 验收：API E2E 19/19、前端剧情单测 50/50、Playwright 7/7（含 axe 0 violation），`pnpm run ci` 全绿。

不纳入本期：节点挂接章节与角色、真实外部模型接入、旧数据迁移（M4）。

## 五、已知限制与残余风险

| 项 | 说明 | 处理 |
| --- | --- | --- |
| 推衍步骤等待方式 | 第一阶段前端采用轮询 `getDerivation`（1.5s / 最多 40 次） | 已于 2026-11-19 接入 SSE：面板订阅任务事件，异常自动回退轮询；补 `ai-task.sse.test.ts` 与面板用例 |
| 拖拽入组 | 画布拖拽仅调整坐标；归组通过检查器「分组」下拉完成 | 已在 02 §6 登记偏差；拖拽入组留作体验优化 |
| 并发 409 的 UI 验证 | Playwright 未覆盖双端并发场景，仅单测 + API E2E 覆盖 | 冲突提示文案与刷新引导已单测断言 |
| 模型能力 | 推衍走 `MockPlotModelProvider`，真实外部模型未接 | 与项目整体 AI 能力节奏一致，留待后续里程碑 |
| dev 缓存 | 契约 `dist` 更新后需清理 `apps/web/node_modules/.vite/deps` | 已记录到 04 实施记录；CI 走 build 不受影响 |
| 自动建树前置 | 覆盖/追加提交要求作品已有剧情树，否则返回 409 `PLOT_TREE_MISSING` | 前端按现有语义提示；新建作品需先「新建空树」 |
| 草稿可追溯性 | 目前只有按 ID 查询草稿，无草稿列表；关闭预览后无法从 UI 重新打开旧草稿 | 不影响正式树；如需恢复列表能力，列入后续迭代 |
| 章节自动建树内容 | Playwright 使用 Mock 模型，新作品章节为空时根节点回退为「自动剧情树」 | 真实模型接入后按模型输出；API E2E 已覆盖章节正文快照 |
