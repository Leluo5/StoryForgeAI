## 一、交付清单

### C1 数据层

- 8 个实体：`plot_trees / plot_nodes / plot_links / plot_groups / derivation_sessions / derivation_steps / derivation_candidates / plot_generation_drafts`。
- 迁移：
  - `1760300000000-plot-base.ts`：建表 + 幂等种子工具 `plot_derivation`、`plot_generate`；
  - `1760300001000-ai-task-plot-scope.ts`：`ai_tasks.chapter_id` 可空、新增 `scope`（默认 `chapter`）；
  - `1760300002000-derivation-session-start-node-no-fk.ts`：删除 `derivation_sessions.start_node_id` 外键（原因见 02 §2.3）。
- `data-source.ts` 注册实体与迁移；`test/test-database.ts` 倒序清表、种子工具补齐为 6 个。

### C2 契约层

- `packages/contracts/src/plot.ts`：枚举、节点/关联/分组/树、导入导出、推衍会话/步骤/候选、自动建树请求与响应 Schema。
- `aiTaskSchema` 增加 `scope`、`chapter_id` 可空；`index.ts` 导出。

### C3 剧情树服务

- `plot-tree.service.ts`：整树读取、建树、节点 CRUD、父级调整、归组、批量坐标、乐观锁（`expected_version` → 409）。
- `plot-cycle.ts`：父子链与线性关联环检测（Kahn 拓扑）。
- 坐标批量更新不推进结构版本；删除节点级联子树；删除分组仅解组。

### C4 关联与导入导出

- `plot-import.ts`：导入校验顺序 `duplicate_id → invalid_parent → invalid_group → invalid_link → parent_cycle → link_cycle`，失败 422 `PLOT_IMPORT_INVALID` 且不写库。
- `createLink` 自指守卫 409 `PLOT_LINK_SELF`（DB CHECK 之前拦截）；重复关联 409 `PLOT_LINK_EXISTS`。
- `exportTree`（`schema_version:1` + `exported_at`）/ `importTree`（事务内重建、id 全部重发、第二遍回填父子、`version+1`、审计 `plot_tree_import`）。

### C5 接口层

- `plot.controller.ts`：16 条剧情树路由（含导出附件头、导入 200）；`SessionGuard` + 写操作 `CsrfGuard` + `ZodValidationPipe` + `ok(request, data)`。
- `plot.module.ts` 注册，`app.module.ts` 挂载。
- `test/plot-tree.e2e-spec.ts`：10 个用例覆盖鉴权、版本冲突、环、子树删除、坐标不推版、导入导出、跨作者 404。

### C6 任务作用域扩展

- `plot-model.provider.ts`：`PlotModelProvider` 端口 + `MockPlotModelProvider` + `PlotModelError(retryable)`。
- `plot-task.handler.ts`：`writeStep` 在调用方事务内 pessimistic_write 锁会话、同 `step_no` 幂等、写步骤并置会话 `paused`。
- `ai-task.processor.ts`：`ProcessContext` 拆 `chapter | plot`；plot 分支 `buildPlotContext`（会话 + 前置/关联节点摘要 + 近 5 步历史）→ `generateStep` → `finishPlotSucceeded`；错误分类兼容 `PlotModelError`。
- `ai-task.service.ts`：`assertOwnedTask` 改经 `WorkEntity` 校验，兼容无章节 plot 任务（getTask/retry/cancel/SSE 不再 404）。
- `ai-task.module.ts`：导出 `AI_TASK_QUEUE`、`AI_TASK_EVENT_BUS` 供 plot 模块复用。

### C7 推衍服务与接口

- `plot-derivation.service.ts`：会话创建（工具启停 + 节点归属校验）、查询、更新（running 禁改配置）、生成下一步（同会话 pending 任务 409）、步骤编辑（未知分支 422）、候选生成（合并 / 按步拆分 `parent_index` 链）、确认回写、拒绝。
- 确认回写单事务：锁会话与树、`expected_version` 校验、用候选 `start_node_id` 快照定位起点（已删 409 `PLOT_START_NODE_MISSING`）、sibling 位移、`origin='derivation'`、`version+1`、审计 `plot_candidate_confirm`；重复确认经 `payload.confirmed_node_ids` 幂等返回。
- 8 条推衍路由（`POST steps` 返回 202）。

## 二、关键问题与处理

| 问题 | 处理 |
| --- | --- |
| 自指关联触发 DB CHECK 抛 `QueryFailedError` | 服务层前置 `PLOT_LINK_SELF` 409 |
| 删除起点节点级联删除推衍会话 | 新增迁移 `1760300002000` 去掉外键；回写改用候选快照，节点缺失返回 409 |
| Nest DI 在 vitest/esbuild 下无 decorator metadata | 全部显式 `@Inject(Token)`，`DataSource` 用值导入 |
| plot 任务无章节导致任务查询 404 | `assertOwnedTask` 改走 `work_id` |
| e2e TRUNCATE 后推衍工具缺失 404 | 测试种子补齐为 6 个工具 |
| 全量回归时 M3b 两个用例断言 4 个种子工具 | 同步更新为 6 个（`agent.service.test.ts`、`agent-config.e2e-spec.ts`） |
| `ai-task.queue.test.ts` 超时 / job 被锁 | 后台 dev server 的 Worker 与测试共用 Redis 队列抢 job；停掉 dev server 后 5/5 通过，非代码回归 |
