## 一、档案说明

本档案记录 M3b「Agent 与工具」功能从需求澄清到上线的完整证据链。M3b 是 M3「AI 创作」的第二个子里程碑，聚焦 **Agent 配置与管理**：创作工具注册表、工具 ↔ Agent 绑定、执行 Agent 配置与模型参数、配置管理前端面板、发起任务时解析执行 Agent（接入 M3a 的 `ai_tasks.agent_id` 预留字段）。

核心诉求：作者（或管理员）在写作工作台中为每个 AI 创作工具指定执行 Agent 与模型参数，配置变更即生效、可审计，发起 AI 任务时按工具解析出执行 Agent 并写入任务记录。

M3b 后续段（不在本期范围）：AI 创作工具全集、Coze Provider 接入、角色 Agent / 流程 Agent。M3c（剧情/角色/知识）为 M3 第三段。
