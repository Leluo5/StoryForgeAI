## 一、验收结论

M3b「Agent 与工具」验收通过。DoD #D1 ~ #D11 共 11 项全部满足：D1~D8、D11 由自动化测试覆盖，D9/D10 由 Playwright 原生驱动采集。

产品结论：作者可在写作工作台「Agent 管理」面板查看工具注册表、为工具绑定执行 Agent 与模型参数、启停工具、维护 Agent 列表与默认 Agent；配置变更即生效并写审计；发起 AI 任务时按工具解析执行 Agent 并写入 `ai_tasks.agent_id`，工具停用时拒绝发起。

## 二、DoD 逐条核对

| DoD | 要求 | 实现 | 验证方式 | 结论 |
|-----|------|------|---------|------|
| D1 | 工具注册表查询返回名称/标识/绑定 Agent/状态/模型参数概要 | `GET /api/v1/ai-tools` → `toToolListItem` 返回 `bound_agent` 概要 | 单测 `listTools` + e2e「种子工具 4」 | ✅ |
| D2 | 为工具配置执行 Agent 与模型参数，保存后持久化 | `PATCH /ai-tools/:toolId` + `AgentService.updateTool` | 单测（改名/启停/绑定）+ e2e「更新工具」+ 浏览器绑定持久化 | ✅ |
| D3 | 配置变更即生效，新任务写入 `agent_id` | `createTask` 步骤 0/2.5 | 单测「发起任务写 agent_id」「未绑定回退默认 Agent」 | ✅ |
| D4 | 工具停用后发起任务 409「已停用」 | `resolveToolForTask` 抛 `ConflictException` | 单测「停用工具发起 409」 | ✅ |
| D5 | 同刻仅一个默认 Agent，默认必须启用 | 唯一部分索引 + `clearOtherDefaults` + 禁停用默认 | 单测「默认互斥」「禁默认 409」 | ✅ |

| D7 | 配置变更写审计 | `auditService.record`（agent_create / agent_update / agent_delete / ai_tool_update） | 单测断言 + e2e 链路 | ✅ |
| D8 | 401/403/404/409/422 | SessionGuard / CsrfGuard / ZodValidationPipe / 业务异常 | e2e 8 项全覆盖（401/403/422/409/404） | ✅ |
