## 一、档案说明

本档案记录 M3c-3「知识库」从需求澄清到交付的证据链。当前 F1 需求澄清与 F2 技术方案均已定稿；D01~D30 已定义，尚无实施证据。

命名与顺序沿用 M3c 统一口径：

**M3c-1 剧情（含 C11~C13 自动建树）→ M3c-2 角色版图 → M3c-3 知识库。**

本段聚焦全局素材库与作品内引用的双层结构、五种条目类型的自动结构化入库、四维检索与标签管理、灵感关联、Markdown 导入导出与整库备份。旧 F5 仅作为需求基线，只有本次明确选择的内容才进入本段承诺。

## 六、F2 技术方案要点

| 决策点 | 结论 | 影响 |
| --- | --- | --- |
| 结构化执行 | 异步作业 + SSE，原文先行入库，结构化回填 | 新增独立 `knowledge-jobs` 队列与事件表，不改动 `ai_tasks` |
| 灵感相似度 | 向量嵌入 + `pgvector`，余弦距离取前 3 | Postgres 镜像需切换为 `pgvector/pgvector:pg16`，CI 与部署手册同步 |
| 整库备份 | 版本化 JSON + gzip（`schema_version=1`） | 合并恢复按标题 + 内容哈希判重，预览与提交两阶段 |
| 文件解析 | `multer` + `mammoth` + `unpdf` + `iconv-lite` | 单文件 ≤20 MB，解析后只存文本，不保存原始二进制 |
| 检索 | 服务端四维检索 + `pg_trgm` + 游标分页；时间支持创建与更新字段 | 500/2000 条规模目标 1 秒内返回 |
| 大纲验收 | 接真实文本模型，抽样 10 条 ≥8 条可直接使用作为上线门禁；Mock 仅用于 CI | 需模型凭据与调用预算，不绑定厂商 |
| 失效引用 | 删除前逐条另存完整副本；删除后按快照另存为截断摘录 | 快照只作兜底，界面明确标注「摘录」 |

三项评审项已于 2026-11-21 关闭，结论见 [技术方案第十二节](./02-技术方案.md#十二风险与评审记录)。
