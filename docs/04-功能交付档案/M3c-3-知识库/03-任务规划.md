层间硬约束：

1. **L0 未冻结，L1 不动手**：字段、枚举、错误码、游标编码与文件格式先定，避免迁移返工。
2. **L1 未回滚验证，L2 不写事务**：迁移必须同时验证 up 与 down，空库与存量库各一遍；`vector` / `pg_trgm` 扩展创建成功且 down 不删扩展。
3. **L2 未通过真实库集成，L3 不接 controller**：尤其是结构化回填、向量 top-k、引用快照、备份合并、导入五类多表事务。
4. **L3 未闭环，L4 不做真实联调**：前端可先用契约类型与 mock 推进 T28/T29，但 T30 之后依赖真实响应。
5. **L5 不替代各层自测**：回归任务验证的是「跨模块影响」，不能用来补做本层单测。
6. **旧一代代码先处置后重建**：重建以 T01~T05 改写/新增为起点，旧 `knowledge/` 目录在 T27 旧端点别名落地前保持可编译，避免中间态构建失败。
