## 一、用户诉求（非技术语言）

> 创作者希望：**把小说里所有角色之间的关系用一张图摆出来，谁认识谁、谁和谁敌对、谁是谁的盟友，一眼看明白。角色我可以手动加（名字、身份、属性系统自动生成），也可以让 AI 从我写好的正文里自己把角色和关系认出来。图上能按国家、信仰、阵营分类筛选，点谁就跳进谁的专属详情页，详情页里能看这个角色一路的成长线——每个剧情节点他什么状态、和谁关系变了。手机上、平板上、电脑上都要好用，图要流畅不卡。**

## 二、功能范围（做什么）

### 2.1 角色总览可视化关系图谱

- 以**力导向图**（或同等级可视化方案）直观呈现全部角色的人际关联拓扑。
- 完整支持**节点拖拽、画布缩放、平移**等基础交互，操作流畅无卡顿。
- 全链路角色管理：
  - **手动新增角色**：系统自动随机生成姓名、身份、属性等基础设定（可二次编辑）。随机生成字段明细见 **§2.6 随机生成字段规格**。
  - **建立角色关联**：关联建立时**同步双向更新**关联双方的关系信息，保证数据一致。
  - **删除角色**：同时把**涉及该角色出场/台词的相关章节段落文本自动标红**（按「含角色名/台词归属该角色」粒度定位，非整章标红，避免误伤无关章节）；同步删除该角色对应的**个人独立剧情**；自动清理该角色**所有关联关系**，无残留脏数据。
- **AI 角色版图自动生成**：从已有小说文本自动提炼角色实体、识别角色关系、一键生成完整角色图谱；生成过程提供**进度提示**；生成结果支持**二次编辑调整**。

### 2.2 多维度分类筛选系统

- 支持按**国家/地域、信仰、阵营、种族、职业、年龄段**等预设维度对角色进行分组展示与聚合。
- 支持多维度条件的**组合筛选**。
- 筛选结果**实时同步**更新到图谱界面。
- **高亮**符合条件的角色节点与关联关系；不符合条件的节点自动**置灰或隐藏**，视觉区分清晰。

### 2.3 角色节点交互跳转

- 图谱中所有角色节点绑定**标准点击事件**。
- 点击任意角色节点 → **路由跳转**至该角色专属详情页面。
- 完整传递**角色 ID、基础属性、关联关系**等全部上下文参数，详情页**直接加载对应数据，无需二次请求**。

### 2.4 角色详情页 · 角色成长线模块

- 完整呈现该角色参与的**所有剧情节点**。
- 严格按**剧情时间线顺序**展示角色在不同剧情阶段的**人物状态变化、关联关系演变、整体成长轨迹**。
- 支持**逐段浏览、节点快速定位、历史回溯**查看。
- 点击任意剧情节点 → **直接跳转**至对应章节位置。

### 2.5 性能与适配

- 全链路**响应式适配**：桌面端、平板端、移动端不同尺寸下图谱交互流畅度与筛选功能完整可用。
- 数据加载、图谱重绘、状态切换操作控制在 **100ms 响应阈值**内。
- 内存占用保持在合理区间。

### 2.6 随机生成字段规格（手动新增）

系统随机生成以下基础字段，生成后可在编辑面板二次修改：

| 字段 | 生成规则 | 示例 |
| --- | --- | --- |
| 姓名 | 从内置姓名库随机组合（姓+名），支持自定义 | 「林晚风」 |
| 身份 | 预设身份池随机（主角/反派/配角/导师/宿敌…） | 「反派」 |
| 年龄 | 16-70 随机整数 | 34 |
| 性别 | 男/女/未定 随机 | 女 |
| 性格 | 从大五人格/性格特质池抽取 2-3 个 | 「冷静、果决」 |
| 经历 | 从经历模板池抽取 1 段 | 「曾被灭门，隐姓埋名十年」 |
| 国家/地域 | 预设地域池随机 | 「东陵国」 |
| 信仰 | 预设信仰池随机（可为「无」） | 「天穹教」 |
| 阵营 | 预设阵营池随机 | 「联盟」 |
| 种族 | 预设种族池随机 | 「人族」 |
| 职业 | 预设职业池随机 | 「剑修」 |
| 年龄段 | 由年龄自动归档（少年/青年/中年/老年） | 「青年」 |
| 属性 | 随机基础数值（力量/敏捷/智力/魅力等 0-100） | `{力量: 62, 敏捷: 78}` |

> 字段池可配置（`config/role_map_pools.json`），支持扩展自定义，保证随机结果可复现（随机种子）。

## 三、功能边界（不做什么 / 允许什么 / 条件触发）

### 3.1 不做什么（禁止）

| 禁止 | 说明 |
| --- | --- |
| 不修改角色基础数据模型 | 角色版图只读取/关联现有角色数据（P3 role_store），不另立角色存储 |
| 不重写现有剧情树/章节逻辑 | 删除角色时仅通过既有章节接口做「标红 + 清剧情」，不复制实现 |
| 不做实时多人协同编辑图谱 | 单用户编辑图谱，不做 WebSocket 多人同步（协同走 P5 协同模块） |
| 不自动持久化到数据库 | 沿用 JSON 文件存储（预留 SQLite 迁移），图谱数据随项目文件 |

### 3.2 允许什么

| 允许 | 说明 |
| --- | --- |
| 手动新增/编辑/删除角色及关系 | 图谱是角色关系的一等编辑入口 |
| AI 抽取后二次编辑 | AI 生成结果可人工增删改角色与关系 |
| 多维度组合筛选 | 国家/信仰/阵营/种族/职业/年龄段可任意组合 |
| 节点跳转详情页 | 传递完整上下文，详情页免二次请求 |

### 3.3 条件触发

| 条件 | 触发动作 |
| --- | --- |
| 删除角色时 | 弹出二次确认 → 确认后：相关章节段落标红（按角色出场/台词粒度）+ 清独立剧情 + 清关联关系（全链路原子操作） |
| 建立关联时 | 同步更新双方关系列表（A→B 与 B→A 双向一致） |
| AI 生成时 | 进度提示分阶段（提取实体 → 识别关系 → 构建图谱） |
| 筛选变化时 | 实时高亮/置灰节点与关系 |

## 四、交互与流程

### 4.1 手动新增角色流程

```
点击「新增角色」→ 系统随机生成姓名/身份/属性 → 弹出编辑面板（可改）→ 确认保存 → 图谱新增节点 → 可立即拖拽定位 / 建关联
```

### 4.2 建立关联流程

```
选中节点 A → 拖拽/点击「建立关联」→ 选择目标节点 B → 选择关系类型（盟友/敌对/师徒/亲属/同事…）→ 确认 → A→B 与 B→A 双向写入关系列表 → 图谱连边高亮
```

### 4.3 删除角色流程

```
选中节点 → 右键/菜单「删除角色」→ 二次确认弹窗（提示：将标红相关章节、删除独立剧情、清理关联）→ 确认 → 全链路原子清理 → 图谱节点消失、相关连边消失、章节对应文本标红
```

### 4.4 AI 自动生成流程

```
点击「AI 生成角色版图」→ 选择来源（全书/指定章节）→ 启动 → 进度提示（阶段1 提取实体 → 阶段2 识别关系 → 阶段3 构建图谱）→ 完成 → 图谱渲染 → 进入二次编辑态
```

### 4.5 筛选流程

```
选择维度（国家/信仰/阵营）→ 组合条件 → 图谱实时高亮匹配节点+关系、置灰非匹配 → 取消条件恢复全量
```

### 4.6 节点跳转流程

```
点击图谱节点 → 携带角色ID+属性+关联关系上下文 → 路由跳转 /roles/<id> → 详情页直接渲染（免二次请求）→ 成长线模块按时间线加载剧情节点
```

### 4.7 成长线浏览流程

```
详情页进入「成长线」Tab → 按剧情时间线顺序展示节点 → 逐段浏览（上/下段）→ 节点快速定位（时间线刻度点击）→ 历史回溯（回到任意已完成节点）→ 点击节点 → 跳转对应章节位置
```

## 六、风险与依赖

| 项 | 说明 |
| --- | --- |
| 依赖角色数据 | 需 P3 角色 Agent 体系 role_store 已建角色；图谱读取 `Role` 实体 + 关系字段 |
| 依赖章节数据 | 删除角色标红需章节内容接口；成长线跳转需章节位置锚点 |
| 依赖剧情节点 | 成长线数据来自 F7 剧情树节点（PlotNode 时间线） |
| 100 节点性能 | 力导向图 O(n²) 布局，需按节点数分级（<50 全量物理模拟，50-100 简化/WebGL 加速） |
| 移动端交互 | 拖拽/缩放手势需与页面滚动区分，防误触 |

## 七、与既有功能的关系

| 既有功能 | 关系 |
| --- | --- |
| F5 知识库 | 角色属性可引用知识库条目（只读） |
| F6 剧情推衍 | 角色关系影响推衍上下文（只读注入） |
| F7 剧情树 | 成长线模块读取 PlotNode 时间线；删除角色联动清剧情树该角色节点 |
| 章节管理 | 删除角色联动标红章节文本 |
| 角色 Agent（P3） | 图谱角色 = 角色 Agent 体系同一角色，不另立 |
