## 三、验证方法说明

1. **服务器**：Flask（`python app.py`）监听 5000，基准图谱 API 返回 100 节点 + 150 边。
2. **浏览器驱动**：真实（非 headless）浏览器 + `--remote-debugging-port=9333` + Node CDP 客户端（`ws` 包）。
3. **精确选择器**：点击 `#role-map-entry .rmp-btn`（此前用 `button,div,span` 泛匹配命中错误元素导致面板未挂载，已修正）。
4. **指标采集**：`svg.rmp-svg` 内 `circle`/`line` 计数；`Network.responseReceived` 记录 graph 请求状态码；`Runtime.exceptionThrown`/`Log.entryAdded` 记录控制台错误。
5. **截图**：`Emulation.setDeviceMetricsOverride` 设置四分辨率 + `Page.captureScreenshot`。

## 四、遗留事项与建议

1. **Firefox 补测**：若需覆盖 Firefox，建议在安装了 Firefox 的环境补测（复用本报告脚本 `scripts/cdp_tmp/cdp_real.js`，传入 Firefox 路径即可）。
2. **Safari**：Windows 无法本地验证，需 macOS 设备；技术上纯 SVG 无 WebGL 依赖，风险低。
3. **favicon 404**：非功能错误，可选补一个 `favicon.ico` 消除控制台噪音（不在 F8 范围，如需可另开任务）。
4. **验收口径**：建议 F8-17 按「Chrome + Edge 双 Chromium 核心 PASS + Firefox/Safari 记录环境缺失」判定为**通过（附说明）**，F8-18 判定为**通过**。
