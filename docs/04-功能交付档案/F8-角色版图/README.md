## 四、功能说明

- **功能名**：角色版图
- **核心目标**：以可视化关系图谱呈现小说全部角色的人际关联拓扑，支持全链路角色管理（新增/关联/删除）、AI 从小说文本自动生成角色版图、多维度分类筛选、角色节点点击跳转详情页、详情页角色成长线模块，并满足全设备响应式与 100 节点 60fps 性能要求。
- **涉及代码**：`modules/role_map/`（服务层）、`plot` 关联角色数据、`static/js/role_map_panel.js`（图谱渲染）、`static/js/role_detail.js`（详情页成长线）、`static/css/role_map.css`（见 02-技术方案.md）。
