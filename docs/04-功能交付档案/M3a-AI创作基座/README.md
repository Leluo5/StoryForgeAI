## 一、档案说明

本档案记录 M3a AI 创作基座功能从需求澄清到上线的完整证据链。M3a 是 M3「AI 创作」的第一个子里程碑，聚焦**最小 AI 创作闭环**：任务队列与执行、SSE 进度推送、AI 生成待审修订集（复用 M2 的 `revision_set` ai_set 载体）。

核心诉求：作者发起 AI 创作任务后，任务可追踪、可重试、不重复产生有效结果；AI 只生成**待审修订**，作者逐条或批量接受后才落入正文，不静默覆盖人工未确认内容。

M3 后续子里程碑：M3b（Agent 与工具）、M3c（剧情/角色/知识），不在本档案范围。
