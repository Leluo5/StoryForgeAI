## 一、用户诉求（非技术语言）

> 创作者希望：**把整个故事的剧情脉络做成一棵树，节点就是一个个剧情点，线就是它们之间的先后关系。可以从我写的大纲自动生成，也可以从我已有的小说文本里自动梳理出来。树上我能拖、能缩放、能搜、能改，还能把某个节点直接丢进剧情推衍聊天室当起点，推衍完的结果自动长回这棵树上。**

### 1.1 要解决的核心痛点

- 剧情一多就乱，前后逻辑理不清，不知道哪个情节在前哪个在后。
- 手动梳理剧情结构费时费力，大纲和正文对不上。
- 剧情推衍与整体剧情结构脱节，推衍完的结果没法接回主线。
- 剧情树只能在编辑器里看，数据不能迁移、不好复用。

### 1.2 期望的完整体验

```text
创作者进入剧情树页面
  → 选择生成模式：
     ├─ 基于小说大纲 → 自动提取生成剧情树
     └─ 基于现有小说文本 → 智能解析生成剧情树
  → 剧情树视图展示（节点 + 关联连线）
  → 可视化操作：新增/删除/编辑节点、配置关联
  → 可拖拽调整、缩放查看、节点搜索、导出导入
  → 选中某节点 → 作为剧情推衍聊天室起始上下文
  → 推衍结束 → 自动回写为新剧情节点，对接关联到原节点下
```

## 二、功能边界

### 2.1 包含（In Scope）

| # | 能力 | 说明 |
|---|------|------|
| 1 | 大纲自动生成 | 基于用户输入的小说大纲自动提取生成剧情树 |
| 2 | 小说文本解析生成 | 基于已导入的现有小说文本智能解析生成剧情树结构 |
| 3 | 节点可视化操作 | 手动新增节点、删除节点、编辑节点内容与属性 |
| 4 | 多类型关联配置 | 前置后置线性关联（有先后顺序）、无先后顺序的非线性关联 |
| 5 | 关联样式区分 | 线性/非线性关联在剧情树视图中以不同样式的连接线展示 |
| 6 | 聊天室联动入口 | 剧情推衍聊天室开放剧情树节点选择入口，选取节点作为推衍起始上下文 |
| 7 | 推衍结果回写 | 推衍结束后自动生成新剧情节点，对接关联到原选中节点下，同步更新剧情树 |
| 8 | 视图操作 | 拖拽调整、缩放查看、节点搜索 |
| 9 | 数据迁移 | 剧情树导出导入（可迁移、可复用） |

### 2.2 不包含（Out of Scope）

- ❌ 自动生成完整剧情正文（剧情树只负责结构，正文由推衍/创作生成）。
- ❌ 跨作品剧情树合并（当前单作品一棵树）。
- ❌ 节点级权限控制（当前单创作者本地）。
- ❌ 动画式剧情回放（当前为静态树视图）。

## 三、功能流程

### 3.1 生成模式一：基于小说大纲

```text
创作者输入小说大纲（章节/情节概要文本）
  → 自动提取生成剧情树结构
  → 识别关键剧情节点（如「初遇」「冲突升级」「真相揭露」「结局」）
  → 依据大纲顺序建立节点间前后关联
  → 生成剧情树视图预览 → 可编辑确认入库
```

### 3.2 生成模式二：基于现有小说文本

```text
选择已导入的现有小说文本
  → 智能解析剧情脉络
  → 提取剧情节点（按章节/情节段落）
  → 识别节点间逻辑关系（前后置/并列/分支）
  → 生成剧情树结构 → 可编辑确认入库
```

### 3.3 节点可视化操作

```text
剧情树视图
  → 新增节点：右键/工具栏 → 输入节点内容与属性 → 落点
  → 删除节点：选中节点 → 确认删除（级联处理关联连线）
  → 编辑节点：双击节点 → 修改内容/属性 → 保存
  → 配置关联：选中节点 → 建立前置后置线性关联 / 非线性关联
```

### 3.4 聊天室联动与推衍回写

```text
剧情推衍聊天室
  → 开放剧情树节点选择入口
  → 用户选取某剧情树节点作为推衍起始上下文
  → 推衍进行（F6 步骤化推衍）
  → 推衍结束 → 系统自动：
       ├─ 将推衍生成内容作为新剧情节点
       ├─ 对接关联到原选中的剧情树节点下
       └─ 同步更新剧情树结构
  → 剧情树视图自动刷新，新节点可见
```

### 3.5 视图操作与数据迁移

```text
剧情树视图
  → 拖拽节点调整布局（位置实时更新）
  → 缩放查看（滚轮放大/缩小、适应视图）
  → 节点搜索（按关键词/属性过滤定位）
  → 导出剧情树（JSON 结构）
  → 导入剧情树（从 JSON 恢复，校验结构）
```

## 五、异常与边界处理

| 场景 | 处理 |
|------|------|
| 大纲过短/无情节 | 提示补充大纲内容，拒绝生成 |
| 小说文本解析失败 | 提示重试，或降级为手动建树 |
| 删除节点有关联 | 提示确认级联删除关联连线 |
| 关联形成环 | 检测到环路，提示并禁止建立 |
| 推衍回写节点冲突 | 检测重名/重复节点，合并或提示 |
| 导入 JSON 结构非法 | 校验失败提示，不覆盖现有剧情树 |
| 搜索无结果 | 显示空态 + 建议放宽条件 |
| 拖拽超出边界 | 限制在画布范围内 |

## 六、数据字段说明（概念模型）

### 6.1 剧情树（plot tree）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 剧情树唯一 id |
| `title` | string | 剧情树标题 |
| `source` | enum | outline/novel_text/manual |
| `nodes` | array | 剧情节点列表 |
| `links` | array | 关联关系列表 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |

### 6.2 剧情节点（plot node）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 节点唯一 id |
| `label` | string | 节点标题 |
| `content` | text | 节点内容 |
| `attributes` | object | 节点属性（时间节点/角色/状态等） |
| `position` | object | 画布坐标（x/y） |
| `created_from` | enum | manual/outline/novel_text/derivation |

### 6.3 关联关系（plot link）

| 字段 | 类型 | 说明 |
|------|------|------|
| `source_id` | string | 前置节点 id |
| `target_id` | string | 后置节点 id |
| `type` | enum | linear（前置后置）/ non_linear（无先后顺序） |
| `label` | string | 关联说明（可选） |

## 七、相关依赖与约束

- **依赖**：`plot_tree.py`（剧情树引擎）、`plot_parser.py`（大纲/小说文本解析器）、`plot_visualizer.js`（可视化渲染）；与 F6 剧情推衍聊天室双向联动（节点选择入口 + 推衍回写）。
- **约束**：剧情树结构须可序列化为 JSON（导出导入用）；关联关系禁止形成环路（须环检测）；节点坐标独立维护，拖拽只更新位置；推衍回写须原子性（生成节点 + 建立关联 + 刷新视图，任一失败整体回滚）。
- **前置**：需先完成 F6 剧情推衍聊天室；小说文本来自 F5 知识库或导入；角色库来自改造路线图 P3 角色 Agent 体系。
