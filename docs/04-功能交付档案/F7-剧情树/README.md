## 四、功能说明

- **功能名**：剧情树
- **核心目标**：以树状结构组织剧情节点，支持从大纲/现有小说自动生成，提供可视化操作（新增/删除/编辑）、多类型关联（前置后置/非线性）、拖拽缩放搜索导出，并与剧情推衍聊天室（F6）双向联动。
- **涉及代码**：`app.py`（新增路由）、`plot_tree.py`（剧情树引擎）、`plot_parser.py`（生成解析器）、`plot_visualizer.js`（可视化视图）、`static/js/plot_tree_panel.js`（交互面板，见 02-技术方案.md）。
