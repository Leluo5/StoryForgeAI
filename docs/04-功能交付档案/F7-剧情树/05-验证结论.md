## 四、风险与遗留

| 项 | 说明 | 处理 |
|----|------|------|
| LLM 生成质量 | 树结构逻辑性依赖智能体 | 生成后人工校对 + 待确认态（DoD #2） |
| F5 拆文对接 | 生成模式二依赖 F5 拆文 | 数据经注入传递，F5 可用后直接对接 |
| Canvas 大节点量 | 渲染性能 | 节点量预警 + 分层渲染（LOD）后续增强 |
| 导入覆盖 | replace 模式 | 校验失败不覆盖，前端确认后执行 |
