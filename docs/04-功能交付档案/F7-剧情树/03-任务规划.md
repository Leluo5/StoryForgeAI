## 二、任务清单

### 阶段 A · 数据层

**F7-T1 数据模型与存储（`plot_tree.py`）** — 高优先级 · ★
- 实现 `plot_tree`/`plot_node`/`link` 模型（§2.1–§2.3 技术方案）、`data/plot/<tree_id>.json` 持久化。
- 实现 CRUD：`create_tree` / `load_tree` / `save_tree` / `list_trees`。
- 完成标准：单测覆盖 create/load/save/list；原子写。

### 阶段 B · 引擎层

**F7-T2 生成解析器（`plot_parser.py`）** — 高优先级 · ★
- 实现 `parse_outline`（大纲→树）+ `parse_novel`（拆文→树），统一产出 `plot_tree`；生成待确认态。
- 完成标准：单测覆盖两种模式 + 来源缺失 400 + 待确认态；mock LLM。

**F7-T3 树操作引擎（`plot_tree.py`）** — 高优先级 · ★
- 实现 `add_node` / `edit_node` / `delete_node`（级联子节点 + 清 links）/ `add_link`（自环校验）。
- 完成标准：单测覆盖增删改 + 级联 + 自环 400 + 前置/后置/非线性。

**F7-T4 双向联动（`plot_tree.py`）** — 中优先级
- 实现 `push_to_room`（树→推衍上下文注入）+ `pull_from_room`（推衍回写新节点，`linked_room_id` 标记，id 去重）。
- 完成标准：单测覆盖 push/pull + 去重合并 + 来源缺失校验。

**F7-T5 导入导出（`plot_tree.py`）** — 中优先级
- 实现 export（全量/单节点子链）+ import（结构校验合并/覆盖）。
- 完成标准：单测覆盖 export 全量/单节点、import 合法/非法结构。

### 阶段 C · 接口层

**F7-T6 接口层（`app.py` 新增路由）** — 高优先级 · ★
- 实现 §3.1–§3.11 全部路由（trees CRUD / generate / nodes / links / layout / sync-room / export / import）。
- 完成标准：Flask 路由单测覆盖全部端点（含 400/404 异常路径）。

### 阶段 D · 表现层

**F7-T7 可视化视图（`plot_visualizer.js`）** — 高优先级 · ★
- 实现 Canvas 渲染（节点按 type 着色、关联线按 type 样式）+ pan/zoom/drag_node + search 高亮聚焦 + save_layout 节流。
- 完成标准：浏览器验证拖拽/缩放/搜索/节点着色；布局保存。

**F7-T8 前端树列表与节点操作（`plot_tree_panel.js`）** — 中优先级
- 实现树列表侧栏 + 生成入口（两种模式待确认态）+ 节点新增/编辑/删除。
- 完成标准：浏览器验证生成待确认、节点增删改、级联确认。

**F7-T9 前端联动与导入导出（`plot_tree_panel.js`）** — 中优先级
- 实现联动面板（push/pull 开关 + 回写标记）+ 导入导出工具栏。
- 完成标准：浏览器验证 push/pull、导出下载、导入合并。

### 阶段 E · 验收

**F7-T10 单元测试与联调** — 高优先级 · ★
- 汇总 F7-T1~T9 单测；DoD #1~#12 逐条核对；与 F5/F6 联调。
- 完成标准：全部单测通过；DoD 对照表逐条核对；README 更新。
