## 一、方案概述

本功能是创作端的**剧情组织中枢**：以树状结构组织剧情节点，支持从大纲/现有小说自动生成、节点可视化操作、多类型关联、与剧情推衍聊天室（F6）双向联动、推衍回写，以及拖拽/缩放/搜索/导出。核心是「数据引擎 → 生成解析器 → 可视化视图 → 关联渲染 → 导入导出」五层。

### 1.1 方案选型

| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 数据引擎 | 后端 `plot_tree.py`（JSON 持久化） | 内存 | 需持久化 + 与 F6 联动，后端权威 |
| 生成解析器 | 后端 `plot_parser.py` 走 Coze 智能体 | 前端 | 集中错误处理，复用 coze_client |
| 可视化视图 | `plot_visualizer.js`（Canvas/SVG） | D3 | 自绘可控依赖，树 + 关联图轻量 |
| 拖拽/缩放 | 自实现（canvas transform） | 第三方库 | 避免重型依赖，树布局简单 |
| 关联渲染 | 节点-节点连线 + 类型标签 | 列表 | 直观呈现前置后置/非线性 |
| 导入导出 | JSON 全量 + 单节点 | 文本 | 满足 DoD #8 搜索导出 |

## 二、数据模型（对齐需求澄清 §六）

### 2.1 剧情树 `plot_tree`（`data/plot/<tree_id>.json`）

```json
{
  "id": "tree_01xxx",
  "name": "雾都疑案主线",
  "root_node_id": "pn_root",
  "nodes": [
    { "id": "pn_root", "label": "开端", "type": "start", "content": "...", "parent_id": null }
  ],
  "links": [
    { "from": "pn_1", "to": "pn_2", "type": "前置|后置|非线性", "note": "可选" }
  ],
  "created_at": "2026-11-10T10:30:00",
  "updated_at": "2026-11-10T10:35:00"
}
```

### 2.2 节点 `plot_node`

```json
{
  "id": "pn_1",
  "label": "初遇",
  "type": "start|main|branch|turn|climax|end",
  "content": "剧情正文/摘要",
  "parent_id": "pn_root",
  "children_ids": ["pn_2"],
  "source": "generated|manual|outline_sync",
  "linked_room_id": "room_01xxx",
  "position": { "x": 120, "y": 200 },
  "tags": ["主线"]
}
```

### 2.3 关联类型 `link`

| type | 含义 | 渲染 |
|------|------|------|
| 前置 | from 在 to 之前 | 实线 + 箭头 |
| 后置 | from 在 to 之后 | 虚线 + 箭头 |
| 非线性 | 跳过/回环 | 曲线 + 标签 |

## 三、API 设计

### 3.1 `POST /api/plot/trees` — 创建剧情树

**请求体**：`{ "name": "雾都疑案主线", "source": "outline|novel|empty" }`

**响应 200**：`{ "tree_id": "tree_01xxx" }`

### 3.2 `POST /api/plot/trees/<id>/generate` — 自动生成（两种模式）

**请求体**：
```json
{
  "mode": "outline|novel",
  "source_ref": "k_01xxx",   // 大纲模式：知识库大纲条目
  "novel_ref": "k_02xxx"     // 小说模式：小说拆文条目
}
```

**响应 200**：`{ "tree_id": "tree_01xxx", "nodes": [...], "links": [...], "generated_at": "..." }`

> 生成结果进入**待确认态**，前端可全选/局部采纳或放弃（DoD #1 两种模式 + 生成后操作）。

### 3.3 `GET /api/plot/trees` / `GET /api/plot/trees/<id>` — 列表 / 详情

- 列表：`{ "trees": [{ id, name, nodes_count, updated_at }] }`
- 详情：完整 `plot_tree`（nodes + links）。

### 3.4 `POST /api/plot/trees/<id>/nodes` — 新增节点

**请求体**：`{ "parent_id": "pn_1", "label": "新节点", "type": "branch", "content": "..." }`

**响应 200**：`{ "node": {...plot_node} }`

### 3.5 `PUT /api/plot/trees/<id>/nodes/<node_id>` — 编辑节点

**请求体**：`{ "label", "content", "type", "tags" }` 任意子集

**响应 200**：`{ "node": {...} }`

### 3.6 `DELETE /api/plot/trees/<id>/nodes/<node_id>` — 删除节点（级联子节点）

**响应 200**：`{ "deleted": true }`（子节点级联删除 + 关联清理）

### 3.7 `POST /api/plot/trees/<id>/links` — 建立关联

**请求体**：`{ "from": "pn_1", "to": "pn_2", "type": "前置|后置|非线性", "note": "" }`

**响应 200**：`{ "link": {...} }`

### 3.8 `PUT /api/plot/trees/<id>/layout` — 保存布局（拖拽/缩放）

**请求体**：`{ "nodes": [{ "id": "pn_1", "position": {"x":120,"y":200} }] }`

**响应 200**：`{ "saved": true }`

### 3.9 `POST /api/plot/trees/<id>/sync-room` — 与聊天室联动

**请求体**：`{ "room_id": "room_01xxx", "action": "push|pull" }`

- `push`：把剧情树节点推给聊天室作为推衍上下文（关联前置/分支节点）。
- `pull`：把聊天室推衍结果回写到剧情树新节点（DoD 推衍回写）。
- **响应 200**：`{ "synced": true, "new_nodes": [...] }`

### 3.10 `GET /api/plot/trees/<id>/export` — 导出（全量/单节点）

**查询参数**：`scope=all|node&node_id=pn_1&format=json`

**响应 200**：文件下载（JSON）。全量含 nodes+links；单节点含该节点及子链。

### 3.11 `POST /api/plot/trees/<id>/import` — 导入

**请求体**：`{ "data": {...plot_tree 子集...} }`

**响应 200**：`{ "tree_id": "tree_01xxx", "nodes_count": n }`

## 四、核心逻辑

### 4.1 生成解析器（`plot_parser.py`）

```python
def parse_outline(kb_entry_id):
    outline = load_outline(kb_entry_id)   # 来自 F5 knowledge_outline
    tree = llm_outline_to_tree(outline)   # 章节/情节节点 → 树结构
    return tree

def parse_novel(kb_entry_id):
    entry = load_entry(kb_entry_id)
    tree = llm_novel_to_tree(entry["structured"])  # 拆文 → 树
    return tree
```

- 两种模式产出统一 `plot_tree` 结构。
- 生成结果待确认态：前端确认前不入主数据，`generate` 返回候选集。

### 4.4 双向联动（F6 ↔ F7）

```python
def push_to_room(tree_id, room_id):
    nodes = get_context_nodes(tree_id)   # 前置/分支节点 → 推衍上下文
    story_thread.inject_context(room_id, nodes)
    return {"injected": len(nodes)}

def pull_from_room(tree_id, room_id):
    steps = story_thread.get_uncommitted_steps(room_id)  # 推衍回写
    new_nodes = [room_step_to_node(s) for s in steps]
    tree["nodes"].extend(new_nodes)
    save(tree)
    return {"new_nodes": new_nodes}
```

- 推衍回写：F6 每一步确认后，可回写为剧情树新节点（`linked_room_id` 标记来源）。
- 联动方向可切换（push/pull），冲突合并按节点 id 去重。

### 4.5 搜索与导出

- 搜索：节点 `label`/`content` 全量模糊匹配 + 高亮 + 聚焦（`plot_visualizer.search`）。
- 导出：`export` 序列化 `plot_tree` 为 JSON；单节点导出含子链（`descendants`）。
- 导入：校验结构（nodes/links 合法性）后合并或覆盖。

## 五、异常处理（对齐需求澄清 §五）

| 场景 | 处理 | 方案落点 |
|------|------|---------|
| 生成来源为空 | 400「请先在大纲/拆文中生成内容」 | 3.2 source_ref 校验 |
| 生成结果不满意 | 放弃/局部采纳 | 3.2 待确认态 |
| 节点自环 | 400「不允许自环」 | 4.2 add_link 校验 |
| 删除含子节点 | 级联删除确认 | 4.2 delete_node 级联 |
| 联动来源缺失 | 提示先创建聊天室/剧情树 | 3.9 前置校验 |
| 布局未保存离开 | 前端确认弹窗 | 4.3 交互层 |
| 导入结构非法 | 400「结构不合法」 | 4.5 import 校验 |
| 搜索无结果 | 空态提示 | 4.5 search 返回空 |
