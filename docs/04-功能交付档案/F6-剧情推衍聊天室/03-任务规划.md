## 二、任务清单

### 阶段 A · 数据层

**F6-T1 数据模型与存储（`story_engine.py::init_room`）** — 高优先级 · ★
- 实现 `story_room` 模型（§2.1 技术方案）、`history` 结构、实例创建 `create_room`。
- 完成标准：单测覆盖 init/字段校验/必填校验（场所/背景）。

### 阶段 B · 引擎层

**F6-T2 推衍状态机（`story_engine.py::advance_step`）** — 高优先级 · ★
- 实现 idle/running/paused/finished 状态流转；`build_context` + `llm_generate_step` + 步结果记录 + `status=paused`（一步一断）。
- 完成标准：单测覆盖状态流转、无角色校验、生成失败保持 paused。

**F6-T3 随机度系统（`random_system.py`）** — 中优先级 · ★
- 实现 `roll_event`（概率事件池按 background 匹配）+ `roll_enter`（角色池按阵营/关联度 + 去重）。
- 完成标准：单测覆盖概率触发/不触发、去重、配置实时调（DoD #11）。

**F6-T4 多线程隔离（`story_thread.py`）** — 高优先级 · ★
- 实现 `_rooms`/`_room_locks` + `with_room` 实例级锁；`MAX_ROOMS=10` 超限 409。
- 完成标准：单测并发创建/操作隔离（两实例零共享）、超限 409。

**F6-T5 分支生成（`story_engine.py::llm_gen_branches`）** — 中优先级
- 实现 LLM 生成 2-4 个分支选项，符合上下文；非法/重复提示重选。
- 完成标准：单测覆盖分支生成 + 冲突分支提示；mock LLM。

### 阶段 C · 接口层

**F6-T6 接口层（`app.py` 新增路由）** — 高优先级 · ★
- 实现 §3.1–§3.9 全部路由（rooms CRUD / step / continue / characters / stream / config / delete）。
- 完成标准：Flask 路由单测覆盖全部端点（含 400/404/409 异常路径）。

**F6-T7 SSE 流式接口（`/api/story/rooms/<id>/stream`）** — 中优先级
- 实现 SSE 推送 generating/rolling/delta/done 阶段。
- 完成标准：SSE 客户端单测验证事件序列；断连恢复 paused。

### 阶段 D · 表现层

**F6-T8 前端配置与角色管理（`story_panel.js`）** — 中优先级
- 实现配置表单（场所/背景/时间节点/前置/关联剧情）+ 角色库勾选 + 随机入场开关。
- 完成标准：浏览器验证配置保存回显、角色拉入、随机入场开关。

**F6-T9 前端聊天室与一步一断（`story_panel.js`）** — 高优先级 · ★
- 实现推衍面板 + 步结果渲染（事件标记/新角色）+ 编辑区 + 分支按钮组 + continue 确认。
- 完成标准：浏览器验证推衍一步即暂停、可修改、分支选择生效。

**F6-T10 前端多线程标签与历史（`story_panel.js`）** — 中优先级
- 实现多实例 Tab + 切换恢复 + 历史折叠分页 + 未保存确认弹窗。
- 完成标准：浏览器验证多 Tab 切换、历史折叠、未保存提示。

### 阶段 E · 验收

**F6-T11 单元测试与联调** — 高优先级 · ★
- 汇总 F6-T1~T10 单测；DoD #1~#12 逐条核对。
- 完成标准：全部单测通过；DoD 对照表逐条核对；README 更新。
