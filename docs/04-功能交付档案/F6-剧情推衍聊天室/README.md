## 四、功能说明

- **功能名**：剧情推衍聊天室
- **核心目标**：创作者设定剧情基础要素，把角色拉入聊天室，以步骤化方式逐步推衍剧情，支持随机意外事件、随机新角色入场、多线程独立运行与一步一断交互。
- **涉及代码**：`app.py`（新增路由）、`story_engine.py`（推衍引擎）、`random_system.py`（随机度系统）、`story_thread.py`（多线程隔离）、`static/js/story_panel.js`（交互面板，见 02-技术方案.md）。
