### 4.2 环境限制说明（非代码缺陷）

| 项 | 限制 | 说明 |
| --- | --- | --- |
| 真实 AI 头像生成 | 环境无 `image_tools.character_workflow_id` | `global_config.json` 无 workflow_id → `bad_gateway`；用预置缓存文件验证链路（幂等缓存命中，属正确行为） |
| 数据限制 | 4 角色阵营各不相同 | 无「两端同阵营」边 → 「主角」筛选无法触发 matched 边场景；改用「华夏」匹配 4/4 覆盖 |
| 导入预览第三展示位 | 代码已确认，未做浏览器实际导入流程 | `novel_editor.js` 行 424-437 监听 + `avaImg.src = det.avatarPath` 在位；环境无浏览器自动化工具，记录为代码层确认 |
| 多分辨率 | 环境无 resize 工具 | SVG 自适应由 CSS `.rmp-panel{inset:0}` + `.rmp-svg{width/height:100%}` 保证，代码层面覆盖 |
| Edge 冒烟 | 环境仅 Chromium 浏览器工具 | 无法切换 Edge 引擎（环境限制） |

## 五、遗留事项与建议

1. **真实 AI 头像生成补测**：接入 `character_workflow_id` 后，建议在真实文生图环境补一次「不同特征 → 不同头像」链路验证（复用 F9-T9 用例，改 mock 为真实调用）。
2. **导入预览实景补测**：具备浏览器自动化工具后，建议进入「从知识库导入」流程实景验证第三展示位（代码已就位，需实际导入触发）。
3. **Firefox/Safari**：纯 SVG + d3-force + 原生事件，无 WebGL 强依赖，风险低；如需覆盖需对应浏览器环境（Windows 无法本地验证 Safari）。
4. **favicon 404**：非功能错误，可选补 `favicon.ico` 消除控制台噪音（不在 F9 范围）。
