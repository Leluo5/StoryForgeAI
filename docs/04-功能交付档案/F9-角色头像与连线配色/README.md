## 四、功能说明

- **功能名**：角色头像与连线配色
- **核心目标**：根据角色特征（性别/发型/发色/面部特征/服饰风格）生成匹配的个性化头像，相同特征组合生成一致头像；调用形象工具创建/修改后实时同步所有展示位；角色版图每条关系连线分配随机唯一颜色，深浅色背景下均清晰可见；兼容现有角色管理交互。
- **涉及代码**：`modules/novel_creation/role_store.py`（Role 模型）、`modules/plot/role_map_service.py`（图谱服务）、`static/js/role_map_panel.js`（连线渲染）、`static/js/novel_editor.js`（角色导入）、`modules/novel_creation/tool_registry.py`（形象工具注册）（见 02-技术方案.md）。
