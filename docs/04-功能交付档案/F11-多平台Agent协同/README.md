## 一、档案说明

本档案记录 F11「多平台 Agent 协同」从需求澄清到交付的证据链。F1~F4 全部完成并已交付。

首期采用 Flowise + FastGPT + n8n：FastGPT 负责独立演示知识库检索，Flowise 负责角色 Agent 执行，StoryForgeAI 负责自动写回与逐字段撤销，n8n 负责结果及引用资料归档。Coze 保留为按 Agent 可切换、可回退的执行通道。

本功能是独立叠加能力，不改变 M0–M5 路线依赖，也不改变 M3a「正文只接受待审修订」的既有门槛。

## 四、已确认范围决策

| 决策点 | 结论 | 依据 |
| --- | --- | --- |
| 组件组合 | Flowise + FastGPT + n8n | 用户确认方案 C |
| 部署 | 三组件统一私有部署，纳入现有 Docker 运维体系 | 用户确认 |
| 模型 | 按 Agent 使用合规外部模型服务，复用现有可用凭据 | 用户确认 |
| 首期角色 | 一个专用测试角色，不操作正式作品 | 用户确认 |
| 检索 | FastGPT 使用独立演示知识库 | 用户确认 |
| 生成 | Flowise 生成指定角色资料字段 | 用户确认 |
| 写回 | 合格结果自动写回白名单字段 | 用户确认 |
| 撤销 | 按字段撤销，并保护写回后的新修改 | 用户确认 |
| 归档 | n8n 自动归档结果与引用资料 | 用户确认 |
| 回退 | Coze 与 Flowise 并存，切换只影响新任务 | 用户确认 |
| 正文边界 | 正文和剧情树不自动写回，正文仍走待审修订 | 既有硬约束 |
| 知识库边界 | 不替换、不同步 M3c-3，不扩张其角色联动 | 用户确认 |
| 验收 | 功能演示通过，不设置量化稳定性硬指标 | 用户确认 |

## 六、F2 技术方案要点

| 决策点 | 结论 | 影响 |
| --- | --- | --- |
| 任务编排 | 复用 `ai_tasks`，新增 `scope='role_profile'` 与 `channel` 列 | 复用既有幂等、状态机、SSE 与审计，不新建任务表 |
| 通道适配 | 统一 `AgentChannel` 端口，Flowise 与 Coze 各一实现 | TS 侧需补齐最小 Coze 适配器，否则回退只有配置没有执行能力 |
| 检索引用 | FastGPT 检索 + `agent_task_citations` 快照 | 零引用直接失败，不进入写回 |
| 写回模型 | 写回单 + 字段行，字段级前后值 | 支撑按字段撤销，不依赖整份角色快照 |
| 撤销判定 | 比对字段当前值与写回后值 | 其他字段变更不会误伤未修改字段 |
| 归档 | `agent_archive_outbox` + 独立 `collab-archive` 队列 | 归档失败只重试归档，不回滚写回 |
| 部署 | 独立 `docker-compose.collab.yml` 与 `collab` profile | 不改变主 Compose 默认启动范围 |
