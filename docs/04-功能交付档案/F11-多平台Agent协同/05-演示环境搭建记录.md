### 2. AIProxy（FastGPT v4.17 强制模型代理）
**关键事实**：v4.17 起所有模型调用（含 embedding）统一经 `AIPROXY_API_ENDPOINT` 代理，**完全忽略 model config 里的 `baseUrl`**。默认占位值 `http://127.0.0.1:3001/aiproxy` 在容器内无监听，导致所有 embedding 报 `Connection error.`。

解决方案（已落地 `infra/docker-compose.collab.yml` + 新增 `infra/nginx/aiproxy.conf`）：

```nginx
server {
    listen 3001;
    location /aiproxy/ {
        proxy_pass http://ollama:11434/;   # 剥掉 /aiproxy 前缀转发到 Ollama OpenAI 兼容端点
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
    location / { return 404 '{"error":"not found"}'; }
}
```

- 新增服务 `aiproxy`（`nginx:1.27-alpine`），healthcheck 打 `/aiproxy/v1/models`
- `fastgpt` 的 `depends_on` 增加 `aiproxy`
- `AIPROXY_API_ENDPOINT` 默认值改为 `http://aiproxy:3001/aiproxy`

**踩坑记录**：`docker compose restart` **不会重载环境变量**，改 env 后必须 `docker compose up -d --force-recreate <svc>`。

**踩坑记录（通过 API 创建 chatflow 时）**：
1. 节点的 `data` **必须自带 `inputParams` 数组**（前端会自动注入，API 创建不会）。缺失时 `resolveVariables` 直接崩溃，报错被吞成 500。
2. `PromptTemplate` 的 `template` 使用 LangChain f-string 语法，JSON 示例里的 `{` `}` 必须转义或避免出现，否则报 `Single '}' in template` / `Missing value for input`。
3. 模板变量 `{{question}}` 需要在 `promptValues` 里映射：`'{"question":"{{question}}"}'`。
4. `overrideConfig` 的覆盖键**必须是节点参数名**（如 `systemMessagePrompt`），其它键名（如 `systemMessage`）会被 `isParameterEnabled` 静默跳过，导致角色上下文全部丢失。
   - 该缺陷已在 `flowise.channel.ts` 修复（`systemMessage` → `systemMessagePrompt`），并补回归单测。

## 二、关键逆向结论（FastGPT v4.17.4 打包代码）

以下结论均来自容器内 `packages_web`/`server/chunks` 打包代码直接提取，可作为后续修复依据：

1. **模型匹配函数 `L(e)`**：
   ```js
   L = e => isEmptyModelValue(e.modelId)
     ? (isEmptyModelValue(e.model) ? void 0 : p.get(e.model))
     : m.get(e.modelId)
   ```
   - `m = new Map(models.map(e => [e.modelId, e]))`，其中运行时 `modelId = String(_id)`（`formatDbModelToRuntimeModel` 强制 `modelId:String(e._id)`）
   - `p = new Map(models.filter(isSystemModel).map(e => [e.model, e]))`，**仅 system 模型**
   - 结论：team 模型只能用 **`modelId` = Mongo `_id`** 命中

2. **`assertModelAvailable({model, type, vision})`**：仅校验存在、`type` 一致、`isActive`、vision。**不校验 isSystemModel**，team 模型可通过。

3. **`getDatasetModelReference(dataset, 'embedding')`**：
   ```js
   ({modelId: String(dataset.vectorModelId), model: dataset.vectorModel})
   ```

4. **`dataset/create` 强制要求 agent LLM**：
   ```js
   const a = await getTeamModelHandle({teamId})
   n = a.getModelData(getDatasetModelReference(e,'agent'),   {type:'llm'})        // 无 optional
   i = a.getModelData(getDatasetModelReference(e,'embedding'), {type:'embedding'}) // 无 optional
   r = a.getModelData(getDatasetModelReference(e,'vlm'),       {type:'llm', vision:true, optional:true})
   ```
   - 只配 embedding、不传 `agentModelId` 时报 `513001 modelUnConfigured`
   - 传入 embedding 的 `_id` 作 `agentModelId` 时报 `Model type mismatch`（证明 embedding 模型已被正确命中）
   - LLM `config` 必须包含 `maxContext`、`quoteMaxToken` 等数字字段，否则 zod 校验失败

5. **`unAuthModel`（513004）来源**：
   ```js
   t?.authorizedIds && !t.authorizedIds.has(n.modelId) → throw unAuthModel
   ```
   `authorizedIds` 由 `getAuthorizedModelIds({actor, handle})` 产出（模型使用授权）。当 `authorizedIds` 为空集合或非空但缺少该 `modelId` 时被拒绝。
