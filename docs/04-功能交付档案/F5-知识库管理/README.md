## 四、功能说明

- **功能名**：知识库管理
- **核心目标**：把文章、论文、小说、灵感等多类型资料结构化录入、智能拆分整理并建立知识关联，提供统一检索与复用入口。
- **涉及代码**：`app.py`（新增知识库路由）、`knowledge_store.py`（数据层）、`knowledge_parser.py`（拆分引擎）、`knowledge_linker.py`（关联引擎）、`static/js/knowledge_panel.js`（前端面板，见 02-技术方案.md）。
