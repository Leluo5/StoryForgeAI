## 二、任务清单

### 阶段 A · 数据层

**F5-T1 数据模型与存储引擎（`knowledge_store.py`）** — 高优先级 · ★
- 实现 `knowledge_entry` 数据模型（§2.1/§2.2 技术方案）、`data/knowledge/index.json` 元数据索引。
- 实现 CRUD：`save_entry` / `load_entry` / `delete_entry` / `update_index` / `query_index`。
- 完成标准：单测覆盖 save/load/delete/索引重建；重复录入哈希查重返回已有条目。

### 阶段 B · 引擎层

**F5-T2 类型识别引擎（`knowledge_parser.py::detect_type`）** — 高优先级
- 实现 LLM 自动判定 + 手动指定兜底；不确定抛 `TypeUncertain`。
- 完成标准：单测覆盖四类 + 手动指定 + 不确定分支；LLM mock 注入。

**F5-T3 拆分引擎（`knowledge_parser.py::parse_entry`）** — 高优先级 · ★
- 实现 `parse_article`（段落/要点/摘要/标签）、`parse_paper`（五要素）、`parse_novel`（四要素）、`parse_inspiration`。
- 拆分失败降级原文存储；超大文本 8000 字分块。
- 完成标准：单测覆盖四类拆分 + 降级 + 分块；mock LLM。

**F5-T4 大纲提取引擎（`knowledge_outline.py`）** — 中优先级
- 实现 `extract_outline` 四维度（章节/情节/人物关系/核心故事线）；`parse_novel` 成功后自动触发。
- 完成标准：单测覆盖成功 / `outline_failed` / `no_chapters`；自动触发联动验证。

**F5-T5 关联引擎（`knowledge_linker.py`）** — 中优先级
- 实现 `link_inspiration`：相似度检索（LLM 嵌入优先，TF-IDF 兜底）+ 建立关联 + `llm_enrich` 上下文补充。
- 完成标准：单测覆盖有匹配 / 无匹配 `related_ids=[]`；TF-IDF 兜底。

### 阶段 C · 接口层

**F5-T6 接口层（`app.py` 新增路由）** — 高优先级 · ★
- 实现 §3.1–§3.7 全部路由：统一录入 / commit / OCR / 检索 / 详情 / link / outline。
- 完成标准：Flask 路由单测覆盖全部端点（含 400/404 异常路径）；参数校验。

**F5-T7 检索接口细化（`search_entries`）** — 中优先级
- 实现四维度检索（keyword/type/tag/time）+ 分页。
- 完成标准：单测覆盖四维组合 + 空结果 + 分页边界。

### 阶段 D · 表现层

**F5-T8 前端录入与预览（`knowledge_panel.js`）** — 中优先级
- 实现三种录入方式 Tab + 类型识别确认框 + 条目预览编辑。
- 完成标准：浏览器验证粘贴/上传/OCR 三入口可用；预览可编辑。

**F5-T9 前端检索列表（`knowledge_panel.js`）** — 中优先级
- 实现四维检索栏 + 卡片列表 + 标签。
- 完成标准：浏览器验证筛选组合、空态提示。

**F5-T10 前端详情编辑与大纲视图（`knowledge_panel.js`）** — 中优先级
- 实现详情编辑（structured 编辑 + 关联管理）+ 大纲四维度视图。
- 完成标准：浏览器验证编辑保存、关联建立、大纲查看/编辑/导出。

### 阶段 E · 验收

**F5-T11 单元测试与联调** — 高优先级 · ★
- 汇总 F5-T1~T10 单测；对 DoD #14 做抽样验收（不同篇幅/文风）。
- 完成标准：全部单测通过；DoD #1~#15 对照表逐条核对；README 更新。

## 六、Markdown 导入导出扩展任务（Extension，2026-11-12）

> 本扩展为 F5 增量，对齐技术方案 §九。新增任务 F5-T12~T16，不改动既有 T1~T11。

### 6.1 依赖图（扩展）

```
F5-T12 导出引擎 ──→ F5-T14 API 端点 ──→ F5-T15 前端面板
F5-T13 导入引擎 ──↗                    │
                                        └──→ F5-T16 测试与联调
```

### 6.2 任务清单（扩展）

**F5-T12 导出引擎（`knowledge_markdown_io.py`）** — 高优先级 · ★
- 实现 `build_export_markdown`（标题 H1 + 正文保原样 + 元数据注释）、`sanitize_filename`、`build_filename`、`export_entries`、`build_zip`。
- 完成标准：单测覆盖单条/批量/分类；文件名非法字符替换 + 时间戳；ZIP 字节可解包；内容一致性 100%。

**F5-T13 导入引擎（`knowledge_markdown_io.py`）** — 高优先级 · ★
- 实现 `decode_bytes`（utf-8→gbk）、`parse_markdown_text`（标题/格式统计）、`detect_conflict`（identical/name_collision）、`import_files`（overwrite/rename/skip + 统计 + progress_cb）。
- 完成标准：单测覆盖编码/解析/冲突三策略/统计/进度回调；损坏文件 `parse_error`。

**F5-T14 API 端点（`routes.py`）** — 高优先级
- 实现 `POST /markdown/export`、`/markdown/import/preview`、`/markdown/import`、`/markdown/import/validate` 四端点。
- 完成标准：Flask test_client 覆盖四端点 + 400/404 异常路径。

**F5-T15 前端面板（`knowledge_panel.js`）** — 高优先级
- 实现可挂载「Markdown 导入导出」组件，导出 `StoryForgeKnowledgeMarkdownIO`；导入（FileReader + 预览 + 冲突策略 + 结果统计）/ 导出（范围选择 + 下载）+ 进度反馈。
- 完成标准：`node --check` 语法通过；浏览器验证导入导出全流程。

**F5-T16 测试与联调** — 高优先级 · ★
- 汇总 F5-T12~T15 单测；跑全量测试确认无回归；对齐 MD-1~MD-14 对照表。
- 完成标准：全量测试通过；README 更新为「已交付」。
