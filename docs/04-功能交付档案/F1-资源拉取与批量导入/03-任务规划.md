## 二、任务明细

### 2.1 F1-T1 coze_client 资源拉取封装（数据层）

**目标**：在 `coze_client.py` 中实现统一的资源详情拉取能力，供导入复用。

**完成标准**：
- 新增 `get_bots(pat, workspace)` / `get_workflows(pat, workspace)` / `get_datasets(pat)` 返回标准化列表 `{resource_id, name, type}`。
- 新增 `get_resource_detail(pat, workspace, res)` 按类型返回元信息（bot：name/description/opening/prompt/variables/bot_list；workflow：name/description/params/variables；dataset：name/description/file_count）。
- 字段提取用 `.get()` 容错，Coze 字段漂移不抛异常。
- 统一异常：`CozeAuthError`(401) / `CozeRateLimitError`(429) / `CozeTimeoutError`(504)。

**关键点**：`resource_id` 用 Coze 的 `id`；`type` 区分 bot/workflow/dataset；所有响应经容错解析。

### 2.2 F1-T2 work_manager 批量导入与去重（数据层）

**目标**：`work_manager.py` 支持按 `coze_resource_id` upsert，不产生重复作品。

**完成标准**：
- 新增 `upsert_work(work)`：按 `coze_resource_id` 查重，存在则更新元信息 + `updated_at`，不存在则生成 uuid 新建。
- 新增 `import_works(pat, workspace, resources)`：for 循环逐资源处理，单资源失败捕获记入 `failed`，**不中断整体**。
- 返回 `{"imported": n, "failed": [{resource_id, reason}]}`。
- 作品 JSON 含 `pat_token` / `workspace_id`（服务端），对外由 `get_work_public()` 过滤。

**关键点**：导入幂等（重复导入不重复）；部分失败继续。

### 2.3 F1-T3 导入 API 路由（接口层）

**目标**：`app.py` 暴露三个管理端接口，路由函数保持薄。

**完成标准**：
- `POST /api/admin/coze/test`：参数校验 → 调 client test → `{ok, bots_count, workflows_count}`；Token 无效 401。
- `POST /api/admin/coze/resources`：返回 `{bots, workflows, datasets}` 三数组。
- `POST /api/admin/works/import`：调 `work_manager.import_works` → `{imported, failed}`。
- 所有路由经 `require_admin`（若已实现）鉴权。
- 错误统一 `{"error": msg}` + 状态码（400/401/502/504）。

**关键点**：路由薄；参数校验在路由层；错误映射到状态码。

### 2.4 F1-T4 资源 Tab + 勾选 + 批量导入交互（表现层）

**目标**：`app.js` 管理后台支持资源列表展示、勾选、批量导入。

**完成标准**：
- 资源 Tab 状态 `currentResourceTab`（all/bots/workflows/datasets）切换渲染。
- 每行 checkbox + 全选/取消；选中计数实时显示。
- 点「批量导入」→ 调 import API → 显示「成功 n / 失败 m」。
- 导入成功后刷新 `adminWorks` 列表，大厅即时可见。
- 连接测试按钮 → 调 test → 显示 ok/错误。

**关键点**：全部经 `api.request` 封装；动态内容转义；错误走 toast。

### 2.5 F1-T5 单元测试与验证（测试）

**目标**：验证导入全链路正确性与幂等性。

**完成标准**：
- 单元测试覆盖：`convert` 参数（见 F3）之外，重点测 `upsert_work` 去重、`import_works` 部分失败。
- 手动验证：输入 PAT → 测试连接 → 拉取列表 → 勾选导入 → 大厅出现作品；重复导入不产生重复。
- 运行 `python -m py_compile app.py` 语法通过；启动服务走一遍关键流程。

**关键点**：去重与部分失败是核心断言点。

