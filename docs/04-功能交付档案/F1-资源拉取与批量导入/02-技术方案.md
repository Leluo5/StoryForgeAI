## 一、方案概述

本功能负责把 Coze 平台资源拉取到本地并分类导入。统一入口保留为 `POST /api/admin/works/import`：Bot 由 `AgentService.import_coze_agent()` 写入全局未分类 Agent 池；workflow 继续由 `work_manager` 写入作品库。

### 1.1 方案选型

| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 导入方式 | **同步批量**（for 循环逐个处理） | 异步/线程池 | 资源量小（个人作品集），同步更简单可调试；失败可独立捕获 |
| 导入幂等 | **按资源类型与 Coze ID 去重**（已存在则更新） | 跳过 | Bot 按 `bot_id` 更新原 Agent；workflow 不产生重复作品 |
| 部分失败 | **不中断整体**，记录失败结果 | 全有全无 | 单个资源详情失败不应阻塞其余成功项 |
| 元信息提取 | **服务端提取**（导入时落库） | 前端提取 | 数据统一；Agent 仅保存非敏感配置，不持久化 PAT |

## 二、API 设计

### 2.1 `POST /api/admin/coze/test` — PAT 连接测试

**请求体**：

```json
{ "pat_token": "pat_xxx", "workspace_id": "12345" }
```

**响应 200**：

```json
{ "ok": true, "bots_count": 3, "workflows_count": 5 }
```

**错误**：400（参数缺）、401（Token 无效）、502（Coze 上游异常）

### 2.2 `POST /api/admin/coze/resources` — 拉取资源列表

**请求体**：`{ "pat_token": "...", "workspace_id": "..." }`

**响应 200**：

```json
{
  "bots": [ { "resource_id": "b1", "name": "出行助手", "type": "bot" } ],
  "workflows": [ { "resource_id": "w1", "name": "订单流程", "type": "workflow" } ],
  "datasets": [ { "resource_id": "d1", "name": "知识库A", "type": "dataset" } ]
}
```

### 2.3 `POST /api/admin/works/import` — 批量导入

**请求体**：

```json
{
  "pat_token": "...",
  "workspace_id": "...",
  "bot_ids": [
    { "id": "b1", "name": "角色塑造师", "_source_type": "bot" },
    { "id": "w1", "name": "章节工作流", "_source_type": "workflow" }
  ]
}
```

**响应 200**：

```json
{
  "success": true,
  "total": 2,
  "imported": 2,
  "results": [
    { "success": true, "agent_id": "a1", "name": "角色塑造师", "type": "bot" },
    { "success": true, "work_id": "w1", "name": "章节工作流", "type": "workflow" }
  ]
}
```

## 三、数据库/存储设计

沿用 JSON 文件存储，按资源类型分流，无需新表：

- **Bot**：`data/agents/_global/<agent_id>.json`，`kind=unclassified`、`scope=global`、`source=coze_import`。
- **workflow / dataset**：继续写入 `work_manager` 的作品 JSON。
- **Agent 敏感信息**：`platform_config` 仅包含 `bot_id` 与 `workspace_id`，不保存 `pat_token`；提示词写入 `model_config.system_prompt`。
- **归属约束**：全局未分类 Agent 不设置 `role_id`、`tool_name`、`step_order`，也不绑定小说作品。

## 四、核心逻辑

### 4.1 导入主流程（伪代码）

```python
for resource in bot_ids:
    if resource.get("_source_type", "bot") == "workflow":
        work = work_manager.import_workflow(resource, pat, workspace_id, access_code)
        results.append({"success": True, "work_id": work["id"], "type": "workflow"})
    else:
        detail = coze_client.get_bot_info(resource["id"])
        if detail["success"]:
            agent = agent_service.import_coze_agent(detail["data"], workspace_id)
            results.append({"success": True, "agent_id": agent["id"], "type": "bot"})
        else:
            results.append({"success": False, "id": resource["id"], "error": detail["error"]})
```

### 4.2 元信息提取规则

| 资源类型 | 提取字段 |
|---------|---------|
| bot | name / description（或 opening 开场白）/ prompt（提示词）/ bot_id / workspace_id |
| workflow | name / description / params（变量定义）/ variables |
| dataset | name / description / file_count |

### 4.3 去重策略

- Bot 在 `_global` 池中以 `kind=unclassified + platform_config.bot_id` 查重。
- 已存在 Agent → 仅更新白名单字段并递增 `version_no`，不改变 `kind` 与 `source`。
- 不存在 Agent → 创建新记录；workflow 继续沿用作品存储的既有去重策略。

## 五、异常处理

| 异常 | 处理 |
|------|------|
| `CozeAuthError` | 401「Token 无效」 |
| `CozeRateLimitError` | 429「Coze 限流，稍后再试」 |
| `CozeTimeoutError` | 504「连接 Coze 超时」 |
| 单资源详情失败 | 记入 failed，继续 |
| 文件写入失败 | 记入 failed，不中断 |

所有错误统一 `{"error": "<msg>"}`。

## 七、验收对照

| 需求验收标准 | 方案落点 |
|------------|---------|
| PAT 无效提示明确错误 | 2.1 返回 401 + error 文案 |
| 资源列表按类型分组 | 2.2 返回三数组，前端 Tab 渲染 |
| Bot 进入 Agent 管理而非作品管理 | 2.3 返回 agent_id；4.1 调用 AgentService；后台请求 `_global` 池 |
| workflow 仍进入作品管理 | 2.3 返回 work_id；4.1 保留 work_manager.import_workflow |
| 单资源详情失败不中断 | 4.1 收集失败结果，继续后续资源 |
| Agent 不持久化 PAT，作品不对外暴露 PAT | Agent payload 不含 PAT；作品公开响应由 get_work_public 过滤 |
| 参数提取准确 | 4.2 按类型提取 params |
| 重复导入不重复 | 4.3 Bot 按 bot_id 更新原 Agent |

## 八、风险与待定

| 风险 | 说明 | 对策 |
|------|------|------|
| PAT Token 落盘 | 新 Agent 不保存 PAT；既有作品存储仍需关注明文 Token | Agent 仅保存非敏感配置；作品侧生产迁移环境变量/密钥服务（见开发规范 §5） |
| Coze API 字段漂移 | 平台字段可能变化 | coze_client 做字段容错（.get 默认值） |
| 大批量导入 | 资源多时串行慢 | 资源量小可接受；必要时加线程池 |
