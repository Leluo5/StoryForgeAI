## 一、档案说明

本档案记录 M2 变更协作功能从需求澄清到上线的完整证据链。M2 覆盖六项子功能：修订、版本、评论、待办、通知、审计。

核心诉求：作者创作过程中的所有正文改动与协作动作（评论、待办、通知）必须可追踪、可回溯、可审计，不丢稿、不静默覆盖、评论不随编辑丢失。
