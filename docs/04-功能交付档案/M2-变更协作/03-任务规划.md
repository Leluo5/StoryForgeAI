## 二、任务清单

### 阶段 A · 数据层

**M2-T1 数据模型与迁移（`database/migrations/<epoch>-revision-base.ts` + `database/revision-*.entity.ts`）** — 高优先级 · ★
- 建 6 张表：`revision_sets`、`version_snapshots`、`comment_threads`、`todos`、`notifications`、`audit_logs`（手写 SQL，沿用 M1 模式）。
- 写 6 个 TypeORM 实体：`RevisionSetEntity`、`VersionSnapshotEntity`、`CommentThreadEntity`、`TodoEntity`、`NotificationEntity`、`AuditLogEntity`。
- 关键约束：`UNIQUE(chapter_id, version_no)`（版本快照）、`CHECK IN (...)`（各枚举）、`REFERENCES ... ON DELETE CASCADE/SET NULL`、索引。
- 完成标准：`migration:run` 幂等；实体注册进 DataSource；迁移可重复执行（down/up）。

### 阶段 B · 契约层

**M2-T2 契约层（`packages/contracts/src/revision.ts` + `index.ts` 聚合）** — 高优先级 · ★
- 定义全部请求/响应 Zod Schema：`createRevisionSetRequestSchema`、`resolveOperationRequestSchema`、`createVersionRequestSchema`、`compareVersionsRequestSchema`、`rollbackRequestSchema`、`confirmRollbackRequestSchema`、`createCommentRequestSchema`、`replyCommentRequestSchema`、`reAnchorCommentRequestSchema`、`createTodoRequestSchema`、`updateTodoStatusRequestSchema`、`notificationReadRequestSchema`。
- 导出 `z.infer` 类型（单 schema 双端复用，沿用 M1）。
- 完成标准：contracts 构建通过；前后端 import 同一 schema 类型一致。

### 阶段 C · 服务层

**M2-T3 修订集服务（`revision/revision.service.ts`）** — 高优先级 · ★
- `createRevisionSet`：悲观锁章节行 + `base_version` 校验（不符 409）+ `ai_set` 判定 + 审计 `revision_create`。
- `resolveOperation`：幂等（已处理返回当前结果）+ 单条接受/拒绝 + 状态推进（`pending/partially_resolved/resolved`）+ 首次接受 AI 修订前自动快照 + 审计。
- 完成标准：单测覆盖形成/幂等/AI 不混组/状态推进；冲突 409。

**M2-T4 版本快照服务（`revision/version.service.ts`）** — 高优先级 · ★
- `createVersion`：手动快照 + `UNIQUE(chapter_id, version_no)` 兜底。
- `ensureAutoSnapshot`：首次接受 AI 修订前/回滚前/迁移前；同一修订集只建一个自动快照。
- `compare`：两版本差异（节点 + 正文明细）。
- `rollback`：回滚前自动快照当前正文 + 以目标快照生成 `actor_type='rollback'` 修订集 + preview + 审计。
- `confirmRollback`：悲观锁 + 未保存变更 409 + 应用回滚 operations + `version+1` + 写 `chapter_changes` + 审计。
- 完成标准：单测覆盖快照触发/对比/回滚/确认；404/409 边界。
- 状态：✅ 已完成（2026-11-16）——`version.service.ts` 11/11 单测通过；全量 32/32 无回归。

**M2-T5 评论锚点服务（`revision/comment.service.ts`）** — 高优先级 · ★
- `createComment`：记录选区/原文/前后文/章节版本/作者。
- `reAnchor`：ProseMirror 映射重定位；无法重定位 → `anchor_status='orphaned'`，保留原文与引用，不自动删除。
- `resolve`/`reopen`：状态迁移幂等 + 审计。
- 完成标准：单测覆盖创建/映射重定位/失联标记/解决重开；不删除。
- 状态：✅ 已完成（2026-11-16）——`comment.service.ts` 8/8 单测通过；全量 40/40 无回归。

**M2-T6 待办状态机服务（`revision/todo.service.ts`）** — 中优先级
- `createTodo`：标题/说明/负责人/关联对象；负责人有值产生 `assign` 通知。
- `updateStatus`：`TRANSITIONS` 表校验（非法 422）+ 状态变化产生通知 + 审计；重复完成保持最终状态单次审计。
- `commentToTodo`：评论转待办。
- 完成标准：单测覆盖合法/非法流转、重复完成单次审计、通知触发。
- 状态：✅ 已完成（2026-11-16）——`todo.service.ts` 11/11 单测通过；全量 51/51 无回归。

**M2-T7 通知服务（`revision/notification.service.ts`）** — 中优先级
- `record`：4 类触发（mention/assign/task_result/system）+ `linked_object` jsonb 快照 + content 可读说明。
- `markRead`/`markAllRead`/`unreadCount`/`list`：已读幂等、分页、未读过滤。
- 完成标准：单测覆盖触发/已读幂等/关联对象删除保留说明。
- 状态：✅ 已完成（2026-11-16）——`notification.service.ts` 8/8 单测通过；全量 59/59 无回归。

**M2-T8 审计服务（`revision/audit.service.ts`）** — 中优先级
- `record`：仅追加不更新，写 `audit_logs`（actor/action/target/detail）。
- `query`：作品内过滤（actor/action/target_type/时间范围）+ 分页。
- 完成标准：单测覆盖 record/query；敏感操作可查。

### 阶段 D · 接口层

**M2-T9 接口层（`revision/revision.controller.ts` + `revision.module.ts`）** — 高优先级 · ★

- 完成标准：路由单测覆盖全部端点（含 401/403/404/409/422/429）。
- 状态：✅ 已完成（2026-11-16）——`revision.controller.ts` 创建（RevisionController + NotificationController 两控制器，6 组路由全部落地）；`revision.module.ts` 注册控制器 + 导入 AuthModule；typecheck 通过；全量 66/66 无回归。
- 复核提示：⚠️ 本任务为高风险任务（路由收敛、幂等键、跨端参数），按 §八.3 完成时暂停，请人工复核后再继续 M2-T10。

## 五、编码实现指引（对齐 Skill 11）

1. **每任务一阶段**：M2-T1 完成并跑通迁移，再进 T2，不一口气全做完。
2. **每任务完成即写单测**：通过才进下一任务。
3. **高风险任务暂停**：M2-T1/T2/T3/T4/T5/T9/T10/T12/T13 完成时暂停，人工复核后再继续。
4. **文档同步**：编码完成并单测通过后，更新本档案 README 与总索引为「已交付」。
5. **AI 修订集边界**：M2 先实现手工/导入/回滚修订集；AI 修订集接口预留（M3 接入），不阻塞本里程碑。
