## 一、方案概述

本功能管理站点级配置：站点信息、主题、管理密码、全局 LLM 配置。核心是 `config_loader.py` 的 JSON 读写与 app.js 的主题即时应用。

### 1.1 方案选型

| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 配置存储 | `global_config.json` | 数据库 | 配置量小，单文件足够 |
| 主题实现 | CSS 变量 + `data-theme` 属性 | 多 CSS 文件 | 即时切换，无刷新 |
| 密码存储 | 明文（现状）→ 哈希（增强） | — | 安全规范 §5.2 |
| LLM 配置 | base_url/model/api_key | 环境变量 | 界面可配置更友好；生产建议环境变量 |

## 二、API 设计

### 2.1 `GET /api/admin/config` — 读取配置

**响应 200**：

```json
{
  "site_name": "StoryForgeAI",
  "site_description": "专业小说 AI 写作软件",
  "theme": "light",
  "llm_config": { "base_url": "", "model": "" }
}
```

> 注：`admin_password`、`llm_config.api_key` 不返回明文（仅返回是否存在标记）。

### 2.2 `PUT /api/admin/config` — 更新配置

**请求体**：

```json
{
  "site_name": "新站点名",
  "site_description": "新描述",
  "theme": "dark",
  "admin_password": "newpass",          // 可选，仅更新时传
  "llm_config": { "base_url": "...", "model": "...", "api_key": "..." }
}
```

**响应 200**：`{ "ok": true }`

### 2.3 主题（前端，无独立 API）

- 读取：页面初始化 → `config.theme` → 设置 `<html data-theme>`。
- 切换：设置页切换 → `PUT config` → 即时改 `data-theme`。

### 3.3 敏感字段处理

- `GET`：返回时剔除 `admin_password`、`llm_config.api_key` 明文，仅含 `has_admin_password`、`has_llm_key` 布尔。

## 四、核心逻辑

### 4.1 更新合并（只更新传入字段）

```python
def update_config(payload):
    cfg = load_config()
    for field in ("site_name", "site_description", "theme"):
        if field in payload:
            cfg[field] = payload[field]
    if "admin_password" in payload and payload["admin_password"]:
        cfg["admin_password"] = payload["admin_password"]
    if "llm_config" in payload:
        cfg["llm_config"].update(payload["llm_config"])
    save_config(cfg)
```

### 4.2 主题校验

```python
VALID_THEMES = {"light", "dark"}
assert cfg["theme"] in VALID_THEMES   # 否则 400 / 回退 light
```

### 4.3 前端主题应用

```javascript
function applyTheme(theme) {
    document.documentElement.setAttribute('data-theme', theme);
    // CSS: [data-theme="dark"] { --bg: ...; --text: ...; }
}
```

## 五、异常处理

| 场景 | 处理 |
|------|------|
| site_name 为空 | 400「站点名不能为空」 |
| theme 非法 | 400「主题仅支持 light/dark」 |
| 密码为空 | 400「密码不能为空」 |
| 配置文件损坏 | 回退 DEFAULT_CONFIG + 警告日志 |
| 写入失败 | 500「配置保存失败」，保留原值 |
| 未授权 | 401（需补齐 require_admin） |
