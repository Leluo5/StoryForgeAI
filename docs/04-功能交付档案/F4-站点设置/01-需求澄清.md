## 一、用户诉求（非技术语言）

> 站点运营者希望：**我能改一下网站的名字、描述、外观主题，还能设置管理员密码，以及配置一个全局 AI 模型来辅助我识别截图生成参数。**

### 1.1 要解决的核心痛点

- 站点名称/描述是写死的，改起来要动代码。
- 主题只有一种，没有深浅色切换。
- 管理密码默认写死在配置里，不安全。
- 「AI 识别截图生成参数结构」需要一个可配置的 LLM 端点。

### 1.2 期望的完整体验

```text
管理后台 → 设置页
  → 站点信息：名称 / 描述 / 主题（浅/深）
  → 安全：修改管理密码
  → AI 配置：LLM 端点 / 模型 / API Key（可选）
  → 保存 → 即时生效（主题无需刷新）
```

## 二、功能边界

### 2.1 包含（In Scope）

| # | 能力 | 说明 |
|---|------|------|
| 1 | 站点信息 | 站点名、站点描述 |
| 2 | 主题切换 | 浅色 / 深色，CSS 变量即时切换 |
| 3 | 管理密码修改 | 明文存储（当前），建议哈希（增强） |
| 4 | 全局 LLM 配置 | base_url / model / api_key，供「AI 识别截图生成参数」用 |
| 5 | 配置持久化 | `global_config.json` 读写 |

### 2.2 不包含（Out of Scope）

- ❌ 多站点 / 多租户配置。
- ❌ 主题自定义色板（仅预置浅/深两套）。
- ❌ 邮件/SMTP、第三方登录配置。
- ❌ 配置版本回滚。

## 三、功能流程

### 3.1 读取配置流程

```text
GET /api/admin/config
  → require_admin
  → config_loader.load_config()
  → 返回 { site_name, site_description, theme, llm_config }
  → 前端填充表单
```

### 3.2 更新配置流程

```text
管理后台表单 → PUT /api/admin/config
  → 校验字段（site_name 非空、theme ∈ {light,dark}）
  → config_loader.save_config()
  → 返回保存结果
  → 前端：主题即时应用，提示「已保存」
```

### 3.3 主题应用流程

```text
应用初始化 → 读 config.theme
  → 设置 <html data-theme="light|dark">
  → CSS 变量按主题切换
  → 用户切换 → 存回配置
```

## 四、验收标准（DoD）

| # | 标准 | 验证方式 |
|---|------|---------|
| 1 | 站点名/描述修改后前台即时显示 | 改名 → 保存 → 大厅标题变化 |
| 2 | 主题切换无需刷新即时生效 | 切深色 → 页面立即变深色 |
| 3 | 修改密码后旧密码失效新密码生效 | 改密 → 登出 → 旧密码登录失败 → 新密码成功 |
| 4 | LLM 配置保存后可被 AI 识别功能调用 | 保存配置 → 触发截图识别 → 使用新端点 |
| 5 | 配置持久化重启不丢 | 修改 → 重启服务 → 配置仍生效 |
| 6 | 非法 theme 值被拒绝 | 传 theme=blue → 400 或回退默认 |

## 五、异常与边界处理

| 场景 | 处理 |
|------|------|
| site_name 为空 | 400「站点名不能为空」 |
| theme 非法 | 400 或回退 `light` |
| 修改密码为空 | 400「密码不能为空」 |
| LLM api_key 为空但 base_url 有值 | 允许（部分模型免 key），保存时校验格式 |
| 配置读写失败 | 500「配置保存失败」，保留原值 |
| 密码含敏感字符 | 校验长度 ≥ 6（增强） |

## 六、数据字段说明

### 6.1 全局配置（global_config.json）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `site_name` | string | StoryForgeAI | 站点名称 |
| `site_description` | string | '' | 站点描述 |
| `theme` | enum | light | light / dark |
| `admin_password` | string | （示例值） | ⚠️ 敏感，建议哈希 |
| `llm_config.base_url` | string | '' | LLM 端点 |
| `llm_config.model` | string | '' | 模型名 |
| `llm_config.api_key` | string | '' | ⚠️ 敏感，仅服务端使用 |

## 七、相关依赖与约束

- **依赖**：`config_loader.py`（读写）、`app.js`（主题应用、表单绑定）。
- **约束**：`admin_password` 与 `llm_config.api_key` 属敏感字段，对外 GET 返回时应脱敏（或仅在更新时接受）。
- **前置**：需 `require_admin` 鉴权。
