## 二、任务明细

### 2.1 F2-T1 work_manager CRUD + 脱敏白名单（数据层）

**目标**：作品文件 CRUD 与公开脱敏。

**完成标准**：
- `get_work_public(work)` 白名单 `PUBLIC_FIELDS` 过滤，**绝不返回** access_code/pat_token/workspace_id 明文。
- `has_access_code` = `bool(access_code)` 布尔。
- 支持 `list_works()`（公开）/ `list_admin_works()`（完整）/ `get_work(id)` / `update_work(id, data)` / `remove_work(id)`。
- 每作品一个文件 `data/works/<id>.json`。

**关键点**：白名单过滤是安全核心；更新只改传入字段。

### 2.2 F2-T2 访问码验证与会话（接口层，高风险）

**目标**：公开端访问码验证 + 会话发放（供 F3 调用）。

**完成标准**：
- `POST /api/works/<id>/verify`：无 access_code → 返回 `{token: "public"}` 免验证；错误 → 401（不提示是否存在）。
- 验证成功发放 `secrets.token_urlsafe(24)` 会话，`access_tokens` 内存 dict 存 `{token, expires}`。
- 密码比较用 `hmac.compare_digest`（防时序攻击）。
- `require_access(work_id, token)`：无会话/过期/不匹配 → 403。

**关键点**：401 统一不泄露作品是否存在；比较防时序；会话 TTL。

### 2.3 F2-T3 管理端 CRUD 路由（接口层）

**目标**：管理端作品列表/更新/删除接口。

**完成标准**：
- `GET /api/admin/works`：完整列表（含敏感，仅管理员）。
- `PUT /api/admin/works/<id>`：部分字段更新，非法字段返回 400 并列出。
- `DELETE /api/admin/works/<id>`：删除文件；失败 500。
- 全部经 `require_admin` 鉴权。

**关键点**：非法字段校验；删除文件幂等。

### 2.4 F2-T4 前端编辑/删除/访问码交互（表现层）

**目标**：管理后台编辑/删除作品 + 前台访问码弹窗。

**完成标准**：
- 编辑弹窗：表单预填当前值 → PUT → 刷新列表；成功 toast。
- 删除确认：`confirm` → DELETE → 移除卡片。
- 访问码弹窗：输入 → verify → 存 `accessTokens[workId]` → 进入体验。
- 401 错误 → toast「访问码错误」→ 聚焦输入框。

**关键点**：全走 `api.request`；token 存 `state.accessTokens`。

### 2.5 F2-T5 单元测试与验证（测试）

**目标**：验证脱敏、访问码、CRUD。

**完成标准**：
- 单元测试：`get_work_public` 不含敏感键；verify 正确/错误/公开三种；require_access 过期拒绝。
- 手动验证：公开列表无敏感字段；输入错误访问码被拒；正确访问码进入体验。
- `py_compile` 通过；启动服务走流程。

**关键点**：脱敏与访问码是断言核心。

## 三、依赖关系

```text
F2-T1 ──→ F2-T2 ──→ F2-T4
   └────→ F2-T3 ──→ F2-T4
              └───→ F2-T5
```

- **阻塞任务**：F2-T2/T3 依赖 F2-T1；F2-T4 依赖 T2+T3。
- **高风险**：F2-T2（访问码鉴权，安全敏感）。
- 建议编码顺序：F2-T1 → F2-T2 → F2-T3 → F2-T4 → F2-T5。
