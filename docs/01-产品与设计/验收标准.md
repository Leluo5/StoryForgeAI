## 一、验收总则

### 1.1 验收原则

1. 所有指标**可量化、可复核**，禁止模糊表述（如「性能良好」）。
2. 每项指标必须标注**目标值、统计口径、判定方法**。
3. 验收分为阶段验收（P1-P6 各出口准则）与总体验收（全部改造完成）。
4. 数据证据必须保留（测试报告、日志、截图），禁止只写结论。

### 1.2 指标数量

本文件共 **28 条**可量化验收指标，满足 P1 出口准则「≥ 20 条可量化指标」要求。

## 二、角色 Agent 体系验收（8 条）

| 编号 | 指标 | 目标值 | 统计口径 | 判定方法 |
| --- | --- | --- | --- | --- |
| R-01 | 角色 Agent 调用成功率 | ≥ 99.5% | 连续 7 天，按调用次数统计 | 自动化统计：成功调用数 / 总调用数 × 100% |
| R-02 | 单角色 Agent 绑定数 | ≥ 1 个 | 每个角色至少绑定 1 个 cozeAgent | 遍历角色绑定表，计数 ≥ 1 |
| R-03 | 单角色多 Agent 有序调用 | 100% | 绑定 ≥ 2 个 Agent 的角色 | 按 step_order 排序验证调用顺序 |
| R-04 | 11 步流程完整性 | 1-11 全覆盖 | step_order 1-11 | 遍历流程配置，无缺失、可重排 |
| R-05 | 角色一致性命中率 | 100% | 同一角色会话上下文不串角色 | 自动化测试：模拟跨会话调用，校验 role_id 归属 |
| R-06 | 记忆连续性 | 100% | 同一角色跨会话恢复历史记忆 | 自动化测试：会话中断后恢复 memory_state |
| R-07 | 行为逻辑独立性 | 100% | 多角色不共享上下文 | 自动化测试：角色 A 写不影响角色 B |
| R-08 | 上下文串线拦截 | 100% | 跨角色访问被拦截 | 自动化测试：模拟跨角色读写，断言拦截 + 告警 |

| 验收日期 | `YYYY-MM-DD` |
