## 一、设计目标与定位

| 项 | 说明 |
| --- | --- |
| 定位 | 全局知识库的**独立管理中心**，面向深度整理、批量操作、大纲编辑与关联管理 |
| 用户场景 | 创作者需要集中查看/筛选大量素材、编辑结构化内容、管理关联、导入导出或整库备份时进入 |
| 入口 | 工作台顶部/侧栏「知识库管理」→ 全页；或从抽屉右上角「全屏管理」跳转 |
| 与抽屉关系 | 日常快速检索与引用使用抽屉；深度工作使用本全页。两者共享同一数据源与筛选状态 |
| 断点优先 | 仅桌面 `1024` / `1440` 两档（与 M3c-3 确认一致），移动端暂不适配 |

└─────────────────────────────────────────────────────────────────────────────────┘
┌──────────────┬──────────────────────────────────────────┬─────────────────────────┐
│ 左侧导航      │ 中间列表区（主内容）                       │ 右侧详情区               │

│ 可折叠       │                                          │ 可折叠                   │
│              │  ┌─ 筛选工具栏 ─────────────────────────┐ │                         │
│ 类型筛选      │  │ 关键词 │ 类型多选 │ 标签 │ 时间 │ 排序 │ │  标题 + 类型徽章         │

**布局原则（对齐 UI 规范）**
- 8px 栅格：栏间距 16px，卡片内边距 16px，筛选栏高度 48–56px。
- 左侧与右侧可折叠（记忆用户偏好），折叠后中间区自动扩展。
- 背景：`--bg-primary`；卡片：`--bg-card` + 细边框 + 单层轻阴影。

## 三、组件与交互详细设计

### 3.1 Header

| 元素 | 规格 | 交互 |
| --- | --- | --- |
| 标题 | 「知识库管理中心」 18px 中等字重 | — |
| 库切换 | Segmented Control：`全局库` / `当前作品` | 切换后刷新列表与计数；当前作品需已选中作品 |
| 全局搜索 | 输入框 + 回车/防抖搜索 | 聚焦时展开建议（最近搜索 + 热门标签） |
| 主操作 | 主按钮「录入」；次按钮「导入/导出」「整库备份」 | 录入打开统一录入抽屉/弹窗 |
| 主题/用户 | 沿用全站 Header 组件 | — |

### 3.2 左侧导航

- **类型筛选**：单选 Radio 组，显示各类型数量徽章。选中后中间列表实时过滤。
- **标签云/树**：点击标签加入筛选（可多选）；支持「管理标签」入口。
- **收藏与置顶**：固定区块，展示已收藏条目快捷入口。
- 折叠按钮：左上角图标，折叠后仅显示图标栏。

### 3.3 中间列表区

**筛选工具栏**
- 关键词输入、类型多选下拉、标签选择器、时间范围（今天/近7天/近30天/自定义）、排序（更新时间/创建时间/标题）。
- 批量操作栏：进入多选模式后出现「导出选中」「删除」「取消」。

**卡片规格（知识条目卡片）**

```
┌────────────────────────────────────────────────────────────┐
│ [类型图标]  标题（最多两行，超出省略）          ★收藏  更多… │
│ 类型徽章 · 更新时间 · 有大纲/关联数                         │
│ 标签 chips（最多显示 3 个 +N）                              │
│ 摘要一行（可选，结构化 summary 或原文前 80 字）             │
└────────────────────────────────────────────────────────────┘
```

- 类型图标颜色使用知识库语义色 `--cyan-500`。
- 悬停：轻微上浮 + 边框强调（`--brand-400`）。
- 选中（多选）：左侧 checkbox + 背景 `--brand-50`。
- 点击卡片：右侧详情区加载对应条目（单选模式）；多选模式下切换选中状态。

**空态**
- 插画 + 文案「还没有知识条目」+ 主按钮「开始录入」。
- 筛选无结果：「没有匹配的条目」+ 「清除筛选」。

### 3.4 右侧详情区

**通用结构**
1. 头部：标题（可编辑）+ 类型徽章 + 收藏按钮 + 更多菜单（导出 MD、删除、复制链接）。
2. 元信息行：来源、创建/更新时间、作者归属。
3. 标签编辑区：可增删标签。
4. 原文区块：默认折叠，点击展开完整 `raw_content`（Markdown 渲染）。
5. 结构化内容区块：按 `type` 使用不同模板（见下）。
6. 关联区块：显示 `links` 列表，支持添加/移除关联。
7. 底部操作：`[保存]` `[引用到当前作品]` `[导出 Markdown]`。

**类型专属渲染模板**

| 类型 | 结构化展示重点 |
| --- | --- |
| article | 分段列表 + 核心观点清单 + 摘要 + 标签列表 |
| paper | 五要素卡片（问题 / 方法 / 结论 / 局限 / 启发），每项可独立编辑 |
| novel | 拆文四块（角色 / 情节 / 叙事风格 / 世界观）+ **四维大纲树**（章节可折叠、情节节点、人物关系、故事线） |
| inspiration | 原始灵感 + 补充完善后文本 + 自动关联条目列表（最多 3 条默认） |
| 设定集 | 复用文章结构：分段 + 核心观点 + 标签清单 |

**小说四维大纲**
- 以可折叠树 + 标签形式展示。
- 支持行内编辑、拖拽调整顺序（章节/节点）。
- 提供「重新提取大纲」按钮（触发异步任务 + SSE 进度）。

### 3.5 录入 / 导入导出 / 备份

- **录入**：点击 Header「录入」打开右侧滑出抽屉或居中弹窗，包含粘贴 / 上传文件（docx/pdf/txt/md）入口，类型自动/手动选择，预览后确认入库。
- **Markdown 导入导出**：独立面板（可从 Header 进入），支持单条/批量/分类导出 ZIP，导入带预览与冲突策略（覆盖/重命名/跳过）。
- **整库备份**：触发版本化 JSON + gzip 下载；恢复时提供预览与冲突处理。

## 四、UI 视觉规范（对齐墨韵科技风）

| 元素 | Token / 规格 |
| --- | --- |
| 知识库主强调色 | `--cyan-500` `#0891B2`（面板边框、类型图标、激活态） |
| 卡片背景 | `--bg-card`，边框 `--border-color`，圆角 8px，阴影 `shadow-sm` |
| 选中/悬停底 | `--brand-50` / `--bg-hover` |
| 正文 | `--text-primary` 14–16px，行高 1.6 |
| 次要信息 | `--text-secondary` 12–13px |
| 标签 Chip | 背景 `--brand-100` 或 cyan 浅色，圆角 4px，高度 24px |
| 主按钮 | `--brand-500` 填充，悬停 `--brand-600` |
| 次按钮 | 边框按钮，文字 `--text-primary` |
| 间距 | 严格 8px 倍数：4 / 8 / 12 / 16 / 24 / 32 |
| 图标 | 线性 1.5px，尺寸 16/20/24，知识库相关使用 cyan 色 |

深色主题同步维护，对比度满足 WCAG AA。

## 五、关键交互流程

1. **进入页面** → 默认加载「全局库」+「全部类型」+ 按更新时间倒序。
2. **筛选** → 任意筛选条件变化即时请求（防抖 300ms），更新计数与列表。
3. **查看详情** → 点击卡片 → 右侧加载，URL 可带 `?id=xxx` 支持直达。
4. **编辑保存** → 修改结构化字段后点「保存」→ PUT 接口 → Toast 成功。
5. **引用到作品** → 选择目标作品（若未在作品上下文）→ 创建引用关系。
6. **删除** → 进入回收站（可恢复），彻底删除二次确认。

## 六、状态与反馈

| 状态 | 表现 |
| --- | --- |
| 加载中 | 列表骨架屏；详情区 Spinner |
| 空列表 | 插画 + 引导文案 + 录入按钮 |
| 筛选无结果 | 「无匹配条目」+ 清除筛选链接 |
| 保存成功 | Toast 成功（2s） |
| 结构化进行中 | 详情区显示进度条 + SSE 实时状态 |
| 错误 | Toast 错误 + 可重试操作 |
