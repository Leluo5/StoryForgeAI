## 一、边界定义总则

### 1.1 目的

明确角色 Agent「能做什么、不能做什么、什么条件下才能做」，防止上下文串线、数据越界、越权访问。边界定义无模糊表述，是 P1 出口准则之一。

### 1.2 三类规则

| 规则类别 | 定义 | 处置 |
| --- | --- | --- |
| **禁止项** | 角色 Agent 绝对不可执行 | 系统拦截并抛错，记入审计日志，不静默降级 |
| **允许项** | 角色 Agent 默认可执行 | 无条件放行，但须在角色命名空间内 |
| **条件触发项** | 满足条件才可执行 | 条件不满足则返回明确错误码，不阻塞 |

## 二、角色 Agent 能力边界矩阵

### 2.1 允许项（默认可执行）

| 能力 | 规则说明 | 边界约束 | 触发条件 |
| --- | --- | --- | --- |
| 读写本角色上下文 | 只读写 `role_id` 对应命名空间 | 读写范围严格限定在 `role_id` 命名空间 | 无条件 |
| 读取项目元数据 | 只读 `title` / `genre` / `world_setting` | 禁止写项目元数据 | 无条件 |
| 调用绑定工具 | 仅调用绑定到本角色的工具 | 工具必须在角色绑定表内，且 `enabled=true` | 无条件 |
| 修改章节内容 | 只追加本角色生成章节 | 禁止修改他人角色章节 | 无条件 |
| 读取自身记忆 | 读取本角色 `memory_state` | 跨会话恢复，命名空间独立 | 无条件 |

### 2.2 禁止项（绝对不可执行）

| 能力 | 规则说明 | 违反处置 |
| --- | --- | --- |
| 跨角色读写 | 禁止访问其他 `role_id` 上下文 | 拦截 + 抛错 + 审计告警 |
| 篡改项目元数据 | 禁止修改 `title` / `genre` / `world_setting` | 拦截 + 抛错 |
| 访问管理端 API | 禁止 `/api/admin/*` 及站点配置写操作 | 拦截 + 401 |
| 删除章节/版本 | 禁止删除既有章节、版本快照 | 拦截 + 403 |
| 写知识库条目 | 禁止角色写入知识库条目（只读引用） | 拦截 + 403 |
| 跨线程读写剧情推衍 | 禁止访问其他线程数据 | 拦截 + 抛错 |

### 2.3 条件触发项（满足条件才可执行）

| 能力 | 触发条件 | 未满足处置 |
| --- | --- | --- |
| 生成情节发展内容 | 当前 `step_order = 11`（情节发展步骤） | 返回 409 错误码提示步骤不符 |
| 多角色协同写作 | `project_id` 写锁已获取且协同模式开启 | 返回 409 提示等待写锁 |
| 长耗时工具（长篇小说/有声书/70步） | 任务队列空闲且不阻塞 SSE 主通道 | 返回 202 + `task_id`，轮询进度 |
| 生成角色图像 | 按外貌特征步骤（step 1）已绑定图像工具 | 返回 404 提示未绑定 |
| 情感分析 | 按情感状态步骤（step 5）已绑定分析工具 | 返回 404 提示未绑定 |
| 剧情推衍回写剧情树 | 推衍完成 + 目标父节点存在 + 无环路 | 返回 409 提示环路/父节点缺失 |

## 三、数据流转规则

### 3.1 流向规则表

| 流向 | 规则 | 边界约束 |
| --- | --- | --- |
| 角色 → Agent | 携带 `role_id` 命名空间 + 项目上下文（只读） | 只读项目元数据 |
| Agent → 角色 | 写入本角色上下文 | 禁止越界写其他角色 |
| 工具 → 角色 | 可注入角色上下文（按工具能力） | 只读注入，角色不可改工具定义 |
| 角色 → 章节 | 只追加本角色生成章节 | 禁止改他人章节 |
| 多角色协同 | 经项目写锁串行化 | 防覆盖，写冲突告警 |
| 知识库 → 角色 | 条目只读注入角色上下文 | 角色不可写知识库 |
| 角色 → 剧情推衍 | 上下文透传（按情节发展步骤） | 多线程隔离 |
| 剧情树 ↔ 剧情推衍 | 双向：节点作起始上下文、推衍结果回写 | 回写原子性 + 环路检测 |

### 3.2 上下文注入白名单

| 来源 | 可注入字段 | 注入方式 | 说明 |
| --- | --- | --- | --- |
| 项目元数据 | `title`、`genre`、`world_setting` | 只读 | 角色可读不可写 |
| 本角色上下文 | 全部角色字段 | 读写 | 命名空间内 |
| 知识库条目 | 按工具能力指定条目 | 只读注入 | 角色不可写 |
| 剧情树节点 | 节点内容 | 只读起始上下文 | 仅作推衍起点 |

## 四、多角色协同交互逻辑

1. 协同写作开启时，`project_id` 获得写锁。
2. 按 11 步流程推进，各角色 Agent 依序调用（可并行读取、串行写入）。
3. 每个角色输出写入独立上下文，汇总到章节。
4. 冲突检测：同一字段并发写，以写锁 + 时间戳校验，后写覆盖需告警。

### 4.1 协同边界约束

| 项 | 约束 |
| --- | --- |
| 写锁粒度 | `project_id`（项目级） |
| 并行度 | 可并行读取；写入串行 |
| 冲突处置 | 时间戳校验，后写覆盖需告警 |
| 数据隔离 | 各角色独立命名空间，禁止互访 |

## 五、创作工具模块边界（F5/F6/F7）

### 5.1 边界矩阵

| 模块 | 与角色 Agent 联动 | 数据流转 | 边界约束 |
| --- | --- | --- | --- |
| 知识库管理（F5） | 条目可注入角色上下文 | 知识库 → 角色（只读注入） | 角色不可写知识库条目，只读引用 |
| 剧情推衍聊天室（F6） | 按情节发展步骤调用角色 Agent | 角色 → 剧情推衍（上下文透传） | 多线程隔离，线程间禁止读写对方数据 |
| 剧情树（F7） | 节点作起始上下文、推衍结果回写 | 剧情树 ↔ 剧情推衍（双向） | 回写原子性 + 环路检测；节点删除需先解除关联；版本删除/重命名仅授权用户；分支删除需二次确认且禁止删非空分支 |

### 5.2 专项边界规则

| 规则 | 说明 |
| --- | --- |
| F5 大纲自动提取触发 | 小说拆文完成后自动触发；四维度（章节结构/情节节点/人物关系/故事线）结构化存储并关联绑定 |
| F6 一步一断 | 每步推衍后自动暂停，开放用户修改与分支选择；多线程数据隔离 |
| F7 回写原子性 | 推衍结果作为新剧情节点回写，对接关联到原节点下，原子写入（不丢节点） |
| F7 环路检测 | 回写前检测，禁止形成环；检测到环返回 409 并拒绝写入 |
| F7 版本权限 | 版本创建/切换/回滚/历史/对比：全员可执行；版本删除/重命名：仅授权用户（无权限返回 403） |
| F7 分支隔离 | 各分支剧情内容相互隔离，切换分支仅加载该分支内容，不串数据 |
| F7 分支删除约束 | 删除分支前二次确认；禁止删除存在子节点的非空分支（返回 409） |

## 六、接口访问边界

| 接口范围 | 允许访问者 | 说明 |
| --- | --- | --- |
| `/api/admin/*` | 管理员 | 角色 Agent 不可访问 |
| `/api/projects/*` | 创作端（角色 Agent 按绑定） | 角色仅能访问本角色绑定项目 |
| `/api/works/*` | 体验端（访客） | 沿用既有公开列表 |

> 完整接口契约在 P2 架构设计阶段定义（路线图 P2-T4）。

## 七、边界验证要求

| 验证项 | 方法 | 目标 |
| --- | --- | --- |
| 禁止项拦截 | 自动化测试：模拟跨角色读写/越权访问 | 100% 拦截 |
| 允许项放行 | 自动化测试：角色命名空间内操作 | 100% 放行 |
| 条件触发 | 自动化测试：条件满足/不满足双路径 | 100% 符合 |
| 多线程隔离 | 并发测试：多线程推衍互不干扰 | 0 数据串扰 |
| 回写一致性 | 测试：推衍回写不丢节点、不建环 | 100% 一致性 |
