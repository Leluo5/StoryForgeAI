# 关系类型归一规则表

> 版本：v1.0 · 状态：生效建议稿（2026-11-25）  
> 项目：StoryForgeAI —— 专业小说 AI 写作软件  
> 类型：业务规则 / 数据归一  
> 关联：[角色关系图谱算法探讨](./角色关系图谱算法探讨.md)、[子图注入Agent的Prompt策略](./子图注入Agent的Prompt策略.md)、[知识库结构化字段详细定义](./知识库结构化字段详细定义.md)  
> 说明：将 `character.relationships[].relation` 自由文本归一为有限枚举 `relationType`，供图谱着色、边过滤、子图注入优先级使用。

---

## 一、目标与原则

### 1.1 目标

| 目标 | 说明 |
|------|------|
| 视觉编码 | 边颜色、线型按类型稳定映射 |
| 子图裁剪 | P0/P1/P2 优先级依赖类型，而非自由文本 |
| Agent 约束 | 注入时生成「硬禁止」与称谓提示 |
| 可回退 | 归一失败不影响原文 `relationLabel` 展示 |

### 1.2 原则

1. **保留原文**：`relationLabel` 始终存用户/模型原文；`relationType` 为派生字段。  
2. **宁可 other**：不确定时标 `other`，禁止强行猜成 family/enemy。  
3. **关键词优先，LLM 兜底**：规则能命中则不用模型，降低成本与漂移。  
4. **可多标签（可选）**：v1 单主类型；若一文含「亦敌亦友」，主类型取冲突更强者（enemy > ally），原文进 label。  
5. **方向与类型分离**：师→徒的方向用 `directed` / 端点角色表达，不单靠 type。

## 二、标准枚举（relationType）

```ts
type RelationType =
  | 'family'    // 血缘 / 姻亲 / 拟亲属中的强亲情
  | 'romance'   // 恋慕、爱侣、夫妻、暧昧主线
  | 'mentor'    // 师徒、教导、上下修业
  | 'ally'      // 同盟、朋友、同伴、协作
  | 'enemy'     // 敌对、仇敌、宿敌、对立
  | 'faction'   // 同门、同组织、同僚（组织纽带）
  | 'other';    // 无法归入以上或弱关系
```

### 2.1 注入优先级（与子图策略对齐）

| 优先级 | relationType | 子图注入 |
|--------|--------------|----------|
| **P0** | family, mentor, romance | 几乎总注入 |
| **P1** | enemy | 防止立场写崩，默认注入 |
| **P2** | ally, faction | 预算内注入 |
| **P3** | other | 最后；可截断 |

### 2.2 默认视觉编码（建议）

| relationType | 边颜色建议 | 线型建议 |
|--------------|------------|----------|
| family | 暖橙 / 琥珀 | 实线加粗 |
| romance | 玫红 / 粉 | 实线 |
| mentor | 蓝紫 | 实线 + 箭头（师→徒） |
| ally | 青绿 | 实线 |
| enemy | 暗红 / 橙红 | 虚线或短划 |
| faction | 灰蓝 | 细实线 |
| other | 中性灰 | 细实线 |

## 三、关键词与模式规则表

匹配前处理：

1. 转小写（中文无影响）、去首尾空白  
2. 全角转半角、统一「／/」  
3. 按 **先长词后短词**、**先高优先级类型后低优先级** 扫描  
4. 命中多类型时：按冲突优先级 **enemy > family > romance > mentor > ally > faction > other** 取主类型（可配置）

### 3.1 family（亲情 / 血缘 / 姻亲）

| 关键词 / 模式 | 说明 | 示例原文 |
|---------------|------|----------|
| 父、母、父母、爹、娘、爸、妈 | 直系 | 其父、与母亲相依 |
| 子、女、儿、儿子、女儿、孩子 | 直系 | 他是林远的儿子 |
| 兄、弟、姐、妹、哥、兄弟、姐妹、同胞 | 平辈血亲 | 未相认的兄长 |
| 祖、孙、爷爷、奶奶、外公、外婆 | 隔代 | 祖父留下的剑 |
| 叔、伯、舅、姑、姨、侄、甥 | 旁系 | 舅父 |
| 夫、妻、丈夫、妻子、结发 | 姻亲（已婚） | 与之成婚 |
| 亲情、血亲、血脉、家人、骨肉 | 泛亲情 | 血脉相连 |
| 养父、养母、义父、义母、义兄 | 拟亲属且偏亲情 | 义父沈伯 |

**注意**：

- 「师兄/师姐」→ **mentor 或 faction**，不归 family（见 3.3 / 3.6）  
- 「名义夫妻/联姻工具」若原文强调政治联姻、无感情：仍可 family 或 other；若明确「利用婚约」且无亲情，优先 **other**，label 保留原文  

### 3.2 romance（恋慕 / 爱侣）

| 关键词 / 模式 | 说明 | 示例原文 |
|---------------|------|----------|
| 爱、恋、暗恋、单恋、互许 | 情感 | 暗恋多年 |
| 情人和、情侣、爱人、恋人 | 关系身份 | 地下恋人 |
| 欢喜、倾心、钟情、爱慕 | 情感 | 对其倾心 |
| 未婚夫妻、未婚妻、未婚夫、定情 | 婚前 | 青梅定情 |
| 暧昧（且无「政治/利益」主导） | 弱浪漫 | 关系暧昧 |

**与 family 消歧**：

- 「夫妻」默认 **romance**（若需强调家庭结构，图谱可同时参考 family；v1 单类型时 romance 优先于「仅姻亲」）  
- 规则简化：**含恋/爱/情侣等 → romance**；**仅「妻/夫」且无爱恋词 → family 或 romance 均可，建议 romance**  

### 3.3 mentor（师徒 / 教导）

| 关键词 / 模式 | 说明 | 示例原文 |
|---------------|------|----------|
| 师、师父、师傅、恩师、业师 | 师方 | 拜陈墨为师 |
| 徒、徒弟、弟子、门生 | 徒方 | 其为徒 |
| 师徒、教导、传授、领进门 | 关系 | 师徒名分 |
| 师兄、师姐、师弟、师妹 | 同门排辈 | 见 3.6 消歧 |

**方向**：

- 原文「A 为 B 之师 / B 拜 A 为师」→ edge A→B 或 B→A 由解析规则处理  
- type 均为 `mentor`  

### 3.4 ally（同盟 / 朋友）

| 关键词 / 模式 | 说明 | 示例原文 |
|---------------|------|----------|
| 友、朋友、好友、挚友、至交 | 友谊 | 青梅竹马之友 |
| 同盟、盟友、同伴、伙伴、搭档 | 协作 | 临时同盟 |
| 相助、护短（双向伙伴义） | 行为 | 多次出手相助 |
| 同僚（无上下级压迫义） | 共事 | 军中同僚 |

**注意**：「护短」若明确是单方性格而非关系，不一定建边；有边时偏 ally。

### 3.5 enemy（敌对）

| 关键词 / 模式 | 说明 | 示例原文 |
|---------------|------|----------|
| 敌、仇、宿敌、死敌、仇敌 | 强敌对 | 战场宿敌 |
| 对立、敌对、为敌、反目 | 对立 | 反目成仇 |
| 追杀、暗杀、血海深仇 | 敌对行为 | 遭其追杀 |
| 仇家、冤家（非俏皮爱称） | 仇恨 | 血海深仇 |
| 竞争（且原文含打压/踩） | 弱敌对 | 处处打压 |

**消歧**：

- 「冤家」在言情里可能是 romance 梗 → 若同句有爱恋词，**romance 优先**；纯仇意 → enemy  
- 「亦敌亦友」→ 主类型 **enemy**（约束更强），label 保留全文  

### 3.6 faction（同组织 / 同门）

| 关键词 / 模式 | 说明 | 示例原文 |
|---------------|------|----------|
| 同门、同宗、同派 | 门派 | 青云同门 |
| 同袍、同僚（强组织义） | 组织 | 边军同袍 |
| 属下、上司、主公、属臣 | 组织层级 | 为其属下 |
| 宗门、门派内关系未到师徒 | 组织 | 同属青云宗 |

**与 mentor 消歧**：

| 原文 | 归一 |
|------|------|
| 师父 / 徒弟 / 师徒 | **mentor** |
| 师兄、师姐、师弟、师妹（无师徒二字） | **faction**（同门排辈） |
| 既写师徒又写同门 | **mentor** 优先 |

### 3.7 other

无法命中上表，或关系为：

- 路人、一面之缘、买卖、萍水相逢  
- 纯信息关系（「听说过」）  
- 复杂到无法单类（可人工后标）

## 四、冲突与组合决策表

| 原文特征 | 主 relationType | 理由 |
|----------|-----------------|------|
| 宿敌 + 未相认兄长 | **enemy** | 当面立场仍是敌对；family 信息留在 label / notes |
| 名义婚约 + 互相利用 | **other** 或 **romance** | 无感情词 → other；有倾慕 → romance |
| 师兄 + 青梅竹马 | **faction** 或 **romance** | 以感情词是否出现为准；都有则 romance |
| 同盟但互相防备 | **ally** | label 保留防备；不升为 enemy，除非有仇敌词 |
| 养父 + 师父 | **family** 与 **mentor** 双义 | v1 取 **mentor** 若修炼语境强，否则 **family**；推荐 label 完整保留 |

**「宿敌实为兄长」产品建议**：

- `relationType = enemy`（保证 Agent 不写成盟友）  
- `relationLabel = 宿敌，实为未相认兄长`  
- 子图注入时在硬禁止中写清「当面敌对，勿写和解，除非剧情明确」

## 五、实现流程

```text
输入 relation: string
    ↓
normalize(text)  // 空白、符号
    ↓
ruleMatch(text)  // 本节关键词表，返回 type | null
    ↓
若 null 且 enableLlmFallback → LLM 分类（仅 7 类 + other）
    ↓
若仍 null → other
    ↓
输出 { relationType, relationLabel: 原文, confidence? }
```

### 5.1 规则引擎伪代码

```ts
const RULES: { type: RelationType; patterns: RegExp[]; priority: number }[] = [
  { type: 'enemy', priority: 100, patterns: [/宿敌/, /死敌/, /血海深仇/, /追杀/, /敌对/, /仇敌/] },
  { type: 'family', priority: 90, patterns: [/父母/, /兄长/, /同胞/, /血亲/, /义父/, /女儿/, /儿子/] },
  { type: 'romance', priority: 85, patterns: [/暗恋/, /恋人/, /倾心/, /爱慕/, /夫妻/, /未婚妻/] },
  { type: 'mentor', priority: 80, patterns: [/师徒/, /师父/, /徒弟/, /弟子/, /恩师/] },
  { type: 'faction', priority: 70, patterns: [/同门/, /师兄/, /师姐/, /同袍/, /属下/] },
  { type: 'ally', priority: 60, patterns: [/同盟/, /好友/, /挚友/, /伙伴/, /相助/] },
];

function normalizeRelationType(label: string): RelationType {
  const t = label.trim();
  let best: { type: RelationType; priority: number } | null = null;
  for (const rule of RULES) {
    if (rule.patterns.some((p) => p.test(t))) {
      if (!best || rule.priority > best.priority) best = rule;
    }
  }
  return best?.type ?? 'other';
}
```

（实际关键词表应比伪代码更全，与第三节对齐。）

### 5.2 LLM 兜底 Prompt（可选）

```text
将下列人物关系描述归入且仅归入一类：
family | romance | mentor | ally | enemy | faction | other

关系描述：{relation}
只输出类别英文代码，不要解释。
```

温度 0；结果不在枚举内则 other。

## 七、与图谱 / Agent 的衔接

| 模块 | 使用方式 |
|------|----------|
| 关系图谱 | 边颜色、线型、筛选器绑定 relationType |
| 子图注入 | 按 P0–P3 裁边；enemy/family/mentor/romance 生成硬禁止草稿 |
| 展示 | UI 主显 relationLabel，type 作图标/色点 |
| 统计 | 按 type 统计「敌对数/师徒数」供作者仪表盘（可选） |
