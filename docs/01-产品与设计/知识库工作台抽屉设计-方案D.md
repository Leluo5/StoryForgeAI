> 类型：界面设计文档（写作工作台知识库抽屉）

## 一、设计目标与定位

| 项 | 说明 |
| --- | --- |
| 定位 | 写作工作台内的轻量知识库入口，优先服务「边写边查、快速引用」场景 |
| 用户场景 | 创作者在写作/剧情/角色版图过程中，需要快速搜索素材、查看摘要、一键引用到当前作品或角色上下文时使用 |
| 入口 | 工作台顶部导航或右侧/左侧工具栏「知识库」图标/文字按钮；默认关闭，点击后从左侧滑出 |
| 与全页关系 | 抽屉右上角提供「全屏管理 →」跳转到方案 C 全局管理界面；跳转时可携带当前筛选与选中条目 |
| 断点 | 桌面 1024 / 1440；抽屉宽度固定，不随断点大幅变化 |

## 三、抽屉内部结构

### 3.1 抽屉头部（高度 48–56px）

```
┌─────────────────────────────────────────────────────┐
│ 知识库          [全局库] [本作品]          [全屏管理 →] │
└─────────────────────────────────────────────────────┘
```

- 库切换：Segmented Control，切换后列表即时刷新。
- 「全屏管理 →」：次要文字按钮 + 外链图标，跳转方案 C，并尽量保留当前筛选条件。

### 3.2 搜索与筛选条

- 单行搜索输入框（占满宽度），支持关键词即时搜索（防抖）。
- 下方一行：类型下拉（多选）、标签选择器、时间快捷筛选（可选折叠）。
- 筛选条件以 Chip 形式显示在搜索框下方，可一键清除。

### 3.3 紧凑卡片列表

**卡片规格（比全页更紧凑）**

```
┌──────────────────────────────────────────────────┐
│ [图标] 标题（单行省略）              ★  有大纲标记 │
│ 类型 · 更新时间 · 关联数                           │
│ 标签 chips（最多 2 个）                            │
└──────────────────────────────────────────────────┘
```

- 高度约 72–88px。
- 悬停显示「引用」快捷按钮（右侧浮现）。
- 点击卡片：在抽屉底部或右侧浮层展开**简易详情**（不跳转全页）。
- 支持无限滚动 / 游标加载。

**简易详情（抽屉内展开）**
- 标题 + 类型 + 标签。
- 摘要或结构化关键字段预览（最多 3–4 行）。
- 小说条目额外显示「大纲」折叠区（简化四维预览）。
- 底部操作：`[引用到当前作品]` `[查看完整]` `[编辑]`。
- 「查看完整」可跳转方案 C 并定位到该条目。

### 3.4 底部操作区（固定）

```
┌──────────────────────────────────────────────────┐
│ [+ 快速录入]              [导入 Markdown]         │
└──────────────────────────────────────────────────┘
```

- 「快速录入」：打开轻量录入面板（仅粘贴文本 + 类型选择），确认后直接入库并刷新列表。
- 「导入 Markdown」：打开文件选择，走导入预览流程（简化版）。

## 四、关键交互流程

1. **打开抽屉** → 默认显示「本作品」库（若在作品上下文）或「全局库」；加载最近更新条目。
2. **搜索 / 筛选** → 实时过滤，空结果显示「无匹配」+ 清除按钮。
3. **预览条目** → 点击卡片展开简易详情；再次点击或点关闭收起。
4. **一键引用** → 点击「引用到当前作品」→ 创建引用关系 → Toast「已引用」；若需要可弹出选择引用位置（章节/角色等，后续扩展）。
5. **快速录入** → 粘贴 → 选择类型 → 确认 → 入库 → 列表顶部插入新卡片。
6. **跳转全页** → 点击「全屏管理」→ 打开方案 C，并尽量带上当前关键词与类型筛选。

## 五、UI 视觉规范（与方案 C 一致）

| 元素 | Token / 规格 |
| --- | --- |
| 抽屉背景 | `--bg-card` 或略深于主内容的 `--bg-primary` 变体 |
| 强调色 | 知识库语义色 `--cyan-500`（头部指示条、图标、激活 Segment） |
| 卡片 | 圆角 8px，细边框，悬停背景 `--bg-hover` |
| 搜索框 | 高度 36–40px，圆角 6–8px |
| 字体 | 标题 14px 中等；次要信息 12px `--text-secondary` |
| 间距 | 抽屉内边距 16px；卡片间距 8–12px |
| 阴影 | 抽屉左侧可带轻微投影，与主内容区分离 |
| 动画 | 滑出时长 200–250ms，ease-out；符合全站动效规范 |

深浅主题同步，对比度达标。

## 六、状态与反馈

| 状态 | 表现 |
| --- | --- |
| 抽屉打开/关闭 | 平滑宽度动画 + 主内容区位移 |
| 列表加载 | 顶部或卡片位置骨架屏 |
| 空态 | 「本作品暂无引用知识」或「全局库为空」+ 快速录入引导 |
| 引用成功 | Toast + 卡片上短暂高亮 |
| 网络错误 | 抽屉内错误提示 + 重试按钮 |

## 七、与方案 C 的协作约定

| 场景 | 行为 |
| --- | --- |
| 从抽屉跳转全页 | 携带 `?scope=global|work&q=关键词&type=...` 等参数，全页初始化对应筛选 |
| 在全页修改后返回 | 抽屉重新打开时刷新列表（或通过事件总线通知） |
| 数据一致性 | 两者使用同一套 API 与缓存策略，避免重复请求 |
| 权限与归属 | 全局库按 `author_id`；作品库按当前作品引用关系 |

## 八、验收要点（设计侧）

- [ ] 抽屉宽度在 360–420px 区间可配置，打开后不严重挤压写作区。
- [ ] 紧凑卡片信息层级清晰，单手可快速扫视。
- [ ] 简易详情展开/收起流畅，不遮挡过多列表。
- [ ] 「引用到当前作品」路径最短（≤ 2 次点击）。
- [ ] 「全屏管理」跳转后筛选状态基本保留。
- [ ] 深浅主题、间距、颜色完全符合《UI设计规范》，并与知识库全局页视觉统一。
