# 知识库条目分类规则

> 版本：v1.1 · 状态：生效（2026-11-25）  
> 项目：StoryForgeAI —— 专业小说 AI 写作软件  
> 类型：业务规则文档  
> 适用范围：知识库录入、类型识别、结构化拆分、检索与展示  
> 关联：知识库全局管理界面设计、知识库工作台抽屉设计、知识库结构化字段详细定义、知识库新类型完整定义

---

## 一、分类总览

知识库条目统一划分为以下类型。录入时系统优先自动判定，用户可手动覆盖。

### 1.1 核心类型（已落地）

| 类型代码 | 中文名 | 核心定位 | 典型来源 |
|---------|--------|----------|----------|
| `article` | 文章 | 信息性、观点性、报道性文本 | 公众号、博客、新闻、专栏、网文资讯 |
| `paper` | 论文 | 学术研究、严谨论证文本 | 期刊论文、学位论文、研究报告、学术预印本 |
| `novel` | 小说 | 虚构叙事文本 | 网络小说、出版小说、短篇、大纲草稿 |
| `inspiration` | 灵感 | 碎片化、未成型的想法 | 随手笔记、一闪而过的点子、对话摘录 |
| `setting` | 设定集 | 世界观/规则等结构化设定材料 | 设定文档、力量体系、地理志、组织说明 |

### 1.2 扩展类型（已定义，可按优先级落地）

| 类型代码 | 中文名 | 优先级 | 核心定位 | 典型来源 |
|---------|--------|--------|----------|----------|
| `character` | 角色档案 | P0 | 单个或一组角色的详细设定与弧光 | 人物小传、角色卡、人设文档 |
| `plot_template` | 情节模板 | P0 | 可复用的情节结构与节拍 | 三幕结构、英雄之旅、爽文节拍 |
| `reference_work` | 对标作品 | P1 | 对已有作品的拆解与学习笔记 | 竞品分析、名著拆解、爆款复盘 |
| `technique` | 写作技法 | P1 | 具体可执行的写作方法与示范 | 对话技巧、描写方法、悬念制造 |
| `reader_feedback` | 读者反馈 | P2 | 读者评论与数据洞察 | 评论精选、数据报告、弃坑分析 |
| `timeline` | 时间线 | P2 | 故事或创作相关的时间事件序列 | 大事记、年表、创作日程 |

## 二、各类型判定规则

### 2.1 文章（article）

**判定特征（满足任意 2 项即可倾向判定为文章）：**
- 以传递信息、观点或事实为主，非完整虚构故事
- 存在明确的段落结构与逻辑推进（现象 → 分析 → 结论）
- 包含新闻要素、评论观点、教程步骤或知识科普
- 长度通常中等（500–8000 字常见），无明显章节叙事弧线

**排除特征：**
- 出现完整虚构人物弧光与情节冲突 → 倾向小说
- 出现「研究问题 / 方法 / 结论 / 局限」学术结构 → 倾向论文
- 内容极度碎片、无完整表达 → 倾向灵感
- 以单一角色人设为中心 → 倾向角色档案
- 教授具体写作步骤 → 倾向写作技法

**结构化输出重点：** 分段、核心观点、摘要、标签化要点清单

---

### 2.2 论文（paper）

**判定特征（满足任意 2 项即可）：**
- 具备学术写作特征：摘要、关键词、引言、方法、结果、讨论、参考文献
- 明确提出研究问题或假设，并给出方法与结论
- 使用学术用语（「本研究」「实验表明」「显著性」「局限性」等）
- 结构严谨，数据或引用支撑观点

**排除特征：**
- 仅为科普转述且无研究过程 → 倾向文章
- 纯虚构叙事 → 倾向小说
- 无论证过程的纯观点输出 → 倾向文章或灵感

**结构化输出重点：** 研究问题、研究方法、核心结论、研究局限、对创作/产品的可落地启发

---

### 2.3 小说（novel）

**判定特征（满足任意 2 项即可）：**
- 以虚构人物、情节、冲突为主线
- 存在叙事视角、时间线、场景描写
- 有明显的故事推进（开端–发展–高潮–结局或章节结构）
- 包含对话、心理描写、世界观暗示

**排除特征：**
- 纯设定罗列且无情节推进 → 倾向设定集
- 以单一角色详细人设为主、几乎无情节 → 倾向角色档案
- 真实事件报道或评论 → 倾向文章
- 学术论证 → 倾向论文

**结构化输出重点：** 角色、情节脉络、叙事风格、世界观 + **四维大纲**（章节、情节节点、人物关系、故事线）

---

### 2.4 灵感（inspiration）

**判定特征（满足任意 2 项即可）：**
- 内容碎片化、未完成、口语化或跳跃
- 表达的是「想法」「点子」「突然想到」而非完整文本
- 长度通常较短（< 500 字常见），缺乏完整结构
- 明确标注或语境为灵感记录

**排除特征：**
- 已形成完整段落与逻辑闭环 → 倾向文章
- 具备完整故事或设定体系 → 倾向小说或设定集
- 完整的角色小传 → 倾向角色档案

**结构化输出重点：** 原始文本、基于知识库的补充完善、自动关联（默认最多 3 条）

---

### 2.5 设定集（setting）

**判定特征（满足任意 2 项即可）：**
- 以「设定」为目的：世界观规则、力量体系、地理、历史、种族、物品、组织等
- 结构偏条目化、列表化或百科式，而非叙事推进
- 用于支撑小说创作，本身不是完整故事
- 常见标题含「设定」「体系」「志」「录」「百科」等

**排除特征：**
- 有完整情节与人物弧光 → 倾向小说
- 以单一角色为中心的人设文档 → 倾向角色档案
- 纯观点或资讯 → 倾向文章
- 学术研究过程 → 倾向论文

**结构化输出重点：** 分段 + 核心要点 + 标签 + 可选设定条目列表

---

### 2.6 角色档案（character）【扩展】

**判定特征（满足任意 2 项即可）：**
- 以单一或少数角色为描述中心
- 重点在性格、背景、外貌、能力、说话方式、成长弧光
- 包含关系描述，但主体不是完整故事情节
- 常见形式：人物小传、角色卡、人设文档

**排除特征：**
- 有完整情节推进与多场景叙事 → 倾向小说
- 以世界规则、力量体系为主 → 倾向设定集
- 碎片化一句话想法 → 倾向灵感

**结构化输出重点：** 姓名、身份、性格、背景、弧光、对白风格、重要关系、代表性台词

---

### 2.7 情节模板（plot_template）【扩展】

**判定特征（满足任意 2 项即可）：**
- 描述的是情节结构、节拍、套路、冲突升级路径，而非具体故事
- 可被套用到不同作品（具有抽象性与可复用性）
- 常见词：三幕、英雄之旅、节拍、反转、爽点、节奏

**排除特征：**
- 具体人物 + 具体事件推进 → 倾向小说
- 纯世界观规则 → 倾向设定集
- 写作文笔技巧（如何写对话/描写） → 倾向写作技法

**结构化输出重点：** 模板名称、节拍列表（名称/顺序/叙事任务/目的）、适用题材、冲突模式

---

### 2.8 对标作品（reference_work）【扩展】

**判定特征：**
- 主体是对另一部已有作品（小说/影视/游戏）的分析、拆解、优缺点总结
- 目的是学习或对标，而非讲述新故事
- 常见词：拆解、复盘、对标、学习、为什么火、节奏分析

**排除特征：**
- 作品原文或大量引用原文叙事 → 倾向小说
- 纯技法教学无具体作品 → 倾向写作技法

**结构化输出重点：** 作品名、题材、优点、不足、值得学习的手法、可落地启发

---

### 2.9 写作技法（technique）【扩展】

**判定特征：**
- 核心是「如何写」的具体方法、步骤、示范
- 可直接指导某一类段落或技巧的练习
- 常见：对话技巧、环境描写、悬念制造、文笔节奏

**排除特征：**
- 宏观结构套路 → 倾向情节模板
- 一般观点或资讯文章 → 倾向文章

**结构化输出重点：** 技法名称、说明、可执行步骤、正反示例、常见错误、适用场景

---

### 2.10 读者反馈（reader_feedback）【扩展】

**判定特征：** 来源为读者评论汇总、数据报告、追更/弃坑分析。  
**结构化输出重点：** 来源、正面点、负面点、数据洞察、对作者的改进建议

### 2.11 时间线（timeline）【扩展】

**判定特征：** 以时间顺序排列的事件序列（故事内或创作相关）。  
**结构化输出重点：** 标题、事件列表（时间/顺序 + 事件描述 + 重要程度）、范围（故事世界/创作/其他）

## 三、自动识别与人工覆盖规则

### 3.1 自动识别优先级

1. 用户手动指定类型 → **最高优先级**，直接采用
2. 系统 LLM 自动判定（返回类型 + 置信度）
3. 置信度 ≥ 0.75 → 直接采用自动结果
4. 置信度 0.5–0.75 → 弹出确认框，展示推荐类型与理由，允许用户修改
5. 置信度 < 0.5 或无法判定 → 强制用户手动选择

### 3.2 边界情况处理

| 情况 | 处理规则 |
|------|----------|
| 小说中夹杂大量设定 | 整体仍判定为 `novel`，设定部分在结构化中提取到「世界观设定」 |
| 小说中详细描写单一角色 | 若主体仍是叙事 → `novel`；若几乎无人设外的情节 → `character` |
| 设定集中的人物小传 | 若以角色为中心且无世界规则主体 → `character`；否则保持 `setting` |
| 情节结构说明 + 少量例子 | 倾向 `plot_template` |
| 对某作品的技法分析 | 若以作品拆解为主 → `reference_work`；若以方法教学为主 → `technique` |
| 灵感后续被扩充成完整文章/角色档案 | 允许用户修改类型，系统保留原关联关系 |
| 多类型混合文本 | 以「主要表达目的」为准；无法判断时由用户指定 |

### 3.3 类型变更规则

- 允许随时修改类型
- 修改类型后，系统应重新触发对应结构化拆分（或提示用户是否重新拆分）
- 原有关联关系与标签默认保留，可由用户清理

## 四、分类使用原则

1. **目的导向**：分类服务于「后续如何被创作使用」，而非单纯文本形式。
2. **宁可确认，不可误判**：低置信度必须让用户确认，避免错误结构化。
3. **结构化差异化**：不同类型必须走不同的拆分模板，禁止一刀切。
4. **可追溯**：每条条目记录最终类型来源（`auto` / `manual` / `user_override`）。
5. **检索友好**：类型作为一级筛选维度，必须稳定、可枚举；新增类型需先修订本文档。
6. **扩展克制**：优先落地 P0（character、plot_template），其余按用户反馈与开发带宽推进。

---

## 五、禁止事项

- 禁止新增未在本文档定义的类型（需先修订本规则再上线）
- 禁止将不同核心类型混用同一结构化模板
- 禁止在自动识别失败时静默默认某一类型
- 禁止删除已有类型（仅可标记废弃并迁移）
