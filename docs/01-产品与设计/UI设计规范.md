## 一、设计风格定位与设计原则

### 1.1 风格定位：墨韵科技风（Ink & Tech）

StoryForgeAI 是**面向网络小说创作者的专业 AI 写作工具**。用户长时间沉浸于文字创作，审美偏好偏向**沉静、专注、有书卷气**，同时期望 AI 工具**高效、可靠、科技感**。二者融合，形成「墨韵科技风」：

| 维度 | 取向 | 表现 |
| --- | --- | --- |
| 视觉基底 | 书卷墨色 | 深灰蓝基底、暖白纸感背景，克制不喧宾夺主，让文字成为主角 |
| 品牌识别 | 创作靛蓝 | 靛蓝主色呼应「灵感」与「创作」，紫罗兰渐变为辅助强调 |
| 质感 | 纸张 + 微光 | 极浅阴影 + 细边框，卡片有"纸张"的轻盈；关键 CTA 带柔和光晕 |
| 氛围 | 专注沉静 | 低饱和大面积色块 + 高饱和小面积强调，节奏清晰不疲劳 |
| 科技效率 | 清晰的信息架构 | 左侧导航 + 内容工作台 + 右侧上下文面板，工具化、模块化 |

### 1.2 设计原则（8 条）

| # | 原则 | 说明 |
| --- | --- | --- |
| P1 | **文字优先** | 创作工具的核心是文字。背景、装饰、颜色永远服务于可读性，不抢文字焦点 |
| P2 | **8px 栅格** | 所有间距、尺寸、对齐以 8px 为基准，保证视觉节奏统一 |
| P3 | **状态可见** | 每个组件必须有明确的 `default / hover / active / disabled / loading / focus` 状态，禁止"看起来像不可点" |
| P4 | **对比达标** | 正文文本对背景对比度 ≥ 4.5:1（WCAG AA），大号文字 ≥ 3:1 |
| P5 | **克制渐变** | 渐变仅用于品牌头图、主 CTA、AI 生成区域背景，普通内容区禁用渐变 |
| P6 | **双主题一致** | 浅/深主题必须同时维护，同一语义色在两主题下均达标，禁止只改一主题 |
| P7 | **组件复用** | 禁止散落字面量；颜色、圆角、阴影、字号一律取自 CSS 变量 |
| P8 | **多端适配** | 同一组件在 PC / 移动端语义不变，仅布局与交互方式自适应（见 §9） |

### 1.3 使用禁忌（全局红线）

| 禁忌 | 说明 |
| --- | --- |
| ❌ 禁用高饱和大红/亮绿大面积铺底 | 会破坏沉静氛围，语义色仅作状态与强调 |
| ❌ 禁用无意义渐变背景 | 内容区、表单区、弹窗一律纯色 |
| ❌ 禁用纯黑 `#000` 文本 | 用 `#1A1A2E`（浅） / `#F1F5F9`（深），避免刺眼 |
| ❌ 禁用小于 12px 正文 | 最小可读字号 12px，正文 ≥ 14px |
| ❌ 禁用阴影滥用 | 卡片最多一层阴影，浮层用 `shadow-xl`，禁止多层叠加 |
| ❌ 禁用主题不同步 | 新颜色必须同时定义 `:root` 与 `[data-theme="dark"]` |

## 二、色彩系统（Color System）

### 2.1 品牌主色

主色是产品的身份锚点，用于主 CTA、激活态、品牌标识、链接。沿用既有 `#4F46E5` 保证品牌延续性。

| Token | 浅色主题 | 深色主题 | 用途 |
| --- | --- | --- | --- |
| `--brand-500`（主色） | `#4F46E5` | `#6366F1` | 主按钮、激活导航、焦点、链接 |
| `--brand-600`（主色悬停） | `#4338CA` | `#4F46E5` | 主按钮 hover |
| `--brand-700`（主色按下） | `#3730A3` | `#4338CA` | 主按钮 active |
| `--brand-400`（主色浅） | `#818CF8` | `#A5B4FC` | 图标强调、描边 hover |
| `--brand-100`（主色底） | `#EEF2FF` | `#1E1B4B` | 选中底、tag 背景、浅色强调 |
| `--brand-50`（主色极浅） | `#F5F7FF` | `#17143B` | 悬停浅底、AI 生成背景 |

> 深色主题主色提亮至 `#6366F1` 是为了保证深底对比度 ≥ 4.5:1（`#6366F1` 对 `#0F172A` 约 4.6:1）。

| `--emerald-500` | `#059669` | 版本 / 快照 | 版本管理、导出 |

### 2.4.1 强调色（离开类动作）

「返回作品库」等**离开当前工作上下文**的动作使用强调色，与工具栏内其余 ghost 按钮区分。
语义为「退出」，选暖调琥珀金，与品牌靛蓝互补；深色主题改用亮琥珀 + 深色文字以保住对比度。

| Token | 浅色主题 | 深色主题 | 用途 |
| --- | --- | --- | --- |
| `--btn-accent-bg` | `#B45309` | `#FBBF24` | 强调按钮底色（白字 / 深色字对比度均 ≥ 4.5:1） |
| `--btn-accent-bg-hover` | `#92400E` | `#F59E0B` | hover |
| `--btn-accent-bg-active` | `#7C2D12` | `#D97706` | active |
| `--btn-accent-text` | `#FFFFFF` | `#1C1005` | 文字 |
| `--nav-bg` | `#EEF2F7`（= `--bg-hover`） | `#172033` | 工作台章节导航栏底色 |

> `--nav-bg` 采用「导航栏有底色、去滑动条」方案：底色复用 `--bg-hover` 蓝灰，与正文白底弱对比，不抢阅读焦点。
> 强调色禁忌：同一页面强调色按钮 ≤ 1 处，避免与主色 CTA 抢位。

### 2.5 渐变规则

渐变是**品牌氛围语言**，只在三处使用，禁止扩散：

| 位置 | 渐变 | 说明 |
| --- | --- | --- |
| 品牌头部 / 英雄区 | `linear-gradient(135deg, #4F46E5 0%, #7C3AED 50%, #A855F7 100%)` | 顶部横幅、登录/欢迎页视觉 |
| 主 CTA（可选） | `linear-gradient(135deg, #4F46E5, #7C3AED)` | 仅"生成/创建"类主操作按钮 |
| AI 生成区域背景 | `linear-gradient(180deg, #F8F7FF, #FFFFFF)`（深：`#1E1B4B → #1E293B`） | 区分 AI 产出内容的承载区 |

**渐变禁忌**：卡片、弹窗、表单、表格、侧边栏、普通按钮一律纯色；同一页面渐变使用 ≤ 2 处。

### 2.6 Accessibility 对比度标准

| 元素 | 最小对比度 | 目标 |
| --- | --- | --- |
| 正文文本 vs 背景 | **4.5:1** | WCAG AA |
| 大号文本（≥ 24px 或 ≥ 18.66px bold） | 3:1 | WCAG AA |
| UI 组件边界 / 图标 | 3:1（非装饰性） | WCAG AA |
| 链接 vs 背景 | 4.5:1 | WCAG AA |
| 占位文本 | 4.5:1（建议 ≥ 3:1 容忍） | 尽量达标 |
| 主色 `#4F46E5` vs 白底 | 4.7:1 ✅ | AA 通过 |
| 主色 `#6366F1`(深) vs `#0F172A` | 4.6:1 ✅ | AA 通过 |
| 次要文本 `#475569` vs `#FFFFFF` | 6.5:1 ✅ | AA 通过 |

**检验工具**：WebAIM Contrast Checker；开发自检用浏览器 DevTools 无障碍检查。**任何新颜色必须通过 4.5:1 校验才能作为正文色。**

## 三、字体系统（Typography System）

### 3.1 字体族（Font Family）

| Token | 字体栈 | 用途 |
| --- | --- | --- |
| `--font-sans` | `Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif` | 正文、标题、界面 |
| `--font-mono` | `'JetBrains Mono', 'SF Mono', 'Fira Code', Consolas, monospace` | 代码、JSON、统计数字 |

- 中文：`PingFang SC / Microsoft YaHei` 优先；西文：`Inter / Segoe UI` 优先（西文数字用 Inter 更清晰）。
- 不引入外部字体文件（零构建链），依赖系统字体栈，保证启动速度。

### 3.2 字号层级（Type Scale）

基准 `16px`，以 `1.25` 模块化比例扩展：

| 层级 | Token | 字号 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- | --- |
| Display | `--fs-display` | `32px` | `1.25` | `700` | 页面主标题（仅欢迎页/登录） |
| H1 | `--fs-h1` | `24px` | `1.3` | `600` | 页面级标题 |
| H2 | `--fs-h2` | `20px` | `1.35` | `600` | 区块标题 / 卡片标题 |
| H3 | `--fs-h3` | `16px` | `1.4` | `600` | 子区块 / 分组标题 |
| Body | `--fs-body` | `14px` | `1.6` | `400` | **默认正文** |
| Body-LG | `--fs-body-lg` | `16px` | `1.6` | `400` | 正文强调 / 阅读区 |
| Small | `--fs-small` | `12px` | `1.5` | `400` | 辅助说明、meta 信息 |
| Caption | `--fs-caption` | `12px` | `1.4` | `500` | 标签、徽标、按钮内文本（小） |
| Mono | `--fs-mono` | `13px` | `1.5` | `400` | 代码、ID、数字统计 |

**最小可读字号 12px**。正文默认 14px，长文阅读（章节正文）用 16px 以提升沉浸感。

### 3.3 字重（Font Weight）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--fw-regular` | `400` | 正文、次要内容 |
| `--fw-medium` | `500` | 强调文本、按钮、列表项 |
| `--fw-semibold` | `600` | 标题、卡片标题、导航激活 |
| `--fw-bold` | `700` | 页面主标题、数字强调 |

> 中文粗体在 500-600 区间视觉最均衡，避免 700+ 在中文字体下发糊。标题用 600，主标题才用 700。

### 3.4 响应式适配规则

| 场景 | 规则 |
| --- | --- |
| 字号缩放 | 页面级标题（H1/Display）在移动端下调一档：`32→28`、`24→22`；正文/卡片标题不变 |
| 行高 | 长文阅读行高 1.7-1.8（移动端放宽）；界面行高固定 1.5-1.6 |
| 字重 | 移动端减少粗体使用，用字号 + 间距代替层级区分 |
| 缩放单位 | 页面标题用 `clamp()` 控制（如 `clamp(22px, 4vw, 32px)`）；组件字号固定 px |
| 阅读宽度 | 章节正文最大宽 720px，超宽时居中，防一行过长 |

**禁忌**：正文不用 `vw/vh` 单位（会随窗口抖动）；组件字号固定不缩放。

## 四、间距系统（Spacing System）

### 4.1 8px 基准栅格

所有间距、内边距、组件尺寸基于 **8px 栅格**（`spacing = n × 8px`）。允许半档 4px 用于紧凑微调。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--sp-1` | `4px` | 图标与文本间距、微调（半档） |
| `--sp-2` | `8px` | 紧凑间距、元素间最小间距 |
| `--sp-3` | `12px` | 图标按钮内边距、紧凑卡片内边距 |
| `--sp-4` | `16px` | **默认内边距**（卡片、输入框、列表项） |
| `--sp-5` | `24px` | 区块内间距、卡片间间距 |
| `--sp-6` | `32px` | 区块间间距、页面留白 |
| `--sp-7` | `48px` | 页面级区块分隔 |
| `--sp-8` | `64px` | 页面顶部/底部留白 |

### 4.2 常用间距值速查

| 场景 | 间距 |
| --- | --- |
| 页面左右留白 | `24px`（移动 `16px`） |
| 页面顶部/底部 | `32px` |
| 卡片内边距 | `16px`（紧凑）/ `24px`（宽松） |
| 卡片间距（网格） | `16px` |
| 区块之间 | `32px` |
| 表单字段间距 | `16px`（垂直）/ `12px`（同组） |
| 按钮内水平/垂直 | `16px / 8px`（默认）、`24px / 10px`（大） |
| 输入框内边距 | `12px`（水平）/ `8px`（垂直） |
| 图标与文本 | `8px` |

### 4.3 组件内外边距规范

| 组件 | 内边距 | 外边距 |
| --- | --- | --- |
| 按钮（默认） | `8px 16px` | 相邻按钮 `8px` |
| 按钮（大） | `10px 24px` | — |
| 输入框 | `8px 12px` | 垂直相邻 `16px` |
| 卡片 | `16px`（标准）/ `24px`（宽松） | 网格 `16px` |
| 导航项 | `8px 12px` | 组内 `4px` |
| 标签（tag） | `2px 8px` | 相邻 `8px` |
| 弹窗 | `24px`（内容区） | 标题/内容/底部间距 `16px` |
| 表格单元格 | `8px 16px` | — |

**禁忌**：间距不落在 8px 网格上（4px 半档除外）；组件内边距与页面留白混淆使用。

## 五、组件库标准（Component Library）

### 5.1 通用组件状态机

每个组件统一实现以下状态，视觉必须可区分：

| 状态 | 触发 | 视觉规则 |
| --- | --- | --- |
| `default` | 常态 | 标准外观 |
| `hover` | 鼠标悬停 | 背景加深 / 阴影轻微上浮 / 描边变主色 |
| `active` | 按下 | 背景进一步加深 / 描边主色 / 轻微下沉 |
| `focus` | 键盘/点击聚焦 | `2px` 主色 focus ring（`outline: 2px solid var(--brand-500); outline-offset: 2px`） |
| `disabled` | 不可用 | `opacity: 0.5` + `cursor: not-allowed`，不变色（保持辨识） |
| `loading` | 提交/请求中 | 内容替换为 spinner，禁用点击 |
| `selected` | 已选中 | 主色边框 / 主色底 / 选中态图标 |

> **焦点可见性（关键无障碍项）**：任何可交互元素必须保留可见 `focus` 态，禁止 `outline: none` 而无替代。

### 5.2 按钮（Button）

**变体**：

| 变体 | 外观 | 用途 |
| --- | --- | --- |
| `primary` | 主色底 + 白字 | 主操作（生成、创建、保存） |
| `secondary` | 白底 + 主色描边 + 主色字 | 次操作、取消 |
| `ghost` | 透明底 + 主色字 | 轻量操作、工具栏 |
| `danger` | 错误红底 + 白字 | 删除、破坏性操作（需二次确认） |
| `text` | 纯文字 + 主色 | 行内操作、链接式 |
| `disabled` | `opacity .5` | 不可用 |

**尺寸**：

| 尺寸 | 高度 | 内边距 | 字号 | 场景 |
| --- | --- | --- | --- | --- |
| `sm` | `32px` | `4px 12px` | `12px` | 紧凑、表格内 |
| `md`（默认） | `40px` | `8px 16px` | `14px` | 常规 |
| `lg` | `48px` | `10px 24px` | `16px` | 主 CTA、登录 |

**圆角**：`8px`（默认）。**交互规则**：点击延迟无 → `active` 下沉 `1px`；`loading` 时显示 spinner + 文案（如"生成中…"）并禁用。

**禁忌**：一个区域只放一个 primary；相邻 primary 按钮 ≤ 1；danger 按钮必须配二次确认弹窗；禁止按钮内换行。

### 5.3 输入框 / 表单控件

| 状态 | 规则 |
| --- | --- |
| `default` | 白底（深：`#0F172A`）+ `1px #E2E8F0` 边框 + `8px` 圆角，内边距 `8px 12px` |
| `hover` | 边框变主色 `#818CF8` |
| `focus` | `2px` 主色 focus ring + 边框主色 |
| `filled` | 有值后 `text-primary`，占位 `text-tertiary` |
| `error` | 边框 `--danger-500` + 错误文案（红字 12px 置于下方） |
| `disabled` | `opacity .5` + 灰底 |

**配套规则**：
- 文本域（textarea）行高 `1.6`，min-height `80px`，可拖拽调整（垂直）。
- 下拉（select）需有箭头图标，多选用 chip 标签。
- 校验文案：`12px`，与字段间距 `4px`，错误红 / 成功绿。
- 标签（label）在字段上方，`14px` 中字重，必填项加 `*`（红色）。

**禁忌**：禁止无 label 的裸输入框（除搜索框可加 aria-label）；禁止输入框高度 < 36px。

### 5.4 卡片（Card）

| 类型 | 规则 |
| --- | --- |
| 默认卡片 | 白底 + `1px #E2E8F0` + `16px` 圆角 + `shadow-sm`，内边距 `16px` |
| 可点击卡片 | hover 时 `shadow-md` + 上浮 `2px` + 边框主色，光标 pointer |
| 选中卡片 | 边框 `2px 主色` + 主色浅底 |
| AI 卡片 | 带 `--ai-gen-bg` 渐变背景 + 左上角 AI 徽标（见 §7.3） |

**组成**：`header`（标题 + 可选操作）→ `body`（内容）→ `footer`（可选操作区），间距 `16px`。
**禁忌**：卡片不嵌套卡片（≤ 1 层）；禁止卡片内塞过多操作（> 3 个移入 header 下拉）。

### 5.5 导航（Navigation）

| 类型 | 规则 |
| --- | --- |
| 顶部导航（大厅/全局） | 高度 `64px`，白底 + 底部细边框；左侧 Logo（品牌色），中间菜单，右侧操作区 |
| 左侧边栏（工作台） | 宽度 `240px`（折叠 `64px`），深色或浅色均可，导航项高 `40px`，激活项主色浅底 + 主色字 + 左侧 `3px` 主色条 |
| 面包屑 | `12px` 次要色，层级用 `/` 分隔 |
| Tab 切换 | 下划线式，激活项主色下划线 `2px`，文本主色 |

**交互**：导航项 hover 变 `--bg-hover`；激活态用主色强调；折叠侧边栏 hover 显示 tooltip（名称）。

### 5.6 标签 / 徽标（Tag / Badge）

| 语义 | 底色 | 文字 |
| --- | --- | --- |
| `brand` | `--brand-100` | `--brand-500` |
| `success` | `--success-100` | `--success-500` |
| `warning` | `--warning-100` | `--warning-500` |
| `danger` | `--danger-100` | `--danger-500` |
| `info` | `--info-100` | `--info-500` |
| `violet` | `#EDE9FE` | `#7C3AED` |
| `magenta` | `#FCE7F3` | `#DB2777` |

尺寸：`20px` 高、`12px` 字号、`4px` 圆角、内边距 `2px 8px`。可带删除 `×`。
**禁忌**：同一行 ≤ 3 个 tag，超出用"+N"。

### 5.7 弹窗（Modal / Dialog）

| 项 | 规则 |
| --- | --- |
| 遮罩 | `rgba(0,0,0,0.5)`（深色 `rgba(0,0,0,0.7)`），点击遮罩默认关闭（破坏性确认弹窗除外） |
| 容器 | 宽 `480px`（默认）/ `640px`（宽），`16px` 圆角，`shadow-xl`，居中 |
| 结构 | 标题（`20px` 600）→ 内容（`14px`）→ 底部操作区（右对齐，`16px` 间距） |
| 动画 | 淡入 + 上移 `8px`，`200ms` |
| 关闭 | 右上角 `×` 图标（`24px`）；`Esc` 可关（破坏性除外） |

**禁忌**：禁止无标题弹窗；破坏性弹窗必须有"取消"和"确认"两个按钮，确认用 `danger`。

### 5.8 加载状态（Loading）

| 类型 | 规则 |
| --- | --- |
| 按钮内 | spinner `16px` + 文案 |
| 区块加载 | 居中 spinner `32px` + 次要色文字（如"生成中…"） |
| 骨架屏 | 浅灰 `--bg-tertiary` 占位块，微光扫过动画，用于列表/卡片首屏 |

**禁忌**：SSE 流式输出时不用整页 loading（用流式文本 + 光标），避免频繁闪屏。

### 5.9 其他控件

| 组件 | 规则 |
| --- | --- |
| 开关（Switch） | 开：主色底；关：灰底；轨道 `40×24px`，滑块 `20px` |
| 复选框/单选 | `16px`，选中主色底白勾 |
| 滑条（Slider） | 轨道 `4px` 灰，主色填充，圆钮 `16px` 主色 |
| 工具提示（Tooltip） | 深色 `#1E293B` 底白字，`12px`，圆角 `6px`，箭头指向触发元素 |
| 进度条 | 轨道灰 `6px` 圆角，主色填充，进度文本右侧 |

## 六、图标规范（Icon System）

### 6.1 风格

| 项 | 规范 |
| --- | --- |
| 风格 | **线性（Line）**，描边 `1.5px`，圆角端点（`stroke-linecap: round; stroke-linejoin: round`） |
| 实现 | 内联 SVG（`currentColor`），**禁止**使用 emoji 作为功能图标 |
| 填充 | 默认透明，选中/强调态可填充主色浅底 |

### 6.2 尺寸

| 尺寸 | 用途 |
| --- | --- |
| `16px` | 行内辅助图标、表格内、tag |
| `20px` | 按钮图标、表单控件内 |
| `24px` | 导航项、工具栏、操作区 |
| `32px` | 页面/区块级空状态、卡片头 |
| `48px` | 品牌标识、空状态大图 |

> 图标尺寸必须落在 8px 网格（16/24/32 是主流；20px 作为半档用于紧凑按钮）。

### 6.3 使用场景与禁用

| 场景 | 建议 |
| --- | --- |
| 导航/菜单 | `24px` 线性图标 |
| 按钮内 | `20px`，与文本间距 `8px` |
| 空状态 | `48px` 线性 + 次要色，配主文案 + 次文案 + CTA |
| 状态反馈 | 语义色图标（成功/警告/错误），配文案，不单用图标 |

**禁忌**：功能图标必须配 `aria-label` 或可见文字；装饰性图标必须 `aria-hidden="true"`；禁止用彩色 emoji 代替系统图标；禁止图标与文字基线错位（图标垂直居中对齐文本）。

## 七、布局规则（Layout System）

### 7.1 栅格系统

| 项 | 规范 |
| --- | --- |
| 列数 | **12 列** |
| 栅格间距（gutter） | `16px`（页面）/ `24px`（宽屏） |
| 外边距（margin） | 页面留白，随断点调整 |
| 实现 | CSS Grid（`grid-template-columns: repeat(12, 1fr)`）+ `gap`；移动端降为单列 |
| 断点对应列数 | `<640px` 单列；`640-1024` 6 列；`≥1024` 12 列 |

### 7.2 断点设置（Breakpoints）

| 断点 | 值 | 设备 | 布局行为 |
| --- | --- | --- | --- |
| `--bp-mobile` | `< 640px` | 手机 | 单列堆叠，侧边栏转抽屉，顶导航转汉堡 |
| `--bp-tablet` | `≥ 640px` | 平板 | 2 列卡片，侧边栏可折叠 |
| `--bp-laptop` | `≥ 1024px` | 小桌面 | 3 列卡片，完整侧边栏 |
| `--bp-desktop` | `≥ 1280px` | 大桌面 | 4 列卡片，多栏工作台 |

> 移动端判定以 `max-width` 为主（`@media (max-width: 639px)`），桌面以 `min-width` 为主，避免双重定义冲突。

### 7.3 容器宽度

| 容器 | 最大宽 | 说明 |
| --- | --- | --- |
| 内容容器（大厅） | `1200px` | 居中，左右留白 `24px` |
| 内容容器（窄） | `960px` | 表单、设置页 |
| 阅读/章节容器 | `720px` | 章节正文，居中，行高放宽 |
| 工作台布局 | 满宽 | 侧边栏 `240px` + 内容自适应 + 可选右面板 `320px` |

**禁忌**：容器宽度不用固定 `100%` 撑满无留白；大屏下内容不居中会降低可读性。

## 十一、验收标准

> 设计规范验收（规范本身）与落地验收（代码实现）两层。

### 11.1 规范无歧义

- [ ] 六大模块（色彩/字体/间距/组件/图标/布局）均有明确 Token 值与取值规则，无"适当/酌情"等模糊词。
- [ ] 每条规则标注推荐用法与禁忌，表格化呈现。
- [ ] 所有颜色给出十六进制值 + 浅/深双主题对应值。

### 11.2 组件定义完整

- [ ] 8 类通用组件均有 `default/hover/active/focus/disabled/loading/selected` 状态定义。
- [ ] 每个组件有尺寸、内边距、圆角、间距的具体数值。
